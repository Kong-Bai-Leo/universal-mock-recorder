## 三、构造方式

在课时96 的轴网基础上叠加:

1. **顶部尺寸链**:`DIMLINEAR 0,8880 2972,8880` + `DIMCONTINUE` 到 5960 / 10385 / 14622 / 17104
   —— 五段全部 C 级;右端另加 `DIMLINEAR 38186,8880 45085,8880`。
2. **右侧竖向尺寸链**:`DIMLINEAR 45085,0 45085,4351` + `DIMCONTINUE 45085,6127 / 45085,8880`
   —— **4351 / 6127 两个分点无出处**(见缺口 2),只有总进深 8880 是 C。
3. **通道箭头**:`PLINE 6000,-1200 _W 0 600 6000,600`(锥形箭头,0→600)。
4. **主通道线**:`PLINE 1500,2200 _W 260 260 12000,2600 24000,2400 36000,2600 43500,2400`
   —— 等宽 260 是 C,**折点坐标全部无出处**。
5. **标题**:`TEXT 22542.5,16880 800 0 商铺划分示意图` —— 内容是 D 级(312.0s 特性面板)。
6. **统计文字**:`面积: 15.6m2` / `周长: 15.9m` —— 数值是 C 级(849.1s)。

## 六、做不到的部分 / 数值找不到出处

1. **⚠ 面积/周长的标注对象对不上。** 849.1s 的 `区域 = 15591845.7044`(= **15.59 m²**)
   和 `周长 = 15946.6726`(= **15.95 m**)是本课最硬的两个数,但脚本把它们
   标在了**商铺01** 上;而按轴网算,商铺01 = 3022 × 8880 ≈ **26.8 m²**,周长 ≈ 23.8 m。
   由面积+周长闭合反解,被测的其实是一个约 **4.53 m × 3.44 m** 的矩形 ——
   **不是任何一间商铺**。因此这两条文字虽然数值是 C 级,**归属是错的**。
   建议把它们改成不指向具体商铺的独立标注,或查明视频里到底量的是哪块区域。
2. **⚠ 右侧竖向尺寸链的两个分点(4351 / 6127)没有出处。** 本课只回读过总进深 8880;
   把 8880 分成 4351 + 1776 + 2753 这一步在命令流里**找不到任何依据**。
3. **⚠ 通道 PLINE 的折点坐标全部无出处。** 只有宽度(0/600/260/260)是 C 级,
   `1500,2200 → 12000,2600 → 24000,2400 → 36000,2600 → 43500,2400` 这五个点
   是照画面比例摆的。箭头 `6000,-1200 → 6000,600` 同理。
4. **视频里还有两组尺寸链没有纳入**:254.4s 画面上的 `12250 / 2400 / 6700`,
   565.4s 的 `7710 / 7790 / 4470 / 4750`。它们出现在标注文字里(D 级可读),
   但脚本没有对应几何,**这部分内容缺失**。
5. **`MATCHPROP` 的注释性特性传递(316.8s)未复刻** —— 无头版没有 MATCHPROP。
6. **`562.1s 把 PLINE 宽度改回 0` 未复刻** —— 那次 PLINE 被取消了。
7. **商铺编号文字(商铺01–11)的内容仍无命令行出处**(与课时96 同一缺口);
   本课唯一被确证的文字是标题「商铺划分示意图」(D 级)。
8. **`ERASE 找到 4 个` 删掉的是什么无从判断**,不影响终态。
