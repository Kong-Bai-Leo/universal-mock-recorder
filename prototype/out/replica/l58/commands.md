## 一、命令流

全课只有一条命令:`LE` → `QLEADER`,反复 **30 余次**,每次都先进 `[设置(S)]` 改一个选项再画,
用来把「引线设置」对话框的三个选项卡(注释 / 引线和箭头 / 附着)逐项演示一遍。

典型一轮:
```
命令: LE
QLEADER
指定第一个引线点或 [设置(S)] <设置>: s      ← 打开对话框改设置
指定第一个引线点或 [设置(S)] <设置>:        ← 拾取点 1
指定下一点:  <正交 关>                      ← 拾取点 2
指定下一点:  <正交 开>                      ← 拾取点 3
输入注释文字的第一行 <多行文字(M)>: <文字>
输入注释文字的下一行: <文字或空>
```

## 四、构造方式

12 条引线里 **11 条**落到脚本,布成两列:

- **左列(x=0)8 条**,`QLEADER` 直接复刻:3 个拾取点 + 文字宽度 0 + 注释文字。
  Y 依次为 0 / −120 / −240 / −360 / −480 / −600 / −780 / −960。
- **右列(x=700)3 条**,改用 `LEADER`:因为无头 `QLEADER` 无法进「引线设置」对话框改
  「直线 / 样条曲线」和「无引线」这两个本课重点选项,只能用 `LEADER` 的
  `_F _S`(样条)/ `_F _N`(无引线)等价实现。第三条给了 5 个点,复现 500.6s
  那次「多折点引线」演示。

**所有坐标均无命令行出处**(讲师全程鼠标拾取),按视频画面的相对排布摆放,等级 L。

## 七、做不到的部分 / 数值找不到出处

1. **⚠ 漏了一条引线:`窗户高度 / 窗户宽度 / 窗台高度 / 窗梁高度`。**
   这条 4 行中文引线在 682.1–713.3s 完整走完(`输入注释文字的下一行:` 收空行结束,
   随后回到 `命令:` 提示),**并没有被取消**;721.4s 的两次 `*取消*` 发生在命令提示符下,
   属于空取消。因此视频里实际完成了 **12** 条引线,脚本只有 **11** 条。
   这是本课唯一一条"有实际工程含义"的注释(其余都是乱敲的占位文字),**建议补上**。
2. **第 6 条文字首字符存疑。** 蒙太奇里显示的是 `1k打飞机奥斯卡冷风机啊`(数字 1),
   脚本写的是 `lk…`(小写 L)。命令行字体下 `1` 与 `l` 极难区分,**无法从证据判定**,保持现状并标注。
3. **本课所有坐标没有出处。** 179 条条带里一次拾取点坐标都没回显过;
   唯一出现的数字是 229.9s 动态输入框的 `2375.2162 / 2213.0865`(光标位置,非拾取点)。
   引线的位置、长度、折角全部是按画面比例摆的(L 级)。
4. **「引线设置」对话框的具体勾选项无法读取。** 讲师进出对话框 30 余次,
   但 CV 只抓了命令行条带,没有对应的对话框裁图目录(本课无 `dlg\`),
   所以「注释类型 / 重复使用 / 引线格式 / 箭头 / 角度约束 / 附着位置」的每一项设了什么**无证据**。
   脚本用 `LEADER` 的 `_F _S` / `_F _N` 是**功能等价推断**,不是回读。
5. 视频里 3 条被脚本改成 `LEADER` 的引线,原本在视频里也是 `QLEADER` 画的 ——
   实体类型一致(都是 LEADER),但**命令不同**,属于无头环境下的刻意替换。
