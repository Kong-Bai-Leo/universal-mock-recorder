## 构造

`l9.scr` 只落地 **3 段圆弧**,全部来自**终态帧像素测量**(`geo.json`,t=880.0s,
`--color white`),按 `--flipy 597` 映射:

| geo.json | l9.scr | 换算 |
|---|---|---|
| `c=[447.0, 463.8] r=99.3 a0=185 a1=54` | `_.ARC _C 447.000,133.200 348.078,124.545 _A 229.000` | y: 597−463.8=**133.2**;起点 = 圆心 + 99.3∠185°;夹角 = 54−185+360 = **229** |
| `c=[528.6, 309.0] r=61.0 a0=5 a1=75` | `_.ARC _C 528.600,288.000 589.368,293.317 _A 70.000` | y: 597−309=**288**;夹角 = 75−5 = **70** |
| `c=[528.6, 309.0] r=61.0 a0=221 a1=3` | `_.ARC _C 528.600,288.000 482.563,247.980 _A 142.000` | 夹角 = 3−221+360 = **142** |

**没有第 4 段**,即脚本里不存在测量之外的圆弧。

## 验证(verify.json)

```
l9.dxf  counts = { ARC: 3 }
  {c:[447.0,133.2],   r:99.2999, a0:185.0003, a1:54.0003}
  {c:[528.6,288.0],   r:61.0002, a0:5.0005,   a1:75.0005}
  {c:[528.6,288.0],   r:61.0,    a0:221.0005, a1:3.0005}
```
半径 99.30 / 61.00 / 61.00 与 `geo.json` 的 99.3 / 61.0 / 61.0 **完全一致**,
起止角 185/54、5/75、221/3 也逐一吻合 —— 回放没有走样。
本课**无标注实体**,无标注回读值。

## 证据等级

| 内容 | 等级 |
|---|---|
| ARC 全部 6 种给法(三点 / 圆心 / 端点 / 夹角 A / 弦长 L / 方向 D / 半径 R) | **C** |
| 命令行数值:夹角 60、100、50;半径 200;弦长 1000 | **C**(但**未被脚本采用**,见下) |
| 标注回读:DIMANGULAR 60 / 120 | **D**(未被脚本采用) |
| 落地 3 段圆弧的圆心 / 半径 / 起止角 | **M**(像素测量,1:1 像素→单位) |

## 数值出处核对 —— 发现

- 落地的 3 段圆弧,**每一个数字都能在 `geo.json` 里对上**(见上表),
  **没有发现无出处(疑似编造)的数值**。
- ⚠ 但要指出:命令行里确实存在**更高等级(C 级)的数值** ——
  夹角 **60**(437.8s)、**100**(654.7s)、**50**(785.3s)、
  半径 **200**(708.5s)、弦长 **1000**(797.8s),
  以及 D 级的 DIMANGULAR **60 / 120**(456.0s / 527.5s)。
  这些**一个都没被脚本采用**;脚本落地的三段弧(夹角 229 / 70 / 142)
  是终态画布上讲师徒手画的另外三段,与上述演示弧不是同一批实体
  (演示弧在 542–561s 被 `_.erase 找到 12 个` 清掉了)。
  这属于"**证据取舍**"而非编造,但意味着本课的证据等级停在 **M** 而不是 C。

## 做不到的部分

1. **绝对尺寸未知**:终态画布无任何标注,采用"1 像素 = 1 图形单位"约定,
   只保证形状与相对比例,**不声称绝对尺寸等值**。
2. 434–800s 演示的 6 种圆弧给法,只在文档里记录,**脚本未逐一复刻**
   (落地的 3 段一律用 `_C 圆心 + 起点 + _A 夹角` 这一种给法)。
3. `DIMANGULAR` 标注实体未落地,`verify.json` 里没有 DIMENSION。
