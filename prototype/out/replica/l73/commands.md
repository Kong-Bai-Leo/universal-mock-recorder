## 二、剔除清单

**视频里画出来的每一个图元最后都被取消了**:
矩形(92.2s)、垂直构造线(528.2s)、水平构造线(531.5s)、直线(715.4s)、

外加 20+ 次空窗选 `*取消*`。

## 三、构造方式

本课的成品 `l73.dwg` 是一份**样板文件**:主体价值在**图层表 + 线型 + 系统变量**,
而不是图形。脚本建了 5 个图层并画了 3 个"验证用"图元:

| 图层 | 颜色 | 线型 | 线宽 |
|---|---|---|---|
| 粗实线 | 7(白) | Continuous | 0.35 |
| 细实线 | 7(白) | Continuous | 0.15 |
| 虚线 | 4(青) | ACAD_ISO02W100 | (默认) |
| 标注 | 3(绿) | Continuous | 0.15 |
| 中心线 | 6(洋红) | CENTER | 0.15 |

三个图元:虚线层的水平线 `(0,0)–(400,0)`、中心线层的竖线 `(200,−150)–(200,150)`、
粗实线层的矩形 `(0,−100)–(100,−40)` —— **纯粹是为了让每个图层上至少有一个实体、
使线型/线宽在 DWG 里可见**。

## 四、验证(verify.json 回读)

```
LINE       2   (0,0)-(400,0) / (200,-150)-(200,150)
LWPOLYLINE 1   (0,-100)-(100,-40)
```
DWG 里图层表含上述 5 个图层,`ACAD_ISO02W100` 与 `CENTER` 两种线型已加载。

## 六、做不到的部分 / 数值找不到出处

1. **⚠ 整张图层表(5 个图层 × 4 个属性 = 20 个值)全部没有出处。**
   本课的图层是在**图层特性管理器对话框**里建的,`-LAYER` 命令行版**一次都没用过**,
   59 条条带里**没有出现过任何图层名、颜色号、线型名或线宽**。
   本课也**没有 `dlg\` 对话框裁图目录**(不像课时55/56),所以连 D 级回读都做不到。
   「粗实线 / 细实线 / 虚线 / 标注 / 中心线」这套命名和
   「7 / 7 / 4 / 3 / 6」「0.35 / 0.15」「ACAD_ISO02W100 / CENTER」这些值
   **是按机械制图通用样板惯例填的,不是从视频里读出来的**。
   → **这是本课最严重的 A6 缺口。要补证据,只能重跑一次带 `--dlg` 的 CV 抽帧,
     或直接从视频 316–360s(图层管理器停留时段)抽帧回读。**
2. **「选项」对话框改了什么完全无证据。** 8 次 `OP`,命令行只有 `OPTIONS 正在重生成模型。`。
   脚本没有设任何 OPTIONS 相关的系统变量(不像课时4 那样有对话框裁图可读)。
3. **「草图设置」(`DSETTINGS`,4 次)改了什么同样无证据** —— 捕捉间距、极轴角、
   对象捕捉勾选项一个都没回显,脚本没有设 SNAPUNIT / POLARANG / OSMODE。
4. **三个图元的坐标全部是编的。** 视频里画的矩形、两条构造线、一条直线**统统被取消**,
   终态图纸上是空的。脚本画这 3 个图元只是为了让图层可见,**属于对忠实性的主动偏离**,
   在此明确记录。
5. **`LTSCALE 1` 无出处** —— 视频没有回显过线型比例。
6. **样板的另存格式无法确定。** 366.4 / 934.9s 的 `_SAVEAS` 下拉里能看到 DXF 各版本,
   但讲师最终选的是 `.dwt` 还是某个 `.dxf`、存到哪里,**没有回显**。
   脚本按流水线约定存成 `2018 DWG` + `DXF 16`。
