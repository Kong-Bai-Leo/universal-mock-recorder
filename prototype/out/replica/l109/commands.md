# 课时109 高脚杯制作1 —— 命令流

蒙太奇覆盖: 12/12 去重条带图 (=239/239 条带, 100%)

## 关键发现
本课的高脚杯**不是用 REVOLVE 做的, 是用 LOFT(放样) 做的**。
前半段先用 LINE 画轮廓线并 JOIN, 试图 EXTRUDE(被取消并 ERASE),
后半段改为「画若干圆截面 → 调整 Z 高度 → LOFT」。

## 命令序列
BOX(*取消*) → LINE ×3(杯体轮廓) → JOIN(3 个对象 → 1 条多段线) →
EXTRUDE(*取消*) → ERASE → (换工作空间, 命令行位置改变) →
CIRCLE 半径 80 → CIRCLE 半径 15 → 夹点拉伸/移动微调 →
CIRCLE 半径 80 → LOFT(2 个横截面, 模式 _SO, 仅横截面 C, 合并多条边 J)

## 数值证据
| 命令 | 参数 | 等级 | 出处 |
|---|---|---|---|
| CIRCLE | 半径 **80** | C | t≈591–599s 键入 |
| CIRCLE | 半径 <80.0000>: **15** | C | t≈632–639s 键入 |
| CIRCLE | 半径 <15.0000>: **80** | C | t≈778s 键入 |
| 夹点拉伸 | 距离 **5**, 然后 **3** | C | t≈669/676s 键入 |
| 夹点移动 | 距离 **5**, 然后 **2** | C | t≈799/808s 键入 |
| EXTRUDE | 高度提示默认 **<239.9686>** | C | t≈202s(= 上一次实际拉伸高度) |
| JOIN | 3 个对象 → 1 条多段线 | C | t≈200s 回显 |
| LOFT | 闭合轮廓创建模式 <实体> _SO | C | 选项回显 |

**圆心的 Z 高度全程靠鼠标拖拽**, 命令行无回显 → 杯口 z=360 / 杯脚 z=60
为占位值(L 级)。半径 80 与 15 是硬证据。

## 剔除
- t≈104s BOX *取消*;t≈208s EXTRUDE *取消*;t≈212s ERASE(清掉轮廓线)
- 多处右键菜单误触

## 复刻做法
1. LINE 三段轮廓 + PEDIT _M/_J 合并为 1 条多段线(还原 JOIN 3→1 的回显)
   —— 无头 AutoCAD 的 JOIN 首问是单选, 按坑表改用 PEDIT。
2. CIRCLE r=80 (杯口) 与 CIRCLE r=15 (杯脚) → LOFT 仅横截面 → 实体

## 做不到的部分
- 圆截面的 Z 高度无证据(占位)。
- 夹点拉伸/移动的 5/3/5/2 是「微调像素」性质, 无法定位到具体夹点, 未复刻。
