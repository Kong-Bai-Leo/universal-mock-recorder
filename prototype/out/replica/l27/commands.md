## 构造(每个图形怎么来的)

### A. 几何 —— M 级,**变换式可逐点复算**

**变换式:`世界坐标 = (px, 597 − py)`**(SOP 标准的 `--flipy 597`,**无缩放**)。
测量产物已留档:`geo.json`(t = **203s**,含 10 条线 / 1 个圆 / 2 段弧 / 1 个椭圆)、`geo_overlay.png`。

| 脚本 | `geo.json` 对应记录(屏幕像素) | 复算 |
|---|---|---|
| `_.CIRCLE 451.8,234.0 19.4` | circles `[451.8, 363.0, 19.4]` | 597 − 363.0 = **234.0** ✓,半径**原样** ✓ |
| `_.LINE 335,259 371,280` | lines `[335,338] - [371,317]` | 597−338 = **259**、597−317 = **280** ✓ |
| `_.LINE 372,279 380,253` | lines `[372,318] - [380,344]` | 597−318 = **279**、597−344 = **253** ✓ |
| `_.LINE 380,252 418,267` | lines `[380,345] - [418,330]` | 597−345 = **252**、597−330 = **267** ✓ |
| `_.LINE 337,219 357,234` | lines `[337,378] - [357,363]` | 597−378 = **219**、597−363 = **234** ✓ |
| `_.LINE 358,234 371,210` | lines `[358,363] - [371,387]` | 597−363 = **234**、597−387 = **210** ✓ |
| `_.LINE 371,211 403,230` | lines `[371,386] - [403,367]` | 597−386 = **211**、597−367 = **230** ✓ |

**`geo.json` 的 10 条线与脚本的 9 条 `_.LINE` 逐条对得上,坐标一位不差** ——
这是本课 M 级证据里最干净的一次。

### B. 镜像 / 复制动作 —— 选项 C 级、位置 L 级

| 脚本 | 参数出处 | 等级 |
|---|---|---|
| `_.MIRROR _ALL` + 镜像线 `649.2,80 → 649.2,350` + **`_N`** | **`_N`** ← 315.8s `<否>: N`;<br>**镜像线位置无出处** | C(选项)/ **L**(轴) |
| `_.COPY _W 300,160 600,300` + `451.8,234 → 853.8,380` | 206.4s `CO COPY 找到 9 个`;<br>**位移量无出处** | C(命令)/ **L**(位移) |
| `_.RECTANG 288.8,87 1046.8,318` | **无出处**(为最后一次镜像做背景框) | **L** |
| `_.MIRROR _C 454,256 492,284` + 同一镜像线 + **`_Y`** | **`_Y`** ← 270.2s `<否>: Y` | C(选项)/ **L**(轴) |

**镜像线 `x = 649.2` 的来历**:它是**左图形组与其镜像的中垂线** ——
`451.8`(圆心)与 `846.6`(镜像后的圆心)的中点正是 **649.2**。
换句话说,**它不是量出来的,是先定的**;
但视频 385.0s 有 `<正交 开>` 回显,证明**镜像线确实是竖直的**(C 级),
脚本的竖直轴与之一致,只有**横坐标**属布局。

**工程设置**:`PICKBOX 8` / `APERTURE 50` / 两处 `_.ZOOM _W` —— SOP 坑表要求的回放脚手架。

## 验证(verify.json)

```
l27.dxf  counts = { LINE: 27, LWPOLYLINE: 4, CIRCLE: 3 }
CIRCLE = c(451.8, 234.0) r 19.4      ← 原件
         c(846.6, 234.0) r 19.4      ← 镜像件
         c(853.8, 380.0) r 19.4      ← 复制件
```

**实体计数与坐标的三重自校验,全部通过:**

**1. 数量守恒**
脚本画了 **9 条线 + 1 个矩形 + 1 个圆 = 11 个**实体。

| 步骤 | 效果 | 累计 |
|---|---|---|
| 画图 | 9 LINE + 1 LWPOLYLINE + 1 CIRCLE | 11 |
| `_.MIRROR _ALL … **_N**`(保留源) | **翻倍** | 22 |
| `_.COPY`(窗选原件 11 个) | **+11** | 33 |
| `_.RECTANG`(背景框) | +1 LWPOLYLINE | 34 |
| `_.MIRROR _C … **_Y**`(删除源) | **数量不变**(等价于移动) | **34** |

DXF 实测 `27 + 4 + 3 = **34**` ✓,且分类也对上:
`LINE 27 = 9 × 3`(原件 / 镜像件 / 复制件)、
`LWPOLYLINE 4 = 1 × 3 + 1 背景框`、`CIRCLE 3 = 1 × 3` ✓

**2. 镜像坐标逐位对上**
镜像线 `x = 649.2`,原圆心 `x = 451.8` → 镜像后应为 `2 × 649.2 − 451.8 = **846.6**`。
DXF 实测第二个圆心 **846.6** ✓,且 `y` 保持 **234.0** 不变(竖直轴镜像的必要条件)✓

**3. `_Y` 与 `_N` 的差异被数量证明**
若最后一次镜像也答 `_N`,实体数会变成 35;实测 34,说明 **`_Y` 确实删除了源对象** ✓
反过来,第一次镜像答 `_N` 才让数量翻倍(11 → 22),
**两种应答的行为差异被同一份 DXF 同时证明** —— 这是本课最有力的一条。

**本课无尺寸标注实体**,无标注回读值。

## ⚠ 数值出处核对 —— 关键发现

### 发现 1:**本课命令行里一个几何数值都没有**

这是与前几课本质不同的一点。逐张核对 6 张蒙太奇后确认:

- `CIRCLE 指定圆的半径或 [直径(D)]:`(99.8s)—— **连默认值 `<…>` 都没有回显**;
- `RECTANG`、`LINE`、`PLINE` 全程鼠标拾取,**没有一次键入坐标或长度**;
- 唯一带数字的回显是**选择计数**(`找到 1/2/9/14 个`)和
  **动态输入框里的图纸绝对坐标**(176.6s `12568.5743 / 12681.6754`,与本课几何无关)。

**因此本课在原理上拿不到任何 C 级几何证据**,只能做到 M 级 ——
而 M 级这一块**做得是合格的**:`geo.json` 留档、变换式 `(px, 597 − py)` 无缩放、
本次已把 9 条线 + 1 个圆**逐点复算核对通过**。

### 发现 2:4 处布局值无出处(影响可控)

| 脚本值 | 说明 |
|---|---|
| **镜像线 `649.2,80 → 649.2,350`** | 横坐标 649.2 是**先定的**(它使镜像件不与源件重叠),不是量出来的。<br>**但竖直方向有 C 级支撑**:385.0s 的 `<正交 开>` 证明讲师的镜像线是正交的。<br>**影响:低** —— 镜像的正确性由"镜像件坐标 = 2×轴 − 源坐标"这条恒等式保证,与轴放在哪无关。 |
| **COPY 位移 `451.8,234 → 853.8,380`** | 无出处,纯排版。**影响:低**。 |
| **背景矩形 `288.8,87 → 1046.8,318`** | 无出处;它在视频里也没有对应物,是**为了让最后一次 `_.MIRROR _C` 的窗选有个可视边界而补的**。<br>**影响:中** —— 它是脚本自行添加的实体,视频里并不存在。 |
| **矩形 `458,280 → 488,259`** | `geo.json` 里没有直接的矩形记录(只有 2 段弧 + 1 个椭圆),<br>本次**未能把它复算回测量记录**。**影响:低**。 |

### 结论

**没有发现"伪造关键参数"** —— 本课的关键参数只有 `_Y` / `_N` 两个选项,两者都是 C 级,
且被 DXF 的实体计数硬性证明。
无出处的是**布局位置**,其中**背景矩形是脚本自行添加的、视频里没有**,
这一条应当在脚本头注里写明(目前 `l27.scr` 无任何注释)。

## 做不到的部分

1. **本课拿不到任何 C 级几何证据**(见发现 1),全部几何最高只能是 M 级。
2. **镜像线的真实位置不可知** —— 讲师用鼠标点两点,命令行只回显提示;
   脚本的 `x = 649.2` 是自定的(仅"竖直"这一点有 `<正交 开>` 支撑)。
3. **`_.RECTANG 288.8,87 1046.8,318` 是脚本自行添加的背景框,视频里不存在** ——
   它的作用是给最后一次 `_.MIRROR _C` 的交叉窗选提供可靠的拾取范围
   (SOP 坑表:「编辑类命令点选失败 —— 先 ZOOM _W 覆盖全部图元」)。
4. **`MIRRTEXT` 系统变量未演示** —— 镜像文字是否翻转是本命令的常见考点,
   但视频里没有文字对象、也没有出现 `MIRRTEXT`,**不编造**。
5. **矩形 `458,280 → 488,259` 未能复算回 `geo.json`** ——
   `measure.py` 在该处检出的是 2 段弧 + 1 个椭圆(圆角/干扰),不是矩形轮廓;
   它的尺寸只能算"目视对齐",严格说低于本课其余实体的 M 级。
