## 构造

`l15.scr` 造了 **3 个等大矩形 + 3 个 SOLID 填充**:

```
_.RECTANG 0,0 140,100 / 160,0 300,100 / 320,0 460,100
_.ZOOM _W -60,-60 520,160
_.-HATCH _P _S 70,50 / 230,50 / 390,50
```

- 3 个矩形边界:**L(布局)**,140×100、间距 20 —— 命令行无出处。
- `_P _S`(SOLID)是**刻意的降级**,理由见下。

## ⚠ 数值出处核对 —— 发现

### 发现 1:渐变色参数**全部无证据**,且**没有落地**
本课的课题是渐变填充,但:

- **AutoCAD 无头版没有 `-GRADIENT` 命令**;`-HATCH _P _G` 之后仍有交互提示会挂死
  (SOP 坑表已列)。因此脚本**降级成了 SOLID 实心填充**,
  `verify.json` 回读的 `_SOLID` 证实了这一点。
- 渐变的**颜色 1 / 颜色 2 / 单色-双色 / 明暗度 / 渐变图案(线形·球形·抛物线等)
  / 角度 / 居中**这些参数全部在对话框里设,命令行**一个都不回显**;
  `cv/slices/` 为空(probe 用 `--no-slices`),**没有对话框截图留档**。
- 唯一沾边的是 660.0s 画面上闪过的**角度下拉列表 `300 / 315 / 330 / 345`**,
  这是 D 级线索,但**看不到讲师最终选了哪一个**。

**结论:本课"渐变"这一核心内容既没有证据、也没有落地,只做到了"填了个实心色块"。**
这在报告里必须写明,不能算复刻成功。

### 发现 2:★ 反向补证 —— 课时13 的 AR-CONC / 比例 1 / 角度 0 找到了 C 级出处
本课 **49.9s / 52.3s** 的
`继承特性: 名称 <**AR-CONC**>, 比例 <**1**>, 角度 <**0**>`
是命令行回显,而本课打开的正是同一套练习图(`2.11练习`)。
它**确认了上一节留在图上的填充就是 AR-CONC、比例 1、角度 0** ——
即 `l13.scr` 里 `_.-HATCH _P AR-CONC 1 0` 这一条**有跨集 C 级证据**。
(`ANSI31` 与 `NET 4` 仍无出处 —— 见 `l13/commands.md`。)

### 发现 3:边界坐标是布局值
`0,0 140,100` / `160,0 300,100` / `320,0 460,100` 与课时14 用的是同一套布局,
**命令行无出处,也没做像素测量**,属 L 级;视频里是徒手不规则边界。

### 发现 4:实体数量对不上(6 vs 18)
851.5s `COPY 找到 **18** 个` 说明终态画布有 18 个实体;
成品只有 **6** 个(3 矩形 + 3 填充),复刻覆盖率约 **1/3**。
