### 自校验:梯形

三条边长 138.49(下底)、97.27(上底)、82.44(斜腰)由命令行独立给出。
把梯形设为等腰以外的一般梯形,斜腰与下底的夹角由**闭合方程唯一确定**:

```
cos θ = (97.27 − 138.49) / 82.44 = −41.22 / 82.44 = −0.50000
θ = 120.000°                      ← 脚本的 @82.44<120
高 = 82.44 × sin120° = 71.3951    ← 脚本的 y = 71.3951
```
角度和高**不是猜的,是三条 C 级边长解出来的**;且与 656.8s 的 `标注文字 = 90`
(另一侧为直角)自洽。

### 自校验:足球

`DIMDIAMETER 标注文字 = 647.21` → 外圆半径 **323.605**。
正五边形的外接圆半径 R 与其"次级同心圆"呈黄金比:
```
323.6068 = 100 × 3.236068 = 100 × 2φ      (φ = 1.618034)
123.6068 = 100 × 1.236068
```
脚本取基准五边形外接圆半径 **100**,外圆 **323.6068**(直径 **647.2136**,
与回读的 647.21 差 0.0036,在 DIMDEC=2 的显示精度内)。
**即:100 这个基准值是由 C 级的 647.21 反推出来的,不是拍脑袋定的。**

## 五、验证(verify.json 回读)

```
LINE       4    梯形四条边
                (0,0)-(138.49,0) / (138.49,0)-(97.27,71.3951)
                (97.27,71.3951)-(0,71.3951) / (0,71.3951)-(0,0)
```

## 七、做不到的部分 / 数值找不到出处

1. **⚠ 视频里 `POLYGON` 演示了近 20 次,一次都没走完(全部 `*取消*`)。**
   843.1–899.8s 只留下 `输入侧面数 <5>`、`[边(E)]`、`[内接于圆(I)/外切于圆(C)] <C>`
   这些**提示文字**,**从未键入过半径或边长**。所以:
   - 边数 5 是 C(默认值 `<5>` 回显);
   - **两个五边形的半径 100 / 123.6068 没有直接回读**,是由 647.21 + 黄金比反推的。
2. **⚠ 环形阵列的参数完全没有出处。** 我读的 14 张蒙太奇里**没有出现过 `ARRAY` / `-ARRAY`**;
   脚本的 `5` 项、`360` 度、`_Y`(旋转对象)是按"五边形足球"这一几何常识定的。
   → 阵列参数应标 L,不是 C。
3. **梯形和足球的绝对位置无出处**(0,0 与 700,200 是布局值)。
4. **文字样式 `5.瘦黑体2.5`(547.4s,C 级)和 `MTEXT` 未落到脚本** —— 视频里 MTEXT 被取消,
   但样式名是硬证据,成品里没有任何文字实体。
5. **命名视图「梯形案例」(671.3s)未复刻** —— 无头环境不建命名视图。
6. **`CANNOSCALE 1:40 → 1:1`(315.5s,C 级)未落到脚本** —— 注释比例不影响几何。
7. **图框/标题栏(517.6s「绘图范围」块、613.2s「A4-1:2 / 2023-09-21」、
   678.9s「喜来登装饰 / 王二小 / 小猪佩奇01」)未复刻** ——
   这些是与课时83 共用的图框块,本课只是引用,复刻件不含图框。
8. **`SCALE 100` 被 `_u` 撤销、`SCALE .01` 缩回**,净效果为 1,脚本不复刻。
9. **`_pasteclip` 失败**(找不到 OLE 对象),无头环境同样不支持,不复刻。
