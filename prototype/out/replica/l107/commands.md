# 课时107 放样工具 —— 命令流

蒙太奇覆盖: 19/31 (61%)

## 命令序列
CIRCLE / RECTANG / ELLIPSE / PLINE(横截面) → LOFT(2 个 / 3 个横截面) →
选项 导向(G) / 路径(P) / 仅横截面(C) / 设置(S) → COPY(阵列 5) → ERASE

## 教学要点(错误回显)
- 「至少必须选择两个轮廓」
- 「横截面曲线必须全部打开或全部闭合」
- 「Error 114051 选定的图元无效」
- 「当前线框密度: ISOLINES=4,闭合轮廓创建模式 = 实体」
