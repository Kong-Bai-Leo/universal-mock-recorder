# 课时116 布尔运算 —— 命令流

蒙太奇覆盖: 16/26 去重条带图 (≈62%, 覆盖了全部有回显的时段)

## 命令序列
BOX ×2 → COPY → **UNION**(找到 2 个 / 3 个) → **SUBTRACT** → **INTERSECT** →
CIRCLE / RECTANG / ARC / XLINE / TRIM / REGION → EXTRUDE → MOVE → VSCURRENT _X(X 射线)

## 数值证据
| 命令 | 参数 | 等级 | 出处 |
|---|---|---|---|
| UNION | 选择对象: 找到 **2 个** / 找到 **3 个** | C | 回显 |
| EXTRUDE | 高度提示默认 **<49.1233>** | C | 提示回显 |
| CIRCLE | 半径提示默认 **<22.6206>** / **<513.5575>** | C | 提示回显 |
| 报错 | 「至少必须选择 2 个实体、曲面或共面的面域」 | C | 回显 |
| VSCURRENT | 选项 X 射线(X) | C | 选项回显 |

**本课全部长方体都是鼠标拖出来的, 命令行零尺寸回显** → BOX 的 200×200×200
与相互偏移 100 全部是占位值(L 级)。

## 剔除
- 多次 *取消*;UNION 少选一个对象时的报错
- VSCURRENT 视觉样式切换(无头环境无显示, 未纳入脚本)

## 复刻做法
三对相同的长方体(200×200×200, 对角偏移 100,100), 分别做:
1. **UNION** 2. **SUBTRACT** 3. **INTERSECT**
—— 三种布尔的结果体积互不相同, 可互相印证。

## 验证(MASSPROP, 与解析式零误差)
| 运算 | 体积 | 解析值 | 误差 |
|---|---|---|---|
| UNION | 14000000.0000 | 8e6+8e6−2e6 | **0** |
| SUBTRACT | 6000000.0000 | 8e6−2e6 | **0** |
| INTERSECT | 2000000.0000 | 100·100·200 | **0** |
