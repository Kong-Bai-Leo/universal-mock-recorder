视频 913s / 202 条命令行条带 / 13 张蒙太奇。
**蒙太奇覆盖:12/13 = 92%**(读 m01–m12;m00 是开场无命令时段)。

## 一、命令序列

`ERASE 找到 19 个`(清上一课残留) → `ATTDEF`(反复起停) → `COPY` / `MOVE`(多次取消) →
`BLOCK 找到 2 个` → `EATTEDIT`(增强属性编辑器) → **`QLEADER` 打三行说明文字** →
`TEXTEDIT` → `BLOCK 找到 3 个` → `-INSERT` → 快捷特性面板查块 → `RECTANG`(取消) →
`BLOCK 找到 2 个 / 3 个` → `TEXTEDIT`

## 三、块与属性证据(等级 D —— 749.3s 快捷特性面板)

749.3s 选中插入的块后,快捷特性面板完整可读:

```
图层    0
名称    窗户参数          ← 块名
旋转    0
窗台高度：900…            ← 属性行 1(被截断)
窗台：900MM               ← 属性行 2
```

由此确证:
- **块名 = 「窗户参数」**(D);
- 块的**图层 = 0**、**旋转 = 0**(D,与 `-INSERT … 1 1 0` 一致);
- 属性值形如 **`900MM`**(带 MM 后缀)—— 脚本三个属性默认值 `1500MM / 900MM / 600MM` 的
  格式由此确证。

## 五、构造方式

1. **三行说明文字**:视频里是用 `QLEADER` 打出来的(433.4 / 442.6 / 458.4s),
   脚本改用三条 `TEXT`(`窗户高度：1500` / `窗台高度：900` / `窗梁高度：600`),
   文字**逐字一致**,但**实体类型从 LEADER+MTEXT 变成了 TEXT**(无头环境的替换)。
2. **窗户图例**:`RECTANG 200,0 260,6` + 中线 `LINE 200,3 260,3` —— 建筑制图里窗的常规画法。
   **尺寸 60×6 完全无出处**(视频里是鼠标拉的,见缺口 2)。
3. **三个属性定义**(`-ATTDEF`),标记/提示/默认值:

   | 标记 | 提示 | 默认值 |
   |---|---|---|
   | 窗户高度 | 窗高 | 1500MM |
   | 窗台高度 | 窗台高 | 900MM |
   | 窗梁高度 | 窗梁高 | 600MM |

4. `-BLOCK 窗户参数 …` 打包成块(块名来自 749.3s 面板)。
5. 两次 `-INSERT`,**属性值按倒序供给**(`600MM` / `900MM` / `1500MM`)——
   这是无头 `-BLOCK` 窗选打包后属性顺序反转的已知坑,已在 DXF 里回读复验。
   第二次插入把窗户高度改成 `2000MM`,演示"同一个块、不同参数"。

`-STYLE 黑体2.5 simhei.ttf 2.5 0.85 0` 是为让中文落进 DXF 而设的文字样式。

## 六、验证(verify.json 回读)

```
TEXT   3   "窗户高度：1500"@(0,60) / "窗台高度：900"@(0,50) / "窗梁高度：600"@(0,40)

```
三条 TEXT 的**字符串与视频命令行逐字一致**;6 个 ATTRIB 已回读确认中文编码正确。

## 八、做不到的部分 / 数值找不到出处

1. **⚠ 属性的「标记 / 提示」用词无法确证,且与画面证据可能相反。**
   视频用的是 `ATT` → **属性定义对话框**,标记/提示/默认值全在对话框里键入,
   命令行只打印 `ATTDEF 指定起点:`。202 条条带里**没有任何一次出现属性标记文字**。
   唯一的旁证是 749.3s 的快捷特性面板,它显示的是 **`窗台：900MM`**(标记像是「窗台」)
   和 **`窗台高度：900…`**;而脚本用的是 标记=`窗台高度`、提示=`窗台高`。
   两者对不上,**标记与提示很可能被写反了**。建议按面板改成 标记=`窗台`、提示=`窗台高度`,
   或明确降级为 L。
2. **窗户图例的尺寸(60 × 6)完全无出处。** 视频里 `RECTANG` 两次都被取消,
   真正画进块里的那个矩形没有任何尺寸回显。
3. **第二次插入的 `2000MM` 无出处。** 视频里演示"改属性值"用的是
   `EATTEDIT` 对话框(271.2s 起)和 `TEXTEDIT`,新值没有命令行回显。
   `2000MM` 只是"与 1500MM 不同"的示例值。
4. **全部插入点 / 属性定义点无出处**(200,-8 / 200,-14 / 200,-20 / 400,0 / 400,-60),纯布局值。
5. **实体类型偏离**:三行说明文字视频里是 `QLEADER`(LEADER + MTEXT),
   脚本用 `TEXT`;成品里因此没有 LEADER 实体。
6. `EATTEDIT` 拾取点 `8634.105166,331.174944` 是**上一课图纸坐标系**里的点,
   与本复刻件的坐标系无关,不能用作定位证据。
