## 构造

### 阶段 1 —— 靶子几何(M 级,变换式可复算)

**变换式:`世界坐标 = (px, 597 − py)`**(SOP 标准 `--flipy 597`,**无缩放**)。
测量产物:`geo.json`(t = **191s**,17 条线 / 2 个圆 / 10 段弧 / 1 个椭圆)、`geo_overlay.png`。

| 脚本 | `geo.json` 对应记录 | 复算 |
|---|---|---|
| `_.CIRCLE 372.6,188.4 50.6` | circles `[372.6, 408.6, 50.6]` | 597 − 408.6 = **188.4** ✓,半径原样 ✓ |
| `_.LINE 325,338 544,372` | lines `[544,225] - [325,259]` | 597 − 225 = **372**、597 − 259 = **338** ✓ |
| `_.PLINE 383,251 448,290 626,254 709,295` | lines `[448,307]-[626,343]`、`[626,342]-[709,302]`、`[448,308]-[383,346]` | 597 − 346 = **251**、597 − 307 = **290**、<br>597 − 343 = **254**、597 − 302 = **295** ✓ |
| `_.RECTANG 473,217 546,143` | 由弧/椭圆记录框定 | **M**(未逐点核对) |
| `_.ELLIPSE _C 698.6,168.5 790.9,135.1 41.3` | ellipses(1 个) | **M**(未逐点核对) |

### 阶段 2 —— 六次 SCALE(比例因子全部 C 级)

| # | 脚本 | 因子 | 出处 |
|---|---|---|---|
| 1 | `_.SCALE _C 315,130 435,250` + `372.6,188.4` + **`2`** | 2 | **160.3s `… : 2`** |
| 2 | `_.SCALE _P` + `372.6,188.4` + **`0.5`** | 0.5 | **177.1s `… : 0.5`** |
| 3 | `_.SCALE _P` + `372.6,188.4` + **`0.5`** | 0.5 | 235.7s `… : .5` |
| 4 | `_.SCALE _C 468,138 552,222` + `473,143` + **`100`** | 100 | **316.8s `… : 100`** |
| 5 | `_.SCALE _P` + `473,143` + **`0.1`** | 0.1 | **332.2s `.1`**(紧跟 `忽略极小的比例因子。`) |
| 6 | `_.SCALE _P` + `473,143` + **`0.1`** | 0.1 | 同上 |
| 7 | `_.SCALE _C … _C …` + `500,250` + **`2`** | 2 | 160.3s |

**因子 2 / 0.5 与 100 / 0.1 成对出现,是"放大后再缩回去"的对照演示** ——
`2 × 0.5 × 0.5 = 0.5`、`100 × 0.1 × 0.1 = 1`,与视频里讲师反复放大缩小的意图一致。

### 阶段 3 —— 参照(R)法(**全部 C 级,可解析验算**)

```
_.ERASE _ALL                                   ← 611.0s ERASE 找到 8 个
_.LINE 0,0 1000,0                              ← 618.2s LINE … : 1000
_.POLYGON 5 1900,300 _I 1900,674               ← 631.2s 侧面数 5;633.1s 内接于圆 I
_.SCALE _L / 1900,300 _R 1900,674 1544.3,415.6 1000   ← 695.5s 新的长度 = 1000
```

- **基点** = 正五边形中心 `(1900, 300)`;
- **参照长度** = 两点 `(1900, 674)` 与 `(1544.3, 415.6)` 之间的距离。
  这两点**正是五边形相邻的两个顶点**(内接半径 374,中心角 72°),
  即**参照长度 = 五边形的边长** `2 × 374 × sin36° = **439.65**`;
- **新长度 = 1000**(C 级),与旁边那条 C 级的 1000 长直线**等长**;
- 于是 **比例因子 = 1000 / 439.65 = 2.27452**。

> **这一段的设计意图很清楚**:用「参照法」把五边形的边长**精确缩放成 1000**,
> 再用旁边那条长 1000 的直线作为**目视标尺** —— 两个 1000 都是 C 级,
> 构成一个**自校验的演示**。

## 验证(verify.json)

```
l28.dxf  counts = { LINE: 1, LWPOLYLINE: 1 }
LINE = (0,0) - (1000,0)
LWPOLYLINE = 5 顶点闭合
   (1900, 1150.6746) (1090.9603, 562.8729) (1399.986, -388.2102)
   (2400.014, -388.2102) (2709.0397, 562.8729)
```

**三条自校验,全部通过:**

**1. `_.ERASE _ALL` 生效** —— 阶段 1、2 画的 5 个靶子全部消失,
DXF 里只剩阶段 3 的 2 个实体 ✓(对应视频 611.0s `ERASE 找到 8 个`)

**2. 直线长度 = 1000,逐位对上命令行** ——
DXF `LINE = (0,0)-(1000,0)`,与 618.2s 的 `LINE … : 1000` **一致** ✓
它没有被缩放(`_.SCALE _L` 只选中了最后创建的正多边形)✓

**3. 参照法的比例因子被顶点坐标逐位复验(本课最硬的一条)**

缩放前正五边形:中心 `(1900, 300)`、内接半径 **374**,
顶点 1 在正上方 `(1900, 674)`。

缩放后应有:顶点 1 = `(1900, 300 + 374 × 2.27452)` = `(1900, **1150.67**)`。

**DXF 实测顶点 1 = `(1900, 1150.6746)`** ✓ **小数点后 4 位全对**

再验边长:DXF 相邻顶点 `(1900, 1150.6746)` 与 `(1090.9603, 562.8729)` 之间的距离
= `√(809.04² + 587.80²)` = **1000.00** ✓
**—— 正是 695.5s 命令行里输入的那个「新的长度 1000」**,
而且与旁边那条 C 级的 1000 长直线**完全等长**,自校验闭合。

**本课无尺寸标注实体**,无标注回读值。

### 与视频的一处差异

`l28.scr` 里的 `_.SCALE _C …` 中的 **`_C` 是"交叉窗口选择"**,
而视频 385.4s 的 **`C` 是"复制"选项** —— **两者拼写相同、含义完全不同**。
本文档已在上表逐条区分;阅读脚本时须注意 `_C` 出现的位置
(在 `SCALE` 后面 = 选择方式;在 `指定比例因子` 提示后 = 复制选项)。

## 做不到的部分

1. **正五边形的原始大小(内接半径 374)无出处**(见上),本文档不为它背书。
2. **`复制(C)` 选项未复现**(见上),这是本课漏掉的一个知识点。
3. **`忽略极小的比例因子。` 这条失败回显未在脚本里复现** ——
   它出现的条件是"相对当前尺度过小",而脚本里 100 → 0.1 的那两步在
   无头环境下并没有触发同样的判定;**只记录、未执行**。
4. **矩形与椭圆未能逐点复算回 `geo.json`** ——
   `measure.py` 在该处检出的是弧/椭圆片段,本次只做了"目视对齐",
   严格说低于圆/直线/折线那三个实体的 M 级。
5. **讲师全程鼠标拾取基点** —— 脚本的基点是按测量到的图形算出来的
   (`372.6,188.4` = 圆心、`473,143` = 矩形角点、`1900,300` = 五边形中心),
   保证落在实体上(SOP 坑表要求),**不是视频里的真实点击位置**。
6. **缩放的视觉效果无法在无头环境比对** —— 只能靠 DXF 坐标做数值验证。
