## 构造(每个实体怎么来的)

`l17.scr` 共 13 个实体,全部为演示 XLINE / RAY 的**各种生成方式**:

| # | 脚本 | 数值出处 | 等级 |
|---|---|---|---|
| LINE 1 | `_.LINE 0,0 1000,0` | **长 1000** ← 198.7s `<正交 开> 1000` | **C** |
| LINE 2 | `_.LINE 2000,-2000 2000,-1800` | 长 200 的竖线,做「垂直/偏移」演示的靶子;<br>长度 200 与 532.3s `<200.0000>` 一致,**位置是布局** | C(长度)/ **L**(位置) |
| LINE 3 | `_.LINE 0,0 -669.1306,743.1448` | **长 1000、方位角 132°** ←<br>**601.9s `标注文字 = 132`**(角标注回读)<br>`1000·cos132° = −669.1306`,`1000·sin132° = 743.1448`(解析式) | **D**(角度)+ C(长度) |
| XLINE 1 | `_.XLINE _H 0,-1500` | 方式 ← 171.4s `H`;过点为布局 | C / L |
| XLINE 2 | `_.XLINE _V 2500,0` | 方式 ← 255.4s `V`;过点为布局 | C / L |
| XLINE 3 | `_.XLINE _A 45 2500,-1500` | **角度 45** ← 502.1s `输入构造线的角度 (0) …: 45` | **C** / L |
| XLINE 4 | `_.XLINE _A 120 3500,-1500` | **角度 120** ← 482.9s `… : 120` | **C** / L |
| XLINE 5 | `_.XLINE _A _R` + 拾取 `-267.6522,297.2579` + **`100`** + `4500,-1500` | **参照角 100** ← 397.9s `输入构造线的角度 <0>: 100`;<br>拾取点 = LINE 3 上 0.4 倍处(`0.4×(−669.1306, 743.1448)`),**落在实体上**(SOP 坑表要求) | **C** / L |

## 验证(verify.json)

```
l17.dxf  counts = { LINE: 3, XLINE: 8, DIMENSION: 1, RAY: 1 }
LINE = (0,0)-(1000,0) / (2000,-2000)-(2000,-1800) / (0,0)-(-669.1306,743.1448)
DIMENSION = { text: "<measured>", type: 34 }  (34 = 2 角度标注 + 32 块引用)
```

**标注回读值(D 级,直接从 DXF 取)**:

```
DIMENSION 组码 42(实测值) = 2.303834624954665 rad = 132.0000°
```

**与视频 601.9s 的 `标注文字 = 132` 逐位一致** —— 这是本课最硬的自校验:
LINE 3 的角度不是量出来的,而是**由标注回读值反解**得到,再由回放后的 DXF 标注**复现同一个 132**,闭环成立。

- 8 条 XLINE = `_H / _V / _A45 / _A120 / _A_R100 / _B / _O200 / _O5000`,逐条对应;
  DXF 里两条偏移构造线落在 `(0,200)` 与 `(0,5000)`,方向 `(1,0)`,
  正是 LINE 1(y=0)向 +Y 偏移 200 / 5000 的结果 ✓。
- 1 条 RAY 起点 (0,0)、通过 (707.1068,707.1068) = 45° ✓。

## 做不到的部分

1. **构造线的「过点」拿不到 C 级证据**:讲师全程鼠标拾取,`指定通过点:` 后无坐标回显
   (只有 81.1s / 161.0s / 565.0s / 642.7s 等处**动态输入框**里的屏幕坐标,
   如 `2675547.8916 / 293°`、`1825557.8935 / 1071926.0563`——
   那是当时的图纸坐标系与缩放下的瞬时值,与最终图形尺度无关,**不可用**)。
   因此所有过点按不重叠的原则布局(L 级),已在上表逐条标明。
2. **`HATCH` / `SPLINE` / `TRIM` / `COPY` / `OFFSET` / `EXPLODE` 的跑题演示未纳入** ——
   它们在视频里全部以 `*取消*` 结束,没有产生任何最终实体。
3. **两条平行线的角标注失败演示(585.6s `直线互相平行。`)未复现** ——
   它只输出一句报错,不产生实体;脚本里保留一条正常的 `DIMANGULAR` 已足以证明命令可用。
4. 视频 636.0s 的**第二个角标注(66°)未在脚本里落成 DIMENSION 实体** ——
   该角与 `_.XLINE _B` 生成的二等分线是同一个角,脚本用**构造线**而非**标注**表达它;
   若要严格复现,应再加一条 `_.DIMANGULAR` 标注 LINE 1 与二等分构造线的夹角。
