(读 m02、m04、m06、m08、m10、m12、m13、m14、m15、m16、m17、m18)。

99→100→101 家装三集的第一集,**三集共用同一套轴网**(总尺寸 13500 × 8430)。

> **重要背景**:本课与课时100 最初是按**像素测量**做成 14120 × 8560 的,

## 三、构造方式

本课只做**墙体轮廓**(不含门窗、标注、文字 —— 那是课时100/101 的内容):

```
PLINE 0,8430 → 11740,8430 → 11740,0 → 3540,0 → 3540,1450 → 0,1450 → 闭合   主体外墙(L 形)
OFFSET 200                                                                  外墙厚 200 (C)
PLINE 11940,0 → 13500,0 → 13500,4290 → 11940,4290 → 闭合                    右侧附属体
OFFSET 100                                                                  其墙厚 100 (C)
LINE  4560/4660、6460/6660(竖)、1700/1800(竖)、4650/4850(横)、5450/5550(横)  内隔墙
LINE  11740/11940(竖)                                                       主体与附属体之间
PLINE 0,6650 → -700,6650 → -700,7950 → 0,7950                               左侧凸出(阳台/入户)
```

其中 **4560**(538.6s 附近键入)、**1700 / 4650 / 4850 / 6460 / 6660 / 11740 / 1450 / 8430**
另有课时101 的 `BOUNDARY`+`LIST` 世界坐标佐证(见 `l101\commands.md`),
**13500 / 4290** 有课时100/101 的标注回读佐证。

## 四、验证(verify.json 回读)

```
LWPOLYLINE 5   主体外墙 + 其 OFFSET 200、附属体 + 其 OFFSET 100、左侧凸出
```

`标注文字 = 13500`(885.6s)、课时101 的 `标注文字 = 8430`(240.5s)一致。

## 六、做不到的部分 / 数值找不到出处

1. **⚠ 若干坐标仍无出处**:
   - **3540**(L 形的缺口宽);
   - **5450 / 5550**(卫生间隔墙的 y);
   - **左侧凸出体 (−700, 6650)–(0, 7950)** 的三个数(700 / 6650 / 7950)。
   这些在本课 12 张、课时100 的 18 张、课时101 的 18 张里都没找到直接回读,
   是按画面比例定的。
2. **⚠ 多个 C 级键入长度在成品里找不到对应几何**:
   **5280**(292.4s)、**950 / 1960**(440.2s)、**2600**(542.4s)、
   **500**(288.5s)、**380**(305.8s)、**1000**(638.9s)。
   它们要么属于被取消的试画,要么属于本课没做的门窗/家具。**值得回头核对**,
   尤其是 5280 和 2600 —— 量级上像是主要开间。
3. **本课视频里画的线几乎全部被取消**,终态图纸上留下的墙体是讲师**分多轮反复重画**的结果;
   脚本是"按已确证长度一次性重建"的等价件,不是逐笔重放。
4. **`SCALE .5`(205.4s)未复刻** —— 那是把参照底图缩小一半,与最终几何无关。
5. **`FILLET` 在本课二十余次全部取消**,`半径 = 0.0000` 只作为"当前设置"证据。
6. **本课没有任何标注、文字、门窗** —— 与视频一致(那是后两集的内容)。
7. **拾取点坐标全程无回显**,所有绝对位置靠长度链推算 + 课时101 的 LIST 坐标锚定。
