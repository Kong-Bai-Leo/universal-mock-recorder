## 剔除(视频里出现但不进入执行序列)

  **无任何坐标回显**,无头环境也无夹点,剔除。

  **但它的两个默认高度回显 387518.4927 / 884653.2154 被本文档用作图纸量级的旁证。**
- **`WSCURRENT` 工作空间切换**(65.3s):对话框,`*取消*`。

## 构造(每个实体怎么来的)

### HELIX 1 —— **全部参数 C 级**

```
_.HELIX 0,-8000000,0  1585866.4845  3043000  _T 30
29589750.0951
```

| 参数 | 值 | 出处 | 等级 |
|---|---|---|---|
| 底面半径 | **1585866.4845** | 168.0s / 239.0s `<1585866.4845>` 默认回显 | **C** |
| 顶面半径 | 3043000 | **未找到出处**(见下) | **✗** |
| 圈数 | **30** | 216.0s `输入圈数 <3.0000>: 30`;238.1s 状态行 `圈数 = 30.0000` | **C** |
| 螺旋高度 | **29589750.0951** | 255.8s `<29589750.0951>` 默认回显 | **C** |
| 底面中心 | (0, −8000000, 0) | 摆位 | **L** |

**内部自校验**:271.2s 的圈间距默认值 **986325.0032 × 30 圈 = 29589750.096**,
与螺旋高度 **29589750.0951** 在小数第 2 位吻合 —— 两个独立回显互相印证,
证明「高度 29589750.0951 + 圈数 30」这一组是视频里真实生效过的参数。

### HELIX 2 —— **全部参数 C 级(高度为 C 级推导)**

```
_.HELIX 14000000,-8000000,0  3491477.3412  3491477.3412  _W _CCW  _T 10
100000
```

| 参数 | 值 | 出处 | 等级 |
|---|---|---|---|
| 底面 / 顶面半径 | **3491477.3412** | 246.2s `指定顶面半径或 [直径(D)] <3491477.3412>` | **C** |
| 扭曲方向 | **CCW** | 307.7s `输入螺旋的扭曲方向 […] <CW>: CCW` | **C** |
| 圈数 | **10** | 321.6s `输入圈数 <30.0000>: 10` | **C** |
| 螺旋高度 | **100000** | **= 圈间距 10000(276.0s,C)× 圈数 10(321.6s,C)**<br>—— AutoCAD 的 HELIX 里"圈高 × 圈数 = 总高"是恒等式,<br>因此这是**由两个 C 级数值唯一解出**的值,不是推测 | **C(推导)** |
| 底面中心 | (14000000, −8000000, 0) | 摆位 | **L** |

## 验证(verify.json)

```
l21.dxf  counts = { POLYLINE: 1, VERTEX: 11, SEQEND: 1, HELIX: 2 }
```

- **`POLYLINE` + `VERTEX 11` + `SEQEND`** = 一条 11 顶点的三维多段线
  (`3DPOLY` 在 DXF 里落成旧式 `POLYLINE`,而非 `LWPOLYLINE` —— 这正是"三维"的标志)✓
- **`HELIX: 2`** = 两条螺旋线 ✓
- **本课无尺寸标注实体**,无标注回读值。
- 三维件本可用 `MASSPROP` 做硬校验(SOP 坑表),
  但 HELIX 是**曲线**不是实体,`MASSPROP` 不适用;3DPOLY 亦然。

## ⚠ 数值出处核对 —— 关键发现

### 结论:本课是**目前证据最扎实的一课之一** ——
### 8 个螺旋参数里 7 个有逐位对得上的命令行出处,但有 3 处仍无法追溯

**在 100% 覆盖率(10/10 张蒙太奇全读)下,以下数值在全片命令行里都没有出现过:**

| # | 脚本数值 | 位置 | 影响 |
|---|---|---|---|
| 1 | **`3043000`** | `_.HELIX … 1585866.4845 **3043000** _T 30` 的**顶面半径** | **中** —— 它决定螺旋 1 是不是锥形螺旋。<br>视频 168.0s 的提示是 `指定顶面半径或 [直径(D)] <1585866.4845>`,<br>**讲师输入了什么、还是直接回车接受默认,画面没有拍到**。<br>`3043000` 这个"整千"数字**不像默认回显**(本课所有回显都带 4 位小数),<br>更像**照着画面比例估的**,但**没有留下任何测量产物**。 |
| 2 | **`ISOLINES 16`** | 脚本第 3 行 | **低** —— 只影响三维曲面显示密度,不改变几何。<br>AutoCAD 默认是 4(课时19 的命令行里就是 `ISOLINES=4`),<br>写 16 **没有出处**。 |
| 3 | **`DELOBJ 0`** | 脚本第 4 行 | **低** —— 回放脚手架(防止源对象被删),非图形数据。 |

**建议(本次未改脚本)**:
- `3043000` 若无法找到出处,最保守的做法是**改回 `1585866.4845`**
  (= 接受 168.0s 的默认值,做成等半径圆柱螺旋),或者补一次像素测量并留档;
- `ISOLINES` 改回默认 4,或在头注写明"仅为显示,任取"。

### 被完整用上的高等级证据

与课时8 / 课时20 相反,本课**把命令行里的高等级证据几乎全用上了**:

- 默认值回显 `1585866.4845` / `3491477.3412` / `29589750.0951` / `986325.0032`
  —— SOP §2.5 点名的最硬通道,**四条全部落进脚本或用作校验**;
- 直接输入值 `30` / `10` / `10000` —— 全部落进脚本;
- 更难得的是 **986325.0032 × 30 = 29589750.096** 这条**闭合校验**,
  相当于尺寸链自校验,证明这组参数是视频里真实生效过的。

## 做不到的部分

1. **螺旋 1 的顶面半径 `3043000` 无法追溯**(见上),本文档不为它背书。
2. **3DPOLY 的 11 个顶点只能做到 M 级,且没有机器可读的测量产物** ——
   `frames/` 里只有标注过的 PNG(`poly1.png`、`cluster.png`),
   没有 `geo.json` 之类可复算的文件,因此**顶点坐标可对照、不可复算**。
3. **讲师全程鼠标连点,3DPOLY 一个坐标都没敲过** ——
   这条多段线在原理上**拿不到 C 级证据**。
4. **夹点移动(89.8–97.4s)、视觉样式、视图切换在无头环境不可复现**,已剔除。
5. **`BOX` 演示未纳入脚本** —— 讲师最后取消了,没有落地实体;
   它的两个高度回显只被本文档当作**量级旁证**使用。
6. **HELIX / 3DPOLY 都是曲线而非实体**,无法用 `MASSPROP` 做那种"零误差"级别的硬校验,
   验证只能停在实体计数与顶点数这一层。
