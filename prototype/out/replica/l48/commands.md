## 无头替换说明
`DIM` 在 accoreconsole 里进入的是旧版 `Dim:` 提示行(`Unknown command: _.DIM` /
`Type EXIT to return to COMMAND prompt`),**新版智能标注不可用**。
故按视频里 DIM 实际走到的分支,改用等价的独立命令:
DIMLINEAR / DIMALIGNED / DIMANGULAR / DIMBASELINE / DIMCONTINUE /
DIMORDINATE / DIMRADIUS / DIMDIAMETER / DIMARC / DIMJOGGED。
`分发(DIMSPACE)` 需要在无显示下点选已有标注,未复现。
