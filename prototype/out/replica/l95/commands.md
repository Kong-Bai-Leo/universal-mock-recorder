## 4. 本轮对脚本的修改(两个已知缺口都补上了)

**缺口 1:视图名用 ASCII 代替中文**

- 新增 `_.-STYLE CN / SimSun / 0 / 1 / 0 / _N / _N`
  (按 SOP 坑表:字体写 **`SimSun`** 不写 `simsun.ttc`;TTF 没有"垂直"一问,只答两个 `_N`)
- `_.-VIEW _S CASE1/CASE2/CASE3` → **`案例3` / `案例4` / `案例5`**,恢复端同步
- `.scr` 存为 **UTF-8 with BOM**;DXF 回读确认落地的是正确的 UTF-8:
  `'案例3' '案例4' '案例5' '名字' '比例大小' '日期' '王二小' '案例整理及打印'`

**缺口 2:未实际出图**

按 SOP 坑表"无头真正出图会挂死"的降级路径,加上完整的 `-PLOT` 详细配置应答链
(与课时 83/84 已验证过的链一致),把**页面设置写进 DWG**:

```
_.-PLOT / _Y / Layout1 / DWG To PDF.pc3 / ISO A4 (210.00 x 297.00 MM)
        / _M / _P / _N / _L / 1=1 / 0,0 / _Y / acad.ctb / _Y / _N / _N / _N
        / <l95-Layout1.pdf> / _Y(保存页面设置) / _N(不真正出图)
```

日志确认应答链**逐问对齐、零错位**:

```
Enter paper size or [?] <ANSI A (11.00 x 8.50 Inches)>: ISO A4 (210.00 x 297.00 MM)
Enter paper units [Inches/Millimeters] <Inches>: _M
Enter drawing orientation [Portrait/Landscape] <Landscape>: _P
Enter plot area [Display/Extents/Layout/View/Window] <Layout>: _L
Enter plot scale (Plotted Millimeters=Drawing Units) or [Fit] <1:1>: 1=1
Save changes to page setup [Yes/No]? <N> _Y
Proceed with plot [Yes/No] <Y>: _N
```

**其它修改**

- 图框由 `RECTANG 0,0 420,297`(自编的 A3 横版)改为 **`RECTANG 0,0 199.88,281.83`**
  —— 直接用视频 927.4s 回显的有效打印区域,A4 竖版,C 级
- 内框 `10,10 189.88,271.83`,标题栏框 `129.88,10 189.88,40`
- 标题栏三行中文 TEXT(名字 王二小 / 比例大小 A4-1:3 / 日期 2023-09-21),图名 `案例整理及打印`
- 三个视口比例按标题栏回读的三个比例分别设为 **1/5XP、1/3XP、1/8XP**(原来三个都是 1/3XP)

**排错记录**:第一次回放时前两个视口 `MSPACE` 报
`There are no active Model space viewports.`,`-VIEW _R` 跟着报
`There are no active Model space viewports in which to restore this view.`,
只有第三个视口成功。根因是**图纸空间当前视图没覆盖到新建视口**
(与 SOP 坑表里 `MVIEW _L _ON` 报 "Invalid window specification" 同源)。
在每个 `MVIEW` 前后各加一条 `_.ZOOM _W -6,-6 206,288` 后,三个视口全部激活。
本条建议补进坑表。

## 6. 做不到的部分

- **真正生成 PDF**:按 SOP 坑表,无头环境答完全部提示后真正出图会 540s 无输出挂死。
  本课按规定降级为 `Proceed with plot = _N`,**页面设置(设备 DWG To PDF.pc3、
  ISO A4、竖版、1:1、acad.ctb、输出文件名)已完整写入 DWG 的 Layout1**,
  在有界面的 AutoCAD 里直接"打印"即可出图。`l95-Layout1.pdf` **未生成**。
- **`COPYCLIP` / `PASTECLIP`**(601.9 / 702.2 / 785.3s 共 3 组):无头环境没有剪贴板,
  按 SOP 坑表不纳入。视频里讲师用它把标题栏从一张图粘到另一张。
- **`MTEXT`**(485–520s,3 次):无头版走就地编辑器会挂死,按坑表降级为 `TEXT`,
  且视频里这 3 次全部 *取消*,本身也不进入序列。文字样式 `"11.瘦黑体 注释性"` 是
  讲师模板里的自定义样式,本地没有,降级为 `SimSun`,**实体类型与字体都变了**。
- **注释性文字/注释比例**:`CANNOSCALE 1:30`(483.4s)与 "注释性 是" 未复现,
  脚本用固定字高 3.5 / 5 落地。
- **案例7 / 案例8**:视频后段还恢复了这两个命名视图(687.4s / 772.3s),
  但对应的图形不在本套复刻件里(属于别的课时),故只做 案例3/4/5 三个。
- 视频里 `正在打印视口 3。` 说明母版布局里至少有 3 个视口,与本脚本一致。
