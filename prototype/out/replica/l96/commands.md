## 四、构造方式

```
RECTANG 0,0 45085,8880          外墙轮廓,总长 45085 = C
OFFSET 100                       内墙线,墙厚 100 = C
10 组双线隔墙(每组两条竖线,间距 100),x 落在尺寸链的 10 个分界点上
DIMLINEAR + DIMCONTINUE          复现底部 11 段连续标注链 + 总长 45085
11 条 TEXT「商铺01」…「商铺11」  落在每间的形心
```
进深 **8880** 与文字位置 y=5505、字高 500 **没有出处**(见缺口 1)。

## 五、验证(verify.json 回读)

```
LWPOLYLINE 2   外墙 (0,0)-(45085,8880) + 内墙(OFFSET 100 生成)
LINE      20   10 组隔墙 × 2 条,x = 3022/3122 … 38186/38286(每组间隔正好 100)
DIMENSION 13   1 条 DIMLINEAR + 10 条 DIMCONTINUE + 总长 + 进深
TEXT      11   商铺01 … 商铺11
```
代回验证:
- 相邻隔墙外沿间距 = 3022 / 4175 / 2941 / 3041 / 3957 / 4221 / 3694 / 4357 / 4678 / 4100 / 6899
  —— 与 `z_chain.png` 的 11 段**逐段一致**;
- 总长 45085 ✓(761.8s 命令行);
- 每组双线间距 = 100 ✓(858.2s `OFFSET 100`);
- 商铺数 11 ✓(840.5s `WBLOCK 找到 11 个`)。

## 七、做不到的部分 / 数值找不到出处

1. **⚠ 进深 8880 没有出处。** 本课只有一条**横向**总长标注(45085)和一条纵向标注,
   但纵向那条的 `标注文字` 在读到的条带里**没有回显**。8880 是从终态画面按
   45085 的横向比例反推的(M 级)。三集共用轴网,**若课时97/98 的命令流里有进深回读,应以那边为准**。
2. **⚠ 313.9s 的 `DIST 距离 = 120` 与脚本的墙厚 100 不符。**
   858.2s 明确键入 `OFFSET … 100`,这是更晚、更可靠的证据,脚本取 100;
   但 120 这个 C 级读数在复刻件里**没有任何对应尺寸**,可能量的是别的构件(如柱边)。
3. **⚠ 「商铺01」…「商铺11」这套文字内容无出处。**
   画面上确实有红色中文标签(649.4s / 711.4s 的条带上缘能看到「商铺」「间铺」字样),
   但**没有一次命令行回显过文字内容**(讲师用的是 MTEXT 就地编辑器),
   编号格式和字高 500 都是构造的。
4. **11 段尺寸的具体数字来自视频画面的标注文字**,不是命令行。
   `z_chain.png` 是从终态帧放大截下的,几个数字(4175 / 3041 / 3694 / 4678 / 4100)
   在放大后仍有识别风险;**它们能被总长 45085 闭合校验,是可信的,但单段并非硬回读**。
5. **`WBLOCK 找到 11 个` 三次全部取消**,外部块没写成,脚本不复刻。
6. **`FILLET 半径 0`(865.0s)未落到脚本** —— 脚本用的是直角矩形,效果等价。
7. **所有拾取点、`_m2p` 中点捕捉的具体坐标都无回显**,隔墙的定位靠尺寸链推算。
