# 课时70 属性块编辑 —— 命令流与证据

视频 900s / 137 条命令行条带 / 9 张蒙太奇。
**蒙太奇覆盖:9/9 = 100%**。

## 一、命令序列

`ERASE 找到 2 个`(清场) → `ATTDEF`(反复,含**多行属性**) → `BLOCK 找到 1 个` →
**`EATTEDIT`(增强属性编辑器,全课主角,10+ 次)** → **`-ATTEDIT`(命令行版属性编辑)** →
`STYLE` 字体下拉(选**宋体**) → `BLOCK 找到 2 个 / 4 个` → `MOVE` / `COPY`(多数取消) →
`EXPLODE 找到 1 个` → `DRAWORDER _B` → `TEXTEDIT` → `EATTEDIT`(报错)

## 四、构造方式

本课与课时69 是同一份素材的延续,脚本重建同一个属性块并演示三种编辑:

1. 窗户图例 `RECTANG 0,0 60,6` + `LINE 0,3 60,3`(与 l69 一致)。
2. 三个 `-ATTDEF`(标记 窗户高度 / 窗台高度 / 窗梁高度,默认值 1500MM / 900MM / 600MM)。
3. `-BLOCK 窗户参数 0,0` 打包。
4. **三次 `-INSERT`**,分别给不同的窗户高度:`1500MM` / `2000MM` / `1800MM`
   —— 演示"同一个块、不同实例值"。属性值按倒序供给(无头 `-BLOCK` 的属性反转坑)。
5. **`-ATTEDIT _N _N 窗户参数 窗户高度 *`**,把 `1500MM` 全局替换成 `2100MM`
   —— 复现视频里 `-attedit` 的"否(N)= 一次编辑多个属性"分支。

`-STYLE 宋体2.5 SimSun` 来自 444.5s 的字体下拉高亮(D)。

## 五、验证(verify.json 回读)

```
INSERT 3
ATTRIB 9   (3 个块 × 3 个属性)
SEQEND 3
```
9 个 ATTRIB 已回读:三组的窗台/窗梁值都是 `900MM` / `600MM`,
窗户高度分别是 `2100MM`(被 -ATTEDIT 改过)/ `2000MM` / `1800MM`。

## 七、做不到的部分 / 数值找不到出处

1. **⚠ `-ATTEDIT` 在视频里五次全部被取消,没有一次跑完。** 命令行只留下第一问
   `是否一次编辑一个属性?[是(Y)/否(N)] <Y>:`,**后续的块名 / 标记 / 值过滤 / 新值全部没有回显**。
   脚本里 `_N _N 窗户参数 窗户高度 * / 1500MM / 2100MM` 这一整串,除了第一个 `_N`,
   **其余都是构造的**。真正做成的属性修改是用 **EATTEDIT 对话框**(235.2–353.3s、889.4s),
   而对话框里改了什么值**完全没有回显**。
2. **⚠ `2100MM` / `2000MM` / `1800MM` 三个值都没有出处。** 只有 l69 的
   `1500 / 900 / 600`(那里是 QLEADER 文字,C 级)可追溯;本课演示"改值"用的新值
   在 137 条条带里一次都没出现。
3. **块名「窗户参数」在本课命令流里没有出现**,是从课时69 的快捷特性面板(749.3s)继承的 D 级证据。
4. **属性标记/提示同样无命令行出处**(全部走 ATTDEF 对话框),与课时69 的缺口一致。
5. **窗户图例 60×6、三个插入点(0 / 150 / 300)全部无出处**,是布局值。
6. **视频演示的「多行属性」(101.3s `指定多行属性的位置`)未复刻** ——
   无头 `-ATTDEF` 没有多行模式,脚本只做单行属性。
7. **`DRAWORDER _B` 未落到脚本** —— 它只影响显示顺序,不改变几何,且 DXF 里无法验证。
8. 属性文字的**线宽**(318.7s 下拉列出 0.90/1.00/1.06/1.20/1.40mm)选了哪一项无法判定,脚本不设。
