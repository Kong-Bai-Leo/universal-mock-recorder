# 课时110 高脚杯制作2 —— 命令流

蒙太奇覆盖: 16/16 去重条带图 (=310/310 条带, 100%)

## 关键发现
本课把杯子做成 **LOFT 曲面(模式 MO → 曲面 SU)**, 再用 **THICKEN 厚度 5**
加厚成实体 —— 这是玻璃杯壁的正确做法, 也是本课唯一的硬数值。

## 命令序列
CIRCLE 半径 <80.0000> → CIRCLE 半径 15 → COPY → MIRROR → 夹点 MOVE →
LOFT(2 个横截面, 设置(S)) → LOFT 合并多条边(J) → LOFT 模式(MO) → 曲面(SU) →
ERASE → **THICKEN 厚度 5** → 多次 U(撤销)重做

## 数值证据
| 命令 | 参数 | 等级 | 出处 |
|---|---|---|---|
| THICKEN | 指定厚度 **5** | C | t≈922–943s 键入 |
| CIRCLE | 半径提示默认 **<80.0000>**, 本次输入 **15** | C | t≈70s |
| LOFT | 模式 [实体(SO)/曲面(SU)] → **_SU** | C | 选项回显 |
| LOFT | 合并多条边(J) | C | 选项回显 |
| 特性面板 | 直径/周长/面积 = *多种*(多选) | D | t≈202s(无具体数) |

## 剔除
- t≈493–506s 连续 U 撤销(整段重做)
- 若干次 *取消*

## 复刻做法
4 个同轴圆 (r=80 / 40 / 15 / 60) → `LOFT _MO _SU`(曲面) → `THICKEN 5` → 实体。
圆的半径 80/15 来自课时109 的键入证据; 40/60 与全部 Z 高度是占位值(L 级)。

## 做不到的部分
- Z 高度、中间截面半径无证据。
- COPY/MIRROR/夹点 MOVE 的具体位移无回显, 未复刻。
