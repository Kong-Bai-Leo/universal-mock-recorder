## 四、构造方式

**左件(4000×3000 组合框架)**
```
CIRCLE (±2000, ±1500) r=300     ← 300 = C;±2000/±1500 = C(OFFSET 2000 / 1500)
LINE   连接四个圆的切点(±1700 / ±1200 = 2000−300 / 1500−300)
ELLIPSE 长半轴 2000、短半轴 1000  ← 2000 = C;1000 无出处
CIRCLE (0,0) r=400              ← 400 = C
ARC  两段,包含角 90°            ← 90° = C(DIMANGULAR)
```

**右件(销轴 + 五角星 + 双头杆)**
```
CIRCLE (5000,0) r=375 / r=150   ← 375、150 = C
POLYGON 5 内接于 r=150 的圆      ← 5 边 + 内接 = C
CIRCLE (5000,1264) r=150        ← 150 = C;1264 无出处
两条斜杆到 (4852.4498,1289.9773) ← 无出处
水平杆 y=±75,端部 r=75 半圆      ← 75 = C(两次:OFFSET 75 + CIRCLE 75)
MIRROR 关于 x=5000 镜像          ← 无回显,按对称性推
```

## 七、做不到的部分 / 数值找不到出处

1. **⚠ 右件的一整组坐标没有出处。**
   - `CIRCLE 5000,**1264** 150` 的 **1264**;
   - 两条斜杆端点 `4852.4498,**1289.9773**` / `5147.5502,1289.9773`;
   - 水平杆的 `4122.05` / `4722.05`(以及镜像后的 5277.95 / 5877.95)。
   这些 x/y 在 338 条条带里**一次都没有回显**(讲师全靠对象捕捉拾取)。
   它们只有半径是 C 级,**位置全是按画面比例摆的**。
2. **⚠ 890.9s 的 `DIMLINEAR 标注文字 = 1210.04` 在复刻件里找不到对应尺寸。**
   脚本的三条水平/竖直线性标注量出来是 150 / 600 / 877.95,**没有 1210.04**。
   要么这条标注量的是视频里另一段(可能是斜杆的水平投影),要么右件的比例整体偏了。
   **这是右件唯一一个能用来校核整体尺寸的数,却对不上 —— 值得回头核对。**
3. **⚠ 784.3s 的 `OFFSET <882.9000>` 与脚本的 877.95 差 4.95。**
   `882.9` 是"上一次实际用过的偏移距离"(SOP 2.5 认可的 C 级通道),
   而脚本水平杆的半长是 5000 − 4122.05 = **877.95**。二者相近但不等,
   说明脚本这个值是画面测出来的,不是这条证据。**要么改用 882.9,要么标 L。**
4. **椭圆的短半轴 1000 没有出处。** 长半轴 2000 有 C 级(OFFSET 2000),短半轴是估的。
5. **`MIRROR` 的镜像轴没有回显**,按左右对称推定 x = 5000(L)。
6. **`FILLET` 在视频里六七次全部取消,一个圆角都没做成**;
   脚本也没做圆角(四角用的是整圆 + 切线),`半径 = 300.0000` 只作为"当前设置"证据保留。
7. **`CANNOSCALE 1:25`(534.2s)未落地**;`DIMSCALE 40` 无出处,为标注可读而设。
8. **`CUTCLIP` 在视频里被 `_u` 撤销两次**,不复刻(无头环境也没有剪贴板)。
9. **`XLINE` / `RECTANG` 在本课全部取消**,一个都没落地,与终态一致。
