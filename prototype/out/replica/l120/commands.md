# 课时120 三维修改工具 —— 命令流

蒙太奇覆盖: 8/15 去重条带图 (≈53%, **低于 60%**, 如实标注)

## 命令序列
BOX / RECTANG / MOVE →
**3DMOVE**(指定基点 → 指定移动点, 键入 **1000**) →
**3DROTATE**(UCS 当前的正角方向 ANGDIR=逆时针 ANGBASE=0;指定基点 →
拾取旋转轴(夹点小控件) → 指定旋转角度 [基点 B/复制 C/参照 R/退出 X]) →
**3DSCALE**(拾取比例轴或平面 → 指定比例因子 [复制 C/参照 R]) →
**MIRROR3D**(镜像平面 [对象 O/最近的 L/Z 轴 Z/视图 V/XY/YZ/ZX/三点 3] <三点>;
是否删除源对象 [是(Y)/否(N)] <否>) →
**MIRROR** → **3DALIGN**(源平面: 基点+第二点+第三点;目标平面: 三个目标点) →
SCALE / DSETTINGS / ORTHOMODE

## 剔除
- 大量 *取消*(3DROTATE/3DSCALE 反复进出而不确认)
- ORTHOMODE 切换

## 复刻做法与降级说明
1. BOX → **3DMOVE** 位移 **1000**(X 向) —— 原样复刻
2. BOX → **ROTATE3D _X 90°** —— **降级说明**: 视频用的是 `3DROTATE`,
   它靠三维夹点小控件拾取旋转轴, 无头 accoreconsole 无图形子系统无法拾取,
   改用等价的传统命令 `ROTATE3D`(轴由 X 轴 + 一点定义)。
3. BOX → **MIRROR3D _XY**(z=250 平面), 不删除源对象(N)
4. BOX → **MIRROR**(二维镜像), 不删除源对象(N)
5. BOX → **SCALE 比例因子 2** —— **降级说明**: 视频里 `3DSCALE` 同样是夹点控件驱动,
   改用视频后段实际也用到的 `SCALE`(t≈398s 有 `SC` 键入回显)。

## 做不到的部分
- 蒙太奇覆盖 53%, 低于规程 60%(节流取舍)。
- **3DROTATE / 3DSCALE 无法在无头环境执行**(依赖三维夹点小控件),
  已降级为 ROTATE3D / SCALE 并在上面写明。
- **3DALIGN 未纳入最终脚本**: 视频里的三组源/目标点全部是鼠标捕捉,
  没有任何坐标回显, 编造 6 个点等于编造证据(违反 R4), 故如实不做。
- BOX 尺寸 500³ 与各摆放位置为占位值(L 级);位移 1000、比例 2 有证据。
