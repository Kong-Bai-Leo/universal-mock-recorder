## 三、构造方式

一个「方板挖 U 形槽」的三维件:

```
XLINE _V 0,0 + OFFSET 25    →  x = ±25 的中心线(25 = C)
XLINE _H 0,0 + OFFSET 55    →  y = 55 的水平线(55 见缺口 1)
MIRROR                       →  对称
CIRCLE 0,55 25               →  顶部半圆(25 = C)
TRIM / ERASE                 →  裁掉多余
LINE ×3 + PEDIT _M _J        →  把 U 形轮廓合成一条闭合多段线(对应 589.4s 的 JOIN)
RECTANG -50,0 _D 100 100     →  100×100 外框(100 = C)
EXTRUDE _L 100               →  外框拉成 100×100×100 方块
EXTRUDE (U 形) 100           →  U 形拉成柱
SUBTRACT                     →  方块减 U 形柱
DIMLINEAR ×5 + DIMRADIUS ×1  →  25 / 100 / R25 三个 C 级尺寸各标一次
```

## 四、验证(MASSPROP 解析复核)

**体积可以完全解析算出,与实测零误差:**

```
外方块            100 × 100 × 100                      = 1 000 000.0000
U 形柱截面积      50 × 55(矩形)+ π·25²/2(半圆)
                 = 2750 + 981.747704                  =     3 731.747704
U 形柱体积        3731.747704 × 100                    =   373 174.7704
差集体积          1 000 000 − 373 174.7704             =   **626 825.2296**
```
与 `MASSPROP` 报出的 **626825.2296 逐位一致(零误差)**。

`verify.json` 回读:
```
3DSOLID    1
LWPOLYLINE 2   U 形轮廓 (-25,55)-(25,0) 闭合 + 外框 (-50,0)-(50,100)
DIMENSION  6   线性×5 + 半径×1
```

## 六、做不到的部分 / 数值找不到出处

1. **⚠ 三个数没有在本次覆盖的 20 张里找到出处**:
   - **`OFFSET 55`**(U 形槽的高度)—— 只找到 `OFFSET 25`;
   - **`EXTRUDE` 的高度 100** —— 630.2s 只回显了默认值 `<83.8786>`(上一次的拉伸高度),
     讲师键入的新值落在我跳过的条带里;
   - **`MASSPROP` 的原始回显**。
   前两个可由几何自洽性反推(55 使 U 形顶部半圆与直边相切于 y=55;
   拉伸 100 使方块成正立方体,且体积解析值 626825.2296 与已知实测值完全吻合),
   **属于 C 派生而非直接回读**。若要闭环,应补读 m01/m03/m23/m25/m27/m29。
2. **视频里 `FILLET` 五次全部取消并被 `_u` 撤销**,成品无圆角 —— 与视频终态一致。
3. **626.8s 的 `JOIN → 1 条样条曲线` 未复刻** —— 那是另一组对象的演示。
4. **`REFEDIT`(488.6s)取消**,不复刻。
5. **标注的尺寸线落点、`ZOOM` 窗口全部是布局值。**
6. **视频里 `DIMCONTINUE` 报 `尺寸界线原点不能相同。`(754.0s)失败**,
   脚本用一条 `DIMCONTINUE 25,0 50,0` 等价实现。
