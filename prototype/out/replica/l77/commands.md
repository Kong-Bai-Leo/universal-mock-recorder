# 课时77 绘制图框 —— 命令流与证据

视频 922s / 297 条命令行条带 / 19 张蒙太奇。
**蒙太奇覆盖:12/19 = 63%**(读 m01、m03、m05–m08、m10、m11、m13、m15、m17、m18;
跳过的 7 张是 0–80s 的 PPT 讲解段和 480–600 / 690–720 / 780–820s 的连续窗选取消段)。

**本课是全批 30 课里证据链最完整的一课**:整套 ISO 纸张尺寸由
`RECTANG` 的 `尺寸(D)` 分支**逐个键入**,而且每一步的 `<默认值>` 正好是上一步键入的值 ——
形成一条**自校验的尺寸链**。

### 自校验

每一次 `RECTANG _D` 的**默认值 = 上一次实际键入的值**(SOP 2.5 的「`<默认值>` 回显」通道):

```
键入 210×297   → 下一次默认 <297.0000> / <210.0000>   ✓
键入 420×297   → 下一次默认 <420.0000> / <297.0000>   ✓
键入 594×420   → 下一次默认 <594.0000> / <420.0000>   ✓
键入 841×594   → 下一次默认 <841.0000> / <594.0000>   ✓
键入 1189×841
```

链条首尾闭合,**五张纸的十个数字全部是 C 级硬证据,零推测**,
且与 ISO 216 标准值(A0 1189×841 / A1 841×594 / A2 594×420 / A3 420×297 / A4 297×210)完全吻合。

## 四、构造方式

脚本把**五张纸并排画出来**,每张都用视频里的 `RECTANG _D <长> <宽>` 原式构造:

```
A0  RECTANG 0,0    _D 1189 841  →  (0,0)-(1189,841)
A1  RECTANG 1249,0 _D 841  594  →  (1249,0)-(2090,594)
A2  RECTANG 2150,0 _D 594  420  →  (2150,0)-(2744,420)
A3  RECTANG 2804,0 _D 420  297  →  (2804,0)-(3224,297)
A4  RECTANG 3284,0 _D 297  210  →  (3284,0)-(3581,210)
```

再在 A3 上用 **`OFFSET 5`** 向内偏移一圈,得到 (2809,5)-(3219,292) 的内框
—— 这就是"图框"的做法,距离 5 来自 462.4s 的 C 级回显。

最后一个 `RECTANG 3104,20 _D 5 5` 是**5×5 的比例参照方块**(见缺口 3)。

各张纸之间的 60 单位间隔纯粹是排版(L)。

## 五、验证(verify.json 回读)

```
LWPOLYLINE 7
(0,0)-(1189,841)      A0  →  1189 × 841   ✓
(1249,0)-(2090,594)   A1  →   841 × 594   ✓
(2150,0)-(2744,420)   A2  →   594 × 420   ✓
(2804,0)-(3224,297)   A3  →   420 × 297   ✓
(3284,0)-(3581,210)   A4  →   297 × 210   ✓
(2809,5)-(3219,292)   A3 内框 → 四边均内缩 5 ✓
(3104,20)-(3109,25)   5×5 参照方块
```
五张纸的实测尺寸与命令行键入值**逐位一致**;内框四边内缩量 = 2809−2804 = 3224−3219
= 292−297 = 5−0 = **5**,与 `OFFSET 5` 一致。

## 七、做不到的部分 / 数值找不到出处

1. **视频里这五张纸最后都被取消/删掉了**,终态图纸是空的。
   脚本把它们全部保留下来是**主动偏离**——目的是让这条 ISO 尺寸链在成品里可验证。
2. **⚠ 文字样式 `10.建筑字体`(字高 1.5)有 C 级证据但没有落到脚本。**
   186.8s 和 631.9s 两次 `MTEXT` 都完整回显了这个样式名,虽然两次 MTEXT 本身都被取消,
   但**样式的存在是硬证据**。脚本里既没有建这个样式、也没有任何文字实体。
   若要更忠实,应补 `-STYLE 10.建筑字体 … 1.5`。
3. **⚠ `RECTANG 3104,20 _D 5 5` 这个 5×5 方块没有出处。** 它显然是照着 `OFFSET 5`
   的"5"造出来的比例参照物,但视频里**没有画过任何 5×5 的矩形**。建议删掉或标为示意。
4. **图框的标题栏、装订边、对中符号一概没做。** 视频后半段(600–900s)大量
   `MOVE` / `COPY 找到 3 个` / `MTEDIT` / `** 拉伸 **` 是在拼标题栏,
   但**这些操作的拾取点一个都没有回显**,无法复刻。本课成品只做到"五张纸 + 一圈内框"。
5. **五张纸的摆放位置和 60 的间隔是布局值**,视频里五张纸是先后画在同一处再删掉的。
6. **`XLINE h`(310.2s)两次都取消**,不复刻。
7. **`_pasteclip`(96.0s)不复刻** —— 无头环境没有剪贴板。
8. **599.7s 的 `<线宽 >` 状态切换具体值未回显**,脚本不设线宽。
9. **A4 在视频里是"长 210 宽 297"(竖放)**,而脚本按 297×210(横放)画,
   与 A3–A0 的横放方向统一。方向是排版选择,数值本身没变。
