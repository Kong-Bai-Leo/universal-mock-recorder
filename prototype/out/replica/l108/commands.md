# 课时108 放样工具类型 —— 命令流

蒙太奇覆盖: 29/29 去重条带图 (=570/570 条命令行条带, 100%)

## 命令序列 (按时间)
VIEW _top → RECTANG(*取消*) → VIEW _front → ELLIPSE → ZOOM _E →
**LOFT**(3 个横截面, 选项 [导向(G)/路径(P)/仅横截面(C)/设置(S)] <仅横截面>) →
COPY 阵列(A) 项目数 5(*取消*) → LOFT 模式(MO) → 曲面(SU)/实体(SO) →
LOFT 点(PO)(指定放样起点/端点) → LOFT 合并多条边(J) → LINE →
LOFT 设置(S) → LOFT 路径(P)(报错) → LOFT 导向(G)(报错) →
VIEW _top → **POLYGON 侧面数 5 内接于圆(I)** → LINE → TRIM → JOIN(10→2 多段线) →
BOUNDARY(创建 1 个多段线) → ERASE → VIEW _swiso → POINT/DDPTYPE →
LOFT(2 个横截面, 连续性(CO)/凸度幅值(B)) → VIEW _front → MIRROR(不删除源对象 N)

## 数值证据
| 命令 | 参数 | 等级 | 出处 |
|---|---|---|---|
| POLYGON | 输入侧面数 <4>: **5**, 内接于圆(I) | C | t≈520s 键入 |
| LOFT | 选项默认 <仅横截面> | C | 选项回显 |
| LOFT | 模式 [实体(SO)/曲面(SU)] <实体> | C | 选项回显 |
| MIRROR | 要删除源对象吗? [是(Y)/否(N)] <否>: N | C | t≈868s |
| COPY | 阵列(A) 项目数 = 5 / 4 | C | t≈148s(该次被取消) |

**本课全程没有键入任何尺寸**: 所有圆/椭圆/多边形的半径与截面间距都是鼠标拖拽,
命令行无回显、无标注、特性面板未打开 → 半径 100/60/30、间距 150、
多边形外接半径 80 等均为**无证据的占位值(L 级)**, 只保证命令与选项序列忠实。
