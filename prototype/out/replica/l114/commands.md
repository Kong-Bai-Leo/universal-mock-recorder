# 课时114 多段体命令(POLYSOLID) —— 命令流

蒙太奇覆盖: 21/21 去重条带图 (=406/406 条带, 100%)

## 命令序列
**POLYSOLID**(头部回显 高度 = 80.0000, 宽度 = 5.0000, 对正 = 居中) →
高度(H) **2800** → 宽度(W) **200** → 对正(J) 居中(C)/左对正(L)/右对正(R) →
对象(O) 模式(把 LINE/PLINE/CIRCLE/ARC/SPLINE 转成多段体) →
LINE 200 → JOIN(5 → 1 条多段线) → BOX 高度 **2800** / **900** / **700** →
DIST(距离 = 5.0000, XY 平面中的倾角 = 270) → IMAGEATTACH → SCALE **.01** / **.1** / 参照(R)

## 数值证据
| 命令 | 参数 | 等级 | 出处 |
|---|---|---|---|
| POLYSOLID | 默认 高度 **80.0000** 宽度 **5.0000** 对正 **居中** | C | 命令头部回显 |
| POLYSOLID | 高度(H) <80.0000>: **2800** | C | t≈127s 键入 |
| POLYSOLID | 宽度(W) <5.0000>: **200** | C | t≈215s 键入 |
| BOX | 高度 **2800** / **900** / **700** | C | 键入 |
| DIST | 距离 = **5.0000**, 倾角 = **270** | C | 回显(量的是默认墙宽 5) |
| SCALE | 比例因子 **.01**, **.1** | C | 键入 |
| JOIN | 5 个对象 → 1 条多段线 | C | 回显 |
| IMAGEATTACH | 图像尺寸 338.737 × 170.09436 mm | C | 回显 |

## 剔除
- POLYSOLID 对象(O) 报错「不能转换自交曲线」
- 若干 *取消*

## 复刻做法
1. POLYSOLID: 高度(H)=**2800**, 宽度(W)=**200**, 对正(J)=**居中(C)**,
   走 0,0 → 5000,0 → 5000,4000 → 0,4000 → 闭合 (矩形墙圈)
2. POLYSOLID 对象(O): 把一条 3000 长的 LINE 转成多段体(沿用 2800×200)
3. BOX 高度 **900**、BOX 高度 **700**
