## 三、构造方式

一个「圆锥台 + 球头 + 横梁 + 阶梯圆柱 + 立板」的组合三维件:

```
CIRCLE 100,0,100  r=100        下截面
CIRCLE 100,0,240  r=30         上截面(z=240 = C,r=30 = C)
LOFT _ALL _C                   圆锥台(2 个截面 = C)
CIRCLE 100,0,0    r=100  →  EXTRUDE 100     底盘(r=100 由 512.2s 默认值确证,高 100 = C)
SPHERE 100,0,240  30           球头(30 = C)
UNION _ALL
BOX  200,-25,50  300,25,70     横梁
CYLINDER 350,0,0   50  75      主轴(r=50 = C)
CYLINDER 350,0,35  30  40      凸台
BOX  325,-60,35  375,60,75     立板
UNION ×2  →  SUBTRACT
```

## 四、验证

`verify.json`:
```
3DSOLID 1
CIRCLE  3   c=(100,0,100) r=100 / c=(100,0,240) r=30 / c=(100,0,0) r=100
```
三个圆的**半径与 z 高度**全部与命令行一致:
r=100(512.2s 默认值)、r=30(336.0s SPHERE 半径)、z=240(263.0s 夹点拉伸)。

**包围盒复核**:成品的三维包围盒为 **400 × 200 × 270**
```
X: 0 … 400        = 底盘左缘(100−100=0) … 立板右缘(375)与主轴右缘(350+50=400)
Y: −60 … 60       = 立板 ±60,共 200
Z: 0 … 270        = 底面 0 … 球顶(240+30=270)
```
其中 **Z 上限 270 = 240 + 30**,由两个 C 级数(z=240、球半径 30)**解析闭合**;
**X 上限 400 = 350 + 50**,由主轴圆心 350 与 C 级半径 50 闭合。

## 六、做不到的部分 / 数值找不到出处

1. **⚠ 右半部分(横梁 / 凸台 / 立板 / 主轴高)的尺寸没有出处。**
   - 横梁 `200,-25,50 → 300,25,70`(100 × 50 × 20);
   - 主轴高 **75**;
   - 凸台 `CYLINDER 350,0,35 30 40`(r=30、h=40、z 起点 35);
   - 立板 `325,-60,35 → 375,60,75`(50 × 120 × 40)。
   这些在 12 张蒙太奇里**一个数都没有回显**,是按画面比例定的。
   唯一有 C 级的是主轴半径 **50**(513.6s)和圆心 x=350 所隐含的 X 上限 400。
2. **⚠ 两个 C 级数没有落到脚本**:
   - **`RECTANG _D … 宽度 85`**(579.8s)—— 脚本里没有任何 85;
   - **`FILLET 半径 10`**(593.8s)—— 脚本没有做任何圆角。
   两者在视频里都被 `*取消*`,但它们是本课**仅有的两个未被采用的键入值**,值得回头核对。
3. **`XEDGES`(162.2s,提取实体边)未复刻** —— 它只生成线框副本,不改变实体。
4. **`POINT` / `DDPTYPE` / `PTYPE` 演示未复刻**(与课时72 同一情形:`PDMODE=0 PDSIZE=0` 是
   唯一回显,点样式对话框里选了什么无证据)。
5. **`VSCURRENT` 视觉样式(真实 / X 射线 / 概念 …)和 `-VIEW _swiso` 未复刻** ——
   它们只影响显示,不进 DXF。
6. **`ISOLINES 16` 与视频的 `ISOLINES=4` 不一致** —— 脚本调高只为让线框可读,是主动偏离。
7. **全部布尔运算的拾取点无回显**,按几何位置推定。
8. **本课没有 `MASSPROP` 回显**(与课时123–125 不同),体积无法交叉验证;
   验收依据是包围盒 **400 × 200 × 270**,已如上闭合复核。
