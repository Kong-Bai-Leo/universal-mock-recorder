# 课时49 标注类型 —— 命令流与证据

> 本课是**证据最硬的一课**:每一次标注都在命令行吐出 `标注文字 = <值>`,
> 所有几何都能由这些回显**解析地反算出来**,几乎不需要像素测量。

## ⚠ 数值找不到出处(重点)

1. **矩形短边 `20`**(`_.LINE 4400,2380 4400,2400` 与 `4500,2380 4500,2400`):
   13 张蒙太奇里 **从未出现 `标注文字 = 20`**,也没有键入 20 的回显。
   全课与该矩形有关的回显只有两处 `= 100`。这个 20 目前**无出处**,只能视作 L 级(为了让矩形看起来像矩形)。
2. **小矩形左边 `x = 5560`**(即宽度 62.35):`DIMORDINATE` 只标了 `2476.31`、`2448.34`、`5622.35`
   三个坐标,**左边界的 X 从未被标注**。因此 62.35 这个宽度**无出处**,是 L 级。
   矩形高度 `2476.31 − 2448.34 = 27.97` 则是 C 级(两条坐标标注之差)。
3. **脚本顶部的 DIM 系统变量块**(`DIMTXT 2.5 / DIMASZ 2.5 / DIMEXE 1.25 / DIMEXO 0.625 / DIMDLI 3.75 /
   DIMGAP 0.625 / DIMDEC 2 / DIMZIN 8 / DIMTAD 1 / DIMTIH 0 / DIMTOH 0 / DIMATFIT 3 / DIMTMOVE 2 /
   DIMSCALE 1 / DIMAUNIT 0 / DIMADEC 0`):**这些是 AutoCAD ISO-25 样板的默认值,本课并未讲授或修改**
   (标注样式管理器是课时50–55 的内容)。它们不是编造,但**也不是本课的证据**,应标为"默认值"。
   其中两项**可由回显反证**:`标注文字 = 107.2`(而不是 107.20)与 `= 66`(而不是 66.00)
   证明 **DIMZIN = 8**(消除尾随零);`= 98.12` / `= 43.19` 证明 **DIMDEC = 2**。这两项是 C 级。
4. **513.6s 的 `<229.6296>`**:这是"上一次画圆的半径"的默认值回显,本课**没有采用**它,
   不应被当作本课的圆半径。成品的 55.76 来自 532.3s 的 `DIMRADIUS`。

## 做不到的部分

- **矩形短边 20 与小矩形宽 62.35 无证据**(见上),按 L 级摆放,不声称是原图尺寸。
- `DIM` 万能命令(315–335s)的各分支只做了选项漫游,未落地,不复现。
- 856–870s 的**夹点拖标注**导致 `标注已解除关联`,是反面演示,终态被取消,不复现。
- `DIMJOGGED` 的折弯位置、`DIMARC` 的引线位置在无头环境只能给近似拾取点,
  外观与视频不完全一致,但**标注值不受影响**(已由 verify 反算复核)。
