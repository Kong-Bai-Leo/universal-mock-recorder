# 课时76 建筑标注样板

## 证据
- **C** `DIMLINEAR 标注文字 = 3629`(799.5s)
- **C** `DIMDIAMETER 标注文字 = 7257`(803.8 / 804.7 / 880.6 / 882.0 / 885.4s 多次回显)
- 两值自洽:7257 = 2 × 3628.5,即直径标注量的是半径 3628.5 的圆,
  与同场景的 3629 线性标注同量级 —— 这是本课唯一的硬尺寸证据。
- **C** `D / DIMSTYLE` 反复开关标注样式管理器;`COPY 找到 1 个`(809.1s)

## 剔除
805.7 / 811.0 / 812.4 / 876.3 / 885.4s 的 `*取消*`;COPY 多次未落点即取消。

## 做不到
建筑标注样板的**具体样式参数**(文字高度、箭头样式与大小、全局比例、
主单位精度等)在命令行没有回显,对话框帧未捕获 —— 我只按建筑图常用量级
设了 DIMTXT/DIMASZ/DIMEXE/DIMEXO,**这几个值是 L 级(布局性选择),不是从视频读的**,
已在此显式声明。真正来自视频的只有 3629 与 7257 两个标注读数。
