## 四、构造方式

| 部分 | 构造 | 来源 |
|---|---|---|
| A3 图纸 | `RECTANG 0,0 _D 420.0 297.0` | **C**,继承课时77 的 ISO 尺寸链 |
| 内框 | `RECTANG 5.0,5.0 _D 410.0 287.0` | **C**,内缩 5(课时77 `OFFSET 5` + 本课 96.5s `拉伸点:5`) |

**跨课交叉印证**:课时83 的「增强属性编辑器」(D 级裁图)里读到的属性栏目正是
`设计 / 制图 / 校对 / 审批 / 日期 / 页码 / 总页 / 比例 / 图号 / 图名`,
**与本课这 8 个提示高度吻合** —— 说明提示用词是对的(缺了「日期」「比例」两项)。
但**具体默认值**在两课里不同(课时83 是 `PM-01-01` / `小猪佩奇01` / `共04页`),
所以本课的 `平面布置图` / `PM-01-04` / `共19页` 只能算示例值。

## 七、做不到的部分 / 数值找不到出处

1. **⚠ 8 个属性的标记、提示、默认值全部没有命令行出处。**
   897.9 / 899.3s 两次 `ATT` → `ATTDEF` 命令行**只打印了 `指定起点:` 一行**,
   标记/提示/默认值/字高全在**属性定义对话框**里键入,一个字都没回显;
   本课也没有 `dlg\` 裁图。
   - 提示用词(设计/制图/校对/审批/图名/图号/页码/总页)靠**课时83 的增强属性编辑器**
     交叉印证,可给 D 级;
   - **标记 `SJ` / `ZT` / `JD` / `SP` / `TM` / `TH` / `YM` / `ZY` 是拼音首字母,纯属编造**;
   - **默认值 `平面布置图` / `PM-01-04` / `共19页` 也是编的**(课时83 里是别的值)。
   → 这是本课最大的 A6 缺口。
2. **⚠ 标题栏的全部格线尺寸没有出处。** 180×50 的外框、x=303.4/334.0/379.0 的三条竖线、
   行高 10 的四条横线,视频里**全是鼠标拾取 + `_m2p` 中点捕捉**画出来的,
   `_m2p` 只打印"中点的第一点:/中点的第二点:",**不给坐标**。
   这一整套格线是按画面比例摆的(与课时83 的同类缺口一致)。
3. **⚠ 唯一有出处的矩形尺寸 `25 × 5`(486.9/488.8s)没有落到脚本。**
   它在视频里画完就被 `*取消*`(490.7s),但它是本课**唯一一个键入过的矩形尺寸**,
   很可能就是标题栏某一格的尺寸。现在脚本里没有任何 25×5 的格子,
   而 x=379→415 那格宽 36、行高 10,与 25×5 对不上。**值得回头核对。**
4. **视频最后的 `BLOCK 找到 35 个` 在「指定插入基点」处被取消(923.8s),块没建成。**
   脚本同样不建块,只留 8 个 `ATTDEF` 定义(未成块的属性定义),与视频终态一致。
   注意 763.0s 那次 `BLOCK 找到 41 个` 也没走完(770.6s 后直接回到 `命令:`)。
5. **`MATCHPROP` 未复刻** —— 视频里它被取消,且无头版没有 `MATCHPROP`(SOP 已列)。
6. **`XLINE h` 未复刻** —— 视频里被取消。
7. **字高 3.5 / 5 无出处**,是按 GB 制图字号惯例填的;`TEXTSIZE 3.5` 同理。
8. **文字样式 `hei` 用 SimSun 字体** —— 名字与字体不符,是脚本为落地中文临时建的样式,
   与视频里的 `10.建筑字体`(课时77 有 C 级回显)不是一回事。
