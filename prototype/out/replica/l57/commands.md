## 二、剔除清单(取消/撤销/重画)

共 20+ 处,主要三类:
1. **MLEADER 全程只讲不留** —— 155.5–176.6 / 179.0–245.8 / 491.0–505.4 / 580.3–601.0 / 566.4–572.6s,全部 `*取消*`;多重引线是**下一课(59)**的内容,本课只是对比演示。
2. **383.0s 的输入错误**:文字打进了「指定文字宽度」提示,`输入无效。`,随后 385.9–388.8s 连续 4 次 `*取消*`,重做。
3. **夹点拉伸 / MOVE / MTEDIT 的收尾操作全部撤销**(923.0 / 925.4s `_u MOVE`),不改变终态。

## 三、构造方式

脚本用 `QLEADER` 精确复刻三条引线,每条 = 3 个点 + 文字宽度 0 + 注释文字:

| # | 引线点 | 文字 | 说明 |
|---|---|---|---|
| 1 | 620,720 → 620,497 → 825,497 | `asfas\` | 对应 246.7–266.9s;箭头临时改 `DIMLDRBLK _BOXFILLED`、`DIMASZ 10` 以复现"换箭头"演示 |
| 2 | 823,808 → 1090,810 → 1190,890 | `这是个圆形` | 对应 407.0–437.8s |
| 3 | 825,706 → 850,636 → 925,636 | `asfasf` / `asfasfasf` / `asdfgafsa` 三行 | 对应 846.2–882.7s |

文字样式用 `-STYLE SHOUHEITI txt.shx,gbcbig.shx`(大字体)以保证中文「这是个圆形」能落进 DXF;
`DIMTXSTY SHOUHEITI` + `DIMTXT 50` 让引线文字可见。

## 六、做不到的部分 / 数值找不到出处

1. **本课的引线坐标全部没有出处。** 三条引线的 9 个点(620,720 / 620,497 / 825,497 / 823,808 / 1090,810 / 1190,890 / 825,706 / 850,636 / 925,636)在 169 条条带里**一个都没有命令行回显** —— 讲师全程鼠标拾取,命令行只打印"指定下一点:"。这些坐标是按视频画面的相对位置摆的(L 级),换句话说**引线的形状是复刻的,位置和长度不是证据**。
   - 唯一一次出现坐标数字是 604.8s 动态输入框里的 `3949.2685 / -597.5435`,那是**光标位置**不是拾取点,不能用。
2. **`DIMLDRBLK _BOXFILLED` 无直接出处。** 视频 826.6s 只看到箭头下拉框末尾的「无 / 用户箭头」两项,讲师换了箭头但具体选了哪一个没有命令行回显,也没有清晰的对话框裁图。脚本选「实心方框」是推断,标 L。
3. **`DIMASZ 10 / 5`、`DIMTXT 50` 无出处**,是为无头出图可读性设的。
4. 视频里的「引线设置」对话框(`QLEADER` 的 `S` 分支)三个选项卡(注释/引线和箭头/附着)的具体勾选项没有可读裁图,只能确认**对话框被打开过**(606.2 / 848.2 / 862.6s 的 `<设置>: S`)。
5. 「复制对象」这一注释类型分支在视频里**尝试失败**(`请选择多行文字、文字、块参照或公差对象。`),脚本不复刻。
6. MLEADER 相关演示全部被取消,故成品里没有 MULTILEADER 实体 —— 这是忠实结果。
