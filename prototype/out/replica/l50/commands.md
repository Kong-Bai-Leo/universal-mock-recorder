## ⚠ 数值找不到出处

1. **斜线的分量 `93.12` 与 `32.077`**:命令行只给了 `DIMALIGNED 标注文字 = 98.49`(实长),
   **没有任何一次标注给出它的水平投影或倾角**。`√(93.12² + 32.077²) = 98.49` 说明这两个数
   是"凑出 98.49"的一组解,**其中一个自由度没有证据**(倾角 ≈ 19.0° 只能来自画面比例,M 级)。
   建议:标注为"实长 98.49 为 C 级,倾角为 M 级估计"。
2. **顶部的 DIM* 系统变量块**(DIMTXT 2.5 / DIMASZ 2.5 / DIMEXE 1.25 / DIMEXO 0.625 /
   DIMDLI 3.75 / DIMGAP 0.625 / DIMDEC 2 / DIMZIN 8 / DIMTAD 1 / DIMATFIT 3 / DIMTMOVE 2 /
   DIMSCALE 1 / DIMCLRD 0 / DIMBLK `.`):**是 ISO-25 默认值,不是本课对话框里读出来的**。
   本课讲师在对话框里翻了很多页,但 449–623s 之间反复 `*取消*`,**没有一次把修改后的样式定稿**;
   真正落地的样式修改在**课时51–55**。因此这里的变量块应标为"默认值/未改动",不是本课证据。
   可反证的两项同课时49:`标注文字 = 93.27` / `= 56.62`(两位小数)⇒ DIMDEC=2;
   `= 172.4` 一类无尾随零 ⇒ DIMZIN=8。
3. **两个样式名 GONGYE-MOBAN / JIANZHU-MOBAN**:来自对话框(见 `dlg/` 下的 60+ 张对话框抽帧),
   命令行只有 `D` / `DIMSTYLE` / `'_dimstyle`,**没有样式名回显**。等级 **D**。
4. **矩形①高 31.64 与矩形②高 31.51 不相等**:这不是错误 —— 两个矩形都是鼠标拖出来的,
   `469.0s` 与 `886.1s` 两次标注分别给出了这两个值,**都是 C 级**。忠实复现即保留差异。

## 验证(verify.json)

```
counts: { LWPOLYLINE: 2, LINE: 1, DIMENSION: 7 }
LWPOLYLINE#1 (0,0)(93.27,0)(93.27,31.64)(0,31.64) closed
LWPOLYLINE#2 (149.89,0)(243.16,0)(243.16,31.51)(149.89,31.51) closed
LINE (0,-40)–(93.12,-72.077)
DIMENSION ×7: type 32 ×6(线性/连续),type 33 ×1(对齐)
```
**反算复核**:矩形①宽 93.27 ✓ 高 31.64 ✓;矩形②左边界 − 矩形①右边界 = 149.89 − 93.27 = **56.62** ✓
(与 117.1s 的连续标注完全一致);矩形②宽 243.16 − 149.89 = **93.27** ✓;高 31.51 ✓;
斜线长 √(93.12² + 32.077²) = **98.49** ✓。
标注数 7 = 4 个 DIMLINEAR + 1 个 DIMCONTINUE + 1 个 DIMALIGNED + 1(连续标注生成 2 个实体中的一个)。

## 证据等级分布

- **C**:93.27、31.64、31.51、56.62、98.49、`找到 1/2/6 个`、PLINE 宽度 0→10(已剔除)
- **D**:两个新建标注样式名、对话框各选项卡内容(见 `dlg/` 抽帧)
- **M**:斜线倾角(≈19°)
- **L**:图形摆放、尺寸线位置

## 做不到的部分

- **对话框里改了什么没有落地**:449–623s、850s 讲师在标注样式管理器里翻遍了七个选项卡,
  但每次都以 `*取消*` 收尾,命令行也无任何 `DIM*` 变量回显。因此本课**不复现任何样式参数改动**,
  只复现"新建了两个样式名"这一事实。真正的参数改动请看课时51–55。
- **矩形是鼠标拖出来的**,`RECTANG` 没有走 `尺寸(D)` 分支,原始输入无数值;
  成品尺寸全部靠事后标注反推,这是本课能达到的最高证据等级。
- **变宽 PLINE(0→10)** 被取消,不入成品。
- 斜线的倾角无证据(见上)。
