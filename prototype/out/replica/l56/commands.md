## 四、构造方式

按视频里演示的 **6 类"其它标注"**各造一个最小实例,全部落在同一张图上:

| 组 | 图元 | 标注命令 | 数值来源 |
|---|---|---|---|
| 1 | `LINE 0,0→234.8066,0`、`→322.6066,0` + 3 条 16 长刻度线 | `QDIM _W` 窗选 + `_C`(连续) | 234.8 / 87.8 = C |
| 2 | `LINE 450,0→450,145.41`、`950,0→950,145.41` | `DIMLINEAR` | 间距 500 = C;线高 145.41 无出处 |
| 3 | `LINE 0,-300→239.1985,-161.9` | `DIMALIGNED` | 斜长 276.2 = C(分解成 ΔX/ΔY 是构造选择) |
| 4 | `LINE 600,-300→800,-300`、`600,-300→700,-126.7949` | `DIMANGULAR` | 60° = C(用 tan60°=1.7320508 精确构造) |
| 5 | `CIRCLE 1100,-200 82` | `DIMRADIUS` | R82 = C |
| 6 | `LINE 0,-600→238.8,-600` + 6 条刻度线 | `DIMLINEAR` + `DIMBASELINE` | 98.7/115.1/143.4/232.7/238.8 全部 = C |
| 7 | `LINE 1500,-900→4929.6,-900` + 4 条刻度线 | `DIMLINEAR` + `DIMBASELINE`,`DIMSCALE 8` | 594.4 / 1127.6 / 3429.6 = C |

第 7 组因跨度接近 3430,把 `DIMSCALE` 临时提到 8、`DIMDLI` 提到 60,画完再复位为 1 ——
这是**为让标注可读做的排版处理**,视频里没有对应回显,等级 L。

## 七、做不到的部分 / 数值找不到出处

1. **`234.8066` 与 `322.6066` 的后两位小数无出处。** 命令行只给 `234.8` 和 `87.8`(DIMDEC=1)。脚本多出的 `.0066` 是构造值,不是读到的。
2. **`145.41`(第 2 组两条竖线的高度)完全没有出处** —— 视频只标了两线间距 500,竖线本身多长没标过。纯排版值。
3. **`239.1985,-161.9` 的分量无出处。** 证据只有斜长 276.2,ΔX/ΔY 的具体拆分是脚本自己选的(任一满足 √(ΔX²+ΔY²)=276.2 的组合都成立)。
4. **`700,-126.7949` 同理**:证据只有 60°,边长 200/100 是自选的。
5. **第 7 组第 2 段:视频回读 533.3,脚本落成 2627.6−2094.4 = 533.2。** 差 0.1。原因是脚本按更硬的基线回读 1127.6 反推,与逐段回读的 1 位小数舍入不自洽 —— 二者只能取其一,已取基线。此处应视为已知的 0.1 舍入分歧,非错误。
6. 视频里另有一批标注回读(319.3 / 184.4 / 47 / 84 / 111 / 51 / 48 / 35 / 9 / 335.6 / 10)属于讲师在**其它已有图元**上试演,脚本没有对应几何,故未纳入 —— 这部分过程无法复刻。
7. 标注样式的具体参数(线/箭头/文字选项卡)本课未展示,`DIMTXT`~`DIMDLI` 全部无出处。
8. 中文样式名无法在无头脚本里落地,用 `GONGYE` 代替。
