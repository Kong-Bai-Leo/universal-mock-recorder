## ⚠ 数值找不到出处

1. **`DIMGAP 10` 与对话框矛盾**:唯一能看清「文字」选项卡的抽帧(**834s**)显示
   「从尺寸线偏移(O)」= **0.625**(ISO-25 默认值)。脚本写 `DIMGAP 10`,
   在命令流与 83 张对话框抽帧里**都找不到 10 这个偏移值**。
   → 建议改回 `0.625`,或补一张能看清该字段为 10 的抽帧作为证据。
2. **`-STYLE SHOUHEITI txt.shx` 里的字体文件 `txt.shx`**:对话框只显示**样式名**「瘦黑体」,
   **没有显示它对应哪个字体文件**。94–102s 的字体列表里也没有出现过 `txt.shx`。
   `txt.shx` 是 AutoCAD 的默认 SHX 字体,这里是**为了让样式能建起来而选的占位字体**,
   **不是证据**。真正的"瘦黑体"应是某个 TTF,本次无法确定。
3. **顶部第一段 DIM* 变量块**(DIMTXT 2.5 / DIMASZ 2.5 / … / DIMTXSTY Standard):
   是 ISO-25 默认值,用作"改之前"的基线,**不是从对话框读出的**。
4. **矩形①与矩形②尺寸相同(234.8066 × 145.41)**:视频里第二个矩形是复制出来的,
   命令流没有单独标注它,脚本按"复制"处理是合理的,但严格说第二个矩形的尺寸是**推定**;
   两矩形间距 `300`(即 x=300 起)是**布局值 L**。

## 验证(verify.json)

```
counts: { LWPOLYLINE: 2, DIMENSION: 3 }
LWPOLYLINE#1 (0,0)(234.8066,0)(234.8066,145.41)(0,145.41) closed
LWPOLYLINE#2 (300,0)(534.8066,0)(534.8066,145.41)(300,145.41) closed
DIMENSION ×3: 全部 type 32
```
**反算复核**:宽 234.8066 与 450.2s 回显**零误差**;高 145.41 与 817.4s 回显**零误差**。
**跨课交叉校验**:课时52 与本课是**同一张图**的两节课,本课 C 级实测的
**234.8066 × 145.41** 可用来**证伪课时52 脚本里的 110 × 70**(见 `l52/commands.md` ⚠ 第 1 条)。
**验证盲区**:verify.json 不回读标注样式与文字参数,`DIMGAP` 的矛盾无法被自动发现。

- 837s 之后是否还改过 `从尺寸线偏移` 无法确认(见 ⚠ 第 1 条)。
