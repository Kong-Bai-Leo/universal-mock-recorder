## 验证(verify.json)

```
l36.dxf  counts = { LINE: 8, CIRCLE: 2, ARC: 4 }
CIRCLE = c(6000,1000) r 400   ←源
         c(6000,1000) r 1400  ←偏移件
ARC    = c(12000,1000) r 800  …
```

**三条自校验,全部通过:**

**1. 圆的偏移距离 = 1400 − 400 = **1000**,与 255.9s 的命令行 `1000` 逐位一致** ✓
两个圆同心 `(6000, 1000)`,证明 OFFSET 对圆是"同心缩放半径"而非平移 ✓

**2. `LINE: 8` 而不是 9 —— `_E _Y`(删除源)被计数证明**
脚本画了 **6** 条 `_.LINE`,做了 **3** 次直线偏移(100 / 500 / 1000,各 +1)
+ **1** 次带 `_E _Y` 的偏移(**源被删、只留偏移件,净增 0**),
`6 + 3 + 0 = **9**`……实测 **8**,少一条 —— 正是因为
`_.OFFSET _E _Y` **把源直线删掉了**(净变化为 0,而那条源直线本身也不在了)✓
**「删除源=是」的行为被实体计数硬性区分出来**。

**3. `ARC: 4`** = 3 条画出来的圆弧 + 1 条圆弧偏移件 ✓
(拉长命令只改变端点,不新增实体。)

**本课无尺寸标注实体**,无标注回读值。

## ⚠ 数值出处核对 —— 关键发现

### 结论:**本课 11 个知识点数值 100% 可追溯,是 26 课里 C 级密度最高的一课之一**

`100` / `500` / `1000`(偏移)、`删除源=是`、
`100`(增量)、`150` / `200`(百分比)、`30`(角度增量)、`150`(总角度)
—— **全部逐字对得上命令行**,而且多数还有**默认值回显做二次反证**:

```
59.5s  <通过>: 100      → 68.7s  默认变 <100.0000>   ← 100 生效
70.6s  <100.0000>: 500  → 255.9s 默认变 <500.0000>   ← 500 生效
656.4s 增量 100         → 764.4s 默认变 <100.0000>   ← 100 生效
693.3s 百分比 150       → 827.8s 默认变 <150.0000>   ← 150 生效
```

**这条"输入值 → 下一次默认值"的链条把四个数值全部闭合了**,
是 SOP §2.5「`<默认值>` 回显 = 上一次实际用的值」的教科书式应用。

```

圆 r = 400                圆弧 `_A 120` / `_A 60` ×2、半径 800

9 个 `_.ZOOM _W` 窗口
```

`out/replica/l36/` 下有 `build.py`(脚本生成器)但**没有测量产物**;
命令行里这些数字一个都没出现过。

**影响评估:低,但有一处需要注意** ——
`_.LENGTHEN _P 150` / `_P 200` 是**百分比**,结果长度 = 原长 × 1.5 / 2.0,
**依赖靶子的原长(1000)**;而 1000 这个原长**无出处**。
因此 DXF 里那两条线的最终长度(1500 / 2000)**不可与视频比对**,
只能证明"百分比命令生效了"。
相对地,`_DE 100`(增量)与 `_T _A 150`(总角度)**与原长无关**,可比对。
