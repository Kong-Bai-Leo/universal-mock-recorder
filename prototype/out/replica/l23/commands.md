## 构造(每个实体怎么来的)

### A. 演示靶子(画 15 个实体,分成"上排 / 下排"两组)

上排(y ≈ 0…2500)供 **MOVE** 演示,下排(y ≈ −2000…−5000)供 **ERASE** 演示:

| 靶子 | 脚本 | 尺寸出处 |
|---|---|---|
| 4 条直线 | `_.LINE 0,y 1000,y`(y = 8000 / −2000 / −4000 / −6000) | **长 1000 = C 级**(280.3s `LINE … : 1000`) |
| 1 条直线 | `_.LINE 8000,-4000 12000,-4000` | 长 4000,**L** |
| 多段线 | `_.PLINE 8000,0 10000,0 11000,1500 9000,2500` | **L** |
| 2 个圆 | `_.CIRCLE 18000,±… 1200` | 半径 1200,**L** |
| 2 段圆弧 | `_.ARC _C … _A 180` | 半径 1200、包含角 180°,**L** |
| 2 个椭圆 | `_.ELLIPSE _C … 1200` | 2000 × 1200,**L** |
| 2 个矩形 | `_.RECTANG … 4000 × 2500` | **L** |

### B. MOVE —— **5 次移动的位移量全部 C 级**

| 脚本 | 位移 | 出处 |
|---|---|---|
| `_.MOVE _W 31500,-300 36500,2700` + `_D` + **`0,0,0`** | (0,0,0) | **378.2s `指定位移 <0.0000, 0.0000, 0.0000>: @0,0,0`** |
| `_.MOVE _W -500,7500 1500,8500` + `0,8000` + **`10000,8000`** | (10000, 0) | **264.5s `<正交 开> 10000`** |
| `_.MOVE _W 7500,-500 11500,3000` + `_D` + **`1000,0,0`** | (1000, 0, 0) | **393.6s `指定位移 …: 1000`**;405.6s 默认回显 `<1000.0000, 0, 0>` 反证 |
| `_.MOVE _W 16500,-300 19500,2700` + `_D` + **`0,1000,0`** | (0, 1000, 0) | **415.7s `… : @0,1000`**;431.0s 默认回显 `<0, 1000.0000, 0>` 反证 |
| `_.MOVE _W 24500,-300 26500,2700` + `_D` + **`0,-1000,0`** | (0, −1000, 0) | **436.3s `… : @0,-1000`** |

> **顺序不是随意的**:SOP 坑表写明「`MOVE _D` 输 `0,0,0` 无效 —— 被当成"接受默认位移";
> **零位移演示排在默认值仍是 0,0,0 时**」。脚本把 `0,0,0` 放在第一条,
> 正是为了避开这个坑,**与视频里 335.0s → 378.2s 的先后顺序也一致**。

### 一条需要留意的取舍

视频末尾(666.7s、697.0–698.9s)讲师把**所有删除和移动都 `_u` 撤销了**,
因此**视频最后一帧的画布 ≠ 本课的"成果"**。
脚本的做法是「每个演示动作各执行一次、不撤销」,
所以 `l23.dwg` 呈现的是**演示过程的累积结果**而非视频末帧。
**这是一个有意的选择,已在此写明**;若要严格复现末帧,成品应当是一张空图。

## 做不到的部分

1. **演示靶子的尺寸与摆位无出处**(见上),本文档不为它们背书。
2. **讲师全程鼠标拾取基点/第二点**,只有开了正交并键入数字的那几次
   (264.5s 的 `10000`、306.2s 的 `1000`)有回显;
   **其余的基点绝对位置在原理上拿不到 C 级证据**。
3. **动态输入框里的世界坐标(170.4s `387339085.8536 / 163986585.998` 等)不可用** ——
   那是讲师当时图纸的绝对坐标(10⁸ 量级),与本课几何(10³–10⁴)无关。
4. **`_u` 撤销链无法在脚本里表达** —— 无头脚本一旦 `_u` 就会把前面的实体也撤掉,
   而验证需要实体留在图里;因此撤销**只记录、不执行**(见上一节的取舍说明)。
5. **窗选的"栏选(F)/圈围(WP)/圈交(CP)"三种方式未复现** ——
   视频里(587.0–600.0s)只是展示提示、全部 `*取消*`,没有实际选中任何对象。
