# 课时112 扫掠工具(SWEEP) —— 命令流

蒙太奇覆盖: 22/22 去重条带图 (=430/430 条带, 100%)

## 命令序列
CIRCLE / POLYGON / PLINE / SPLINE(画轮廓与路径) →
LINE **2100 / 900 / 2100**(路径三段) → JOIN(→1 条多段线) →
RECTANG 尺寸(D) **50 × 240**(轮廓) → **SWEEP**(模式 MO, 对齐 A, 基点 B, 比例 S, 扭曲 T) →
RECTANG 尺寸(D) 3600×2800(*取消*) → EXTRUDE 高度 **200**

## 数值证据
| 命令 | 参数 | 等级 | 出处 |
|---|---|---|---|
| LINE | 段长 **2100**, **900**, **2100** | C | t≈358–366s 键入 |
| RECTANG | 尺寸(D) 长度 <10.0000>: **50**, 宽度 <10.0000>: **240** | C | t≈384–394s 键入 |
| EXTRUDE | 高度 **200** | C | t≈776–783s 键入 |
| POLYGON | 侧面数 <4>: **10**, 内接于圆(I) | C | t≈300s 键入 |
| LINE | 段长 200/300/50/60/80 | C | t≈818–834s 键入 |
| CIRCLE | 半径提示默认 <21.5575> / <28.2742> / <7.2545> / <9.5186> / <4.9392> | C | 提示回显 |
| JOIN | 10 个对象 → 1 条多段线;3 → 1;7 → 1 | C | 回显 |
| SWEEP | 对齐(A) [是(Y)/否(N)] <是>;扭曲(T) 角度 <0.0000> | C | 选项回显 |

## 剔除
- t≈746–763s RECTANG 尺寸 360/3600×2800 *取消*
- SWEEP 报错:「路径曲线不能自交」「不能选择轮廓曲线作为路径曲线」
  「Error 85021 无法扫掠」「不能扫掠或拉伸自交的曲线」

## 复刻做法
1. 路径 = LINE 三段 **2100 / 900 / 2100** + PEDIT 合并为 1 条多段线
2. 轮廓 = RECTANG 尺寸(D) **50 × 240**
3. SWEEP 轮廓沿路径 → 实体
4. POLYGON 10 边内接 沿一条直线路径 SWEEP(还原「十边形截面扫掠」)
5. RECTANG 400×300 → EXTRUDE 高度 **200**
