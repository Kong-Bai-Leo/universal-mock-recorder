## 构造(每个实体怎么来的)

### A. 四个源图形

| 脚本 | 尺寸出处 | 等级 |
|---|---|---|
| `_.CIRCLE 0,0 **4082.1427**` | **61.4s `指定圆的半径或 [直径(D)] <4082.1427>`** | **C** |
| `_.ARC _C 0,-20000 0,-15917.8573 _A 180` | 半径 = `20000 − 15917.8573` = **4082.1427**(**沿用同一个 C 级半径**);<br>包含角 180° | **C** + L(圆心) |
| `_.PLINE 0,-35000 8000,-35000 10000,-30000 2000,-28000` | 顶点为排版取整 | **L** |
| `_.RECTANG 0,-50000 8000,-45000`(8000 × 5000) | 排版取整 | **L** |

### B. 四次 COPY —— **四种用法各演示一次,参数全部 C 级**

| # | 脚本 | 演示的用法 | 数值出处 |
|---|---|---|---|
| 1 | `_.COPY _W …` + `0,0` + **`_A`** + **`5`** + **`10000,0`** | **阵列(A)**:1 源 → 4 个副本 | 项目数 **5** ← 284.2s;<br>间距 **10000** ← 323.5s `[布满(F)]: 10000` |
| 2 | `_.COPY _W …` + **`_D`** + **`0,1000,0`** | **位移(D)** | **214.6s `指定位移 …: @0,1000`** |
| 3 | `_.COPY _W …` + `0,-35000` + `10000,-35000` | **基点 + 第二点**(单次) | 距离 **10000** ← 233.3s `… : 10000` |
| 4 | `_.COPY _W …` + **`_M`** + `0,-50000` + `10000,… 20000,… 30000,…` | **模式(O) = 多个(M)**,一次给三个落点 | 模式 **M** ← 356.2s;<br>间距 **10000** ← 233.3s / 323.5s |

> **为什么第 3 条不加空行?** SOP 坑表:「`COPY` 给完第二点就结束 —— 本版是单次复制,
> **不要**再补空行(会重入 COPY);多重复制用 `_M`」。脚本第 3、4 条正是照此写的。

**摆位**:四个源图形按 `y = 0 / −20000 / −35000 / −50000` 分四排,
副本沿 +X 按 10000 间距展开 —— **排布是布局(L),间距 10000 是 C 级**。

## 验证(verify.json)

```
l24.dxf  counts = { CIRCLE: 5, ARC: 2, LWPOLYLINE: 6 }
CIRCLE = c(0,0) c(10000,0) c(20000,0) c(30000,0) c(40000,0),  r 4082.1427 ×5
ARC    = c(0,-20000) / c(0,-19000),  r 4082.1427,  90°→270° ×2
LWPOLYLINE = 折线 (0,-35000)… / (10000,-35000)…
             矩形 (0,-50000)… / (10000,…) / (20000,…) / (30000,…)
```

**四种 COPY 用法被实体清单逐条硬性证明:**

| 用法 | 预期结果 | DXF 实测 | 结论 |
|---|---|---|---|
| **阵列(A) 5 项 / 间距 10000** | 圆共 **5** 个,圆心 x = 0, **10000, 20000, 30000, 40000** | **完全一致** | ✓ |
| **位移(D) @0,1000** | 圆弧共 2 个,副本圆心 y = −20000 **+ 1000 = −19000** | **完全一致** | ✓ |
| **基点+第二点(单次)** | 折线共 **2** 条,副本整体 **+10000 沿 X** | **完全一致**<br>`(0,-35000)→(10000,-35000)` 等四点全部平移 10000 | ✓ |
| **模式 M(多个)一次三落点** | 矩形共 **4** 个,x = 0, **10000, 20000, 30000** | **完全一致** | ✓ |

**半径一致性**:5 个圆与 2 段圆弧的半径**全部是 4082.1427** ——
与 61.4s 的命令行默认值回显**逐位一致**,并且证明 `_A` 阵列复制**不改变几何**。

**本课无尺寸标注实体**,无标注回读值。

## ⚠ 数值出处核对 —— 关键发现

### 结论:**本课"知识点数值"100% 可追溯,且被 DXF 坐标逐位复验**

与课时23 同属证据链最完整的一档:
COPY 这一课要证明的是**复制的方式与量**,而 4 个关键数值
(`4082.1427` / `@0,1000` / `10000` / `5`)**全部是 C 级**,
并且被 DXF 里 13 个实体的坐标**逐位复验**(见验证一节的四行表)。

### 无出处的数值(全部属"演示靶子",不承载知识点)

```
圆弧圆心 (0,-20000)         折线顶点 (0,-35000)(8000,-35000)(10000,-30000)(2000,-28000)
矩形 (0,-50000)-(8000,-45000)  即 8000 × 5000
四排靶子的 y 间距 15000 / 15000 / 15000
`_W` 窗选框的角点
```

`out/replica/l24/` 下**没有任何测量产物**(无 `geo.json` / `geo_overlay.png` / `build.py`),
命令行里这些数字一个都没出现过,全是 1000 的整数倍,呈"排版取整"特征。

**影响评估:低。** 靶子形状不影响 COPY 的语义;
被证明的对象(副本个数、副本相对源的位移)全部 C 级且已复验。
`_W` 窗选框角点是**为无头拾取可靠而算出来的**(SOP 坑表要求),
不是视频里的真实拖框位置。

**一个值得肯定的细节**:圆弧半径没有另取一个数,而是**沿用了 C 级的 4082.1427**
(`20000 − 15917.8573 = 4082.1427`),
使得"靶子尺寸"这一块的无出处面积被压到了最小。

### 未采用的证据(1 条)

**467.5–483.4s `输入要进行阵列的项目数: 10`** —— 讲师第二次演示阵列时用的是 **10**,
脚本用的是第一次的 **5**(284.2s)。两者都是 C 级,选哪个都成立;
但 10 那一次最后 `*取消*` 了、没有真正落地,**选 5 是更保守的做法**。

### 无出处但影响极小的一处

`_.ARC … _A 180`(包含角 180°)—— 视频里讲师用三点法画弧,
命令行**没有角度回显**;脚本改用 `圆心-起点-包含角` 是为了让半径能精确等于 4082.1427。
**180° 是为了做出半圆而选的,属 L 级**,但它不影响 COPY 的任何结论。
