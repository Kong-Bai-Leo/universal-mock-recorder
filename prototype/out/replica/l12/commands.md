## 构造

本课是**照着参考图临摹佩奇**:讲师用 `IMAGEATTACH` 插入图片(76.8s,
`宽 1 : 高 0.676602`),然后全程用 `ARC` 三点 / `CIRCLE 2P·3P` / `ELLIPSE`
沿图片轮廓**鼠标描线**,命令行**不回显任何顶点坐标**。

因此 `l12.scr` 的全部实体来自**终态帧像素测量**(`geo.json`,t=**860.0s**,
`--color white`),按 `--flipy 597` 映射:

| geo.json | l12.scr |
|---|---|
| `circles: [551.4, 330.6, 50.0]` | `_.CIRCLE 551.400,266.400 **50.000**`(y = 597−330.6 = 266.4) |
| `lines`(21 条,例 `[586,534]→[1199,532]`) | `_.LINE 586.000,63.000 1199.000,65.000` |
| `arcs`(28 段,例 `c=[528.6,324.6] r=71.8 a0=42 a1=107`) | `_.ARC _C 528.600,272.400 581.958,320.444 _A **65.000**`(107−42 = 65) |

计数完全吻合:geo 21 lines + 28 arcs + 1 circle ⇒ 脚本 21 + 28 + 1。
**没有第 22 条线 / 第 29 段弧**,不存在测量之外的实体。

## 验证(verify.json)

```
l12.dxf  counts = { CIRCLE: 1, LINE: 21, ARC: 28 }
  CIRCLE c=[551.4, 266.4] r=50.0                     ← geo 的 50.0 ✓
  ARC    c=[528.6,272.4] r=71.8004 a0=42.0 a1=107.0  ← geo 的 71.8 / 42 / 107 ✓
  ARC    c=[495.0,288.0] r=77.8001 a0=204.0 a1=48.0  ← geo 的 77.8 / 204 / 48 ✓
```
28 段弧的圆心、半径、起止角与 `geo.json` **逐条一致**;本课**无标注实体**。

## 数值出处核对 —— 发现

### 1. 落地数值全部有出处
`l12.scr` 的每个坐标、半径、夹角都能在 `geo.json` 里逐条对上,
**没有发现无出处(疑似编造)的数值**。

### 2. ⚠ 交叉校验:实体数量对不上(50 vs 52)
904.3s 讲师用 `COPY` 窗选整幅佩奇,命令行回显 **`找到 52 个`** ——
这是本课唯一的"终态实体总数"硬证据。
而 `verify.json` 的成品是 **1 + 21 + 28 = 50 个**,**少 2 个**。

差 2 个的可能原因(**均未证实**):
- `measure.py` 把两段极短的弧/线漏检了;
- 讲师窗选时把参考图片(IMAGE 实体)或某条辅助线也框进去了;
- 终态帧(860s)与 COPY 时刻(904s)之间又画了 2 笔。

**这是一处可量化的缺口,应当记录**:成品的完整度约 **50/52 = 96%**。

### 3. ⚠ 命令行里存在、但脚本没有采用的 C 级数值
- 多段线宽 **100**(799.7s 起点宽 / 802.1s 端点宽,841.4s `当前线宽为 100.0000`);
- PEDIT `指定所有线段的新宽度: **500**`(850.6s);
- `_circle` 半径默认回显 `<**753.8635**>`(276.5s);
- 参考图 `基本图像大小 宽 1 : 高 0.676602`(76.8s)——
  这个比例本可用来**标定像素→单位的绝对尺度**,脚本没有用。

脚本落地的多段线宽度是 **0**(所有实体都是 LINE/ARC/CIRCLE,没有 LWPOLYLINE),
即 781–860s 那一整段"多段线加宽 → PEDIT 改宽"的演示**完全没有复刻**。

## 做不到的部分

1. **绝对尺寸未知**:临摹图无任何标注,采用"1 像素 = 1 图形单位"约定。
   本可借 `基本图像大小 宽 1 mm` 反推,但参考图在画布上的实际显示宽度
   在命令行没有回显,**这条路走不通**。
2. **少 2 个实体**(见发现 2),原因未定。
3. **多段线宽度演示(100 / 500)未复刻**;`PEDIT` 的 9 个子选项也未复刻。
4. **参考图片本身(IMAGE 实体)未落地**:无头环境不附着外部图片,
   成品里只有描出来的线条。
5. 全片近百次**夹点拉伸**在视频里全部被取消,无法也无需复刻。
