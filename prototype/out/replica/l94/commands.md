## 3. 构造与证据出处

### 3.1 尺寸链(两条链都自校验闭合,C 级)

**水平链** `DIMLINEAR = 405`(247.2s / 306.7s)+ `DIMCONTINUE = 162`(251.0s / 312.5s)
+ `DIMCONTINUE = 566`(252.5s / 313.9s),总长 `DIMLINEAR = 1133`(218.4s / 302.9s):

```
405 + 162 + 566 = 1133   ← 精确闭合
```

**这解决了上一轮的"OFFSET 404 但标注量得 405,原图自身不自洽"**:
讲师在 122.4s 敲的是 `OFFSET <1133.0000>: 404`,但 **404+162+566 = 1132 ≠ 1133**;
而他随后两次(247.2s、306.7s)`DIMLINEAR` 回读都是 **405**,链才闭合。
按 SOP 第 2.5 节"链能自己闭合就是自校验,缺的段可由闭合方程唯一解出",
**采用 405**,并把 404 判定为讲师键入时的 1 个单位手误。脚本原本就用的 405,本轮确认无误。
规格页像素复核:底部圆心实测落在 (848.3, 829.2) px,405 的预测是 (848.3, 829.2) —— 完全重合。

**竖直链** `DIMLINEAR = 97`(265.0s / 325.0s)+ `DIMCONTINUE = 227`(328.3s)
+ `DIMCONTINUE = 647`(329.3s);对应 OFFSET 97 / 227 / 647(76.3 / 84.0 / 91.2s)。
链的顶端是左毂外圆顶 y = 323.59,323.59 − 227 = **96.59**,与 `DIMLINEAR = 97` 差 0.4%(标注按整数显示)。

### 3.4 弧形槽 —— 上一轮"R378.96/R393.18 与等宽槽矛盾"的解答

本轮拿到本课自己的 C 级回读:`DIMRADIUS = **391.11**`(887.5s)与 `DIMRADIUS = **405**`(889.4s),
两值相差 **13.89**;规格页母版的 R393.18 / R378.96 相差 **14.22** —— 两套数据**同一个特征**。
而端盖是 R48.54,槽宽 = 97.08。**等宽槽要求两条边弧半径相差 97.08,不是 14。**

原因在命令流里:槽的两条边是用 **`ARC 起点 → 端点(_e) → 半径(_r)`** 画的
(694–743s 的那批 ARC),起止点是端盖圆的左/右象限点,半径是**手敲**的。
这样画出来的弧**不与端盖相切**,因此槽必然不等宽 —— **原图本身就不是等宽槽**,不是我们量错了。

按这个构造复算(端盖圆心 (567, ±318),r = 48.54,弦长 636):

| 边 | 半径 | 起止点 | 圆心 | 中部到中心线距离 |
|---|---|---|---|---|
| 左(外)缘 | **405** | (518.46, ±318) | (769.26, 0) | 364.26 |
| 右(内)缘 | **391.11** | (615.54, ±318) | (843.23, 0) | 452.12 |

端部槽宽 = 615.54−518.46 = **97.08**(= 2×48.54 ✓),中部槽宽 = **87.86**,窄了 9.2。
用规格页母版的 393.18 / 378.96 代入**同一构造**:端部 97.08、中部 86.2 —— **同样窄约 10**。
两套半径给出同一种"两端宽、中间略窄"的形状,**互相印证了这个构造**。

脚本原来用的是解析构造的**等宽**槽(同心 R337.53 / R434.61,差正好 97.08),
两个半径**既不等于母版也不等于本课回读**,属 M 级臆造。本轮按上表改为 C 级的 405 / 391.11。
