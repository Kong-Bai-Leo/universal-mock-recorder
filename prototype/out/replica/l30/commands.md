### B. 五次圆角(半径与模式全部 C 级)

| # | 脚本 | 演示的用法 | 出处 |
|---|---|---|---|
| 1 | `_.FILLET **_R 20**` + `_.FILLET 700,120 790,40` | **两条直线倒圆角,r = 20** | **349.9s `半径 = 20.0000`** |
| 2 | `_.FILLET **_R 0**` + `_.FILLET 1080,40 1200,20` | **r = 0 → 把两条不相交的线延伸成尖角** | **522.7s `<20.0000>: 0`** |
| 3 | `_.FILLET **_R 100**` + `_.FILLET **_P** 150,400` | **多段线整体倒圆角,r = 100** | **679.2s `<0.0000>: 100`**;856.8s `P` |
| 4 | `_.FILLET **_R 20**` + `_.FILLET _P 300,60` | 矩形(闭合多段线)整体倒圆角 | 349.9s + 856.8s |
| 5 | `_.FILLET **_T _N _R 200**` + `_.FILLET 1700,400 1400,700` | **不修剪模式,r = 200** | **810.2s `模式 = 不修剪, 半径 = 200.0000`** |

> **为什么 `_T _N _R 200` 要串成一条、而倒角动作要单独一条?**
> SOP 坑表:「`FILLET _T` 设完不退出 —— 只有 `_R` 是"设完即退",`_T` 会回到
> "选择第一个对象";**串成一条 `_.FILLET _T _N _R 200`,再单独一条做倒角**」。
> 脚本第 5 组正是照此写的。

## 验证(verify.json)

```
l30.dxf  counts = { CIRCLE: 1, LWPOLYLINE: 2, LINE: 7, ARC: 2 }
CIRCLE = c(100,100) r 30
ARC    = c(720,60)   r 20,  180° → 270°
         c(1600,600) r 200, 180° → 27x°
```

**四条自校验,全部通过:**

**1. 圆半径 = 30,逐位对上 118.1s 的命令行** ✓
且与 122.4s 的 `DIST 距离 = 60.0000`(= 直径)**互相印证** ✓

**2. 第一个圆角:`ARC c(720,60) r 20`**
两条被倒角的线是 `x = 700`(竖)与 `y = 40`(横),直角顶点 `(700, 40)`。
半径 20 的内切圆心必然是 `(700 + 20, 40 + 20) = **(720, 60)**` ——
**DXF 实测一模一样**,且圆心角 `180° → 270°`(第三象限的四分之一圆)✓
**这直接证明 `_R 20` 生效**(349.9s 的 C 级值)。

**3. 第二个圆角:`ARC c(1600,600) r 200`**
两条线是 `x = 1400`(竖)与 `y = 400`(横),直角顶点 `(1400, 400)`。
半径 200 的内切圆心 = `(1400 + 200, 400 + 200) = **(1600, 600)**` ——
**DXF 实测一模一样** ✓ **这直接证明 `_R 200` 生效**(810.2s 的 C 级值)。

**4. `LINE: 7` 没有变少 —— 证明「不修剪(N)」生效**
若第 5 组用的是默认的「修剪」模式,那两条线会被截短;
用了 `_N` 之后**线段本身完好无损、只额外多一段圆弧**。
脚本画了 7 条 `_.LINE`,DXF 里还是 **7 条** ✓
而 `ARC: 2` 说明**只有第 1、5 组产生了独立圆弧**;
第 2 组(`_R 0`)不产生圆弧、第 3、4 组的圆角以**多段线凸度**形式内嵌
(所以 `LWPOLYLINE` 仍是 2 个而不是变多)✓

**本课无尺寸标注实体**,无标注回读值。

## ⚠ 数值出处核对 —— 关键发现

### 结论:**本课的知识点数值 100% 可追溯,且两个圆弧圆心被逐位复验**

FILLET 这一课要证明的是**半径与修剪模式**,而
`20` / `0` / `100` / `200` 四个半径 + `修剪/不修剪` 两种模式 **全部是 C 级**;
更难得的是**两个圆弧的圆心 `(720,60)` 与 `(1600,600)` 可以由半径解析算出并被 DXF 逐位证实**
(见验证第 2、3 条)。加上 `圆 r30`、`矩形 100×80`、`直线 100` 也都是 C 级,
本课是 26 课里**靶子尺寸 C 级占比最高**的一课之一。

   (好在本课这条验证做得很硬)。
