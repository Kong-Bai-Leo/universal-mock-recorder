## 构造(每个实体怎么来的)

### A. 演示靶子(10 个,分两组)

**上组 —— 会被拉伸的**:

| 靶子 | 脚本 | 尺寸出处 | 等级 |
|---|---|---|---|
| 矩形 | `_.RECTANG 0,0 20000,10000` | 排版取整 | **L** |
| 短直线 | `_.LINE 0,-8000 1000,-8000` | 长 1000 | **L** |
| 折线 | `_.PLINE 0,-20000 15000,-20000 15000,-14000` | 排版取整 | **L** |
| 3 条平行线 | `_.LINE 40000,y 50000,y`(y = 0 / −3000 / −6000) | 长 10000,间距 3000 | **L**<br>(为复现 637.9s 的「找到 **3** 个」) |

**下组 —— 拉伸不动的(演示 STRETCH 对哪些对象无效)**:

| 靶子 | 脚本 | 尺寸出处 | 等级 |
|---|---|---|---|
| 圆 | `_.CIRCLE 0,-40000 **8815.6391**` | **35.0s `指定圆的半径或 [直径(D)] <8815.6391>`** | **C** |
| 正六边形 | `_.POLYGON 6 30000,-40000 _I 5000` | 侧面数 6 / 外接半径 5000 | **L**(见下) |
| 半圆弧 | `_.ARC _C 50000,-40000 50000,-31184.3609 _A 180` | 半径 = `40000 − 31184.3609` = **8815.6391**<br>(**沿用同一个 C 级半径**) | **C** + L |
| 椭圆 | `_.ELLIPSE _C 70000,-40000 78000,-40000 4000` | 8000 × 4000 | **L** |

### B. 四次 STRETCH —— **位移量全部 C 级**

| # | 脚本 | 拉伸对象 | 位移出处 |
|---|---|---|---|
| 1 | `_.STRETCH _C 15000,-2000 25000,12000` + `0,0` + **`10000,0`** | 矩形右边 | **444.5s `… : 10000`** |
| 2 | `_.STRETCH _C 500,-9000 1500,-7000` + `0,0` + **`100,0`** | 短直线右端点 | **625.0s `… : 100`** |
| 3 | `_.STRETCH _C 12000,-16000 18000,-12000` + `0,0` + **`1000,0`** | 折线上端点 | **660.5s `… : 1000`** |
| 4 | `_.STRETCH _C 45000,-8000 55000,2000` + `0,0` + **`1000,0`** | **3 条平行线**的右端 | **689.8s `找到 3 个` … `<正交 开> 1000`** |

> **`_C`(交叉窗口)是命令本身要求的** —— 86.4s 的提示原文就是
> 「**以交叉窗口或交叉多边形选择要拉伸的对象...**」,
> 脚本用 `_C` 而非 `_W`,与该提示一致。
> 每个交叉框都**只框住要移动的端点、把另一端留在框外**,这是 STRETCH 生效的前提。

## 验证(verify.json)

```
l25.dxf  counts = { LWPOLYLINE: 3, LINE: 4, CIRCLE: 1, ARC: 1, ELLIPSE: 1 }
LWPOLYLINE = 矩形 (0,0)(30000,0)(30000,10000)(0,10000) 闭合
             折线 (0,-20000)(15000,-20000)(16000,-14000) 开放
             正六边形 6 顶点,闭合
LINE = (0,-8000)-(1100,-8000)
       (40000,0)-(51000,0) / (40000,-3000)-(51000,-3000) / (40000,-6000)-(51000,-6000)
CIRCLE = c(0,-40000) r 8815.6391
ARC = c(50000,-40000) r 8815.6391, 90°→270°
ELLIPSE = c(70000,-40000) major(8000,0) ratio 0.5
```

**四次拉伸的位移量被 DXF 坐标逐位复验:**

| # | 原始 | 位移(C 级) | 预期 | DXF 实测 | 结论 |
|---|---|---|---|---|---|
| 1 | 矩形右边 x = **20000** | **+10000** | 30000 | **(30000,0)(30000,10000)** | ✓ |
| 2 | 直线右端 x = **1000** | **+100** | 1100 | **(1100, −8000)** | ✓ |
| 3 | 折线顶点 x = **15000** | **+1000** | 16000 | **(16000, −14000)** | ✓ |
| 4 | 3 条线右端 x = **50000** | **+1000** | 51000 | **三条全部 (51000, y)** | ✓ |

**"拉伸不动"的一组同样被证明**:
圆心 `(0,−40000)`、半径 `8815.6391`;正六边形 6 个顶点;弧心 `(50000,−40000)`;
椭圆心 `(70000,−40000)`、长轴 `(8000,0)`、比率 `0.5` —— **与脚本给的原值一模一样**,
说明这四个对象**没有被任何交叉框碰到**,STRETCH 的作用范围是精确的。

**折线的自校验最有说服力**:交叉框 `12000,-16000 → 18000,-12000` 只罩住了
第 3 个顶点 `(15000,−14000)`,没罩住第 2 个顶点 `(15000,−20000)`;
DXF 里第 2 个顶点**保持 15000 不变**、第 3 个变成 **16000** ——
**"框内的点动、框外的点不动"这条 STRETCH 语义被逐点证明**。

**本课无尺寸标注实体**,无标注回读值。

## ⚠ 数值出处核对 —— 关键发现

### 结论:**本课"知识点数值"100% 可追溯,且被 DXF 坐标逐位复验**

STRETCH 这一课要证明的是**"哪些点会被拉走、拉多远"**,
而 4 个位移量(`10000` / `100` / `1000` / `1000`)与圆半径 `8815.6391`
**全部是 C 级**,并被 DXF 里 10 个实体的坐标**逐位复验**(见验证一节两张表)。
与课时23 / 课时24 同属证据链最完整的一档。

### 被丢弃的一条硬证据

**667.7s `DIST 距离 = 1707.4941 / Y 增量 = −1707.4941 / 倾角 270`** ——
这是 SOP §2.5 点名的高等级通道(`MEASUREGEOM`/`DIST` 硬回显),
可以直接反算出讲师图纸里某两点的实际间距,**脚本一个字都没用**。

## 做不到的部分

1. **演示靶子的尺寸与摆位无出处**(见上),本文档不为它们背书;
   其中**正多边形连"存在"本身都未在本次读到的montage 里得到确认**。
2. **讲师全程用鼠标拖交叉框**,框的位置只有画面、无坐标回显 ——
   **交叉框的真实位置在原理上拿不到 C 级证据**;
   脚本的框是"按靶子几何算出来、保证只罩住该动的点"的。
3. **夹点拉伸(593.3s、713.8–715.2s)无法复现** —— 无头环境无夹点。
4. **`栏选(F)/圈围(WP)/圈交(CP)` 三种选择方式未复现** ——
   视频里(206.4–212.6s)只展示提示、全部 `*取消*`。
5. **视频末尾讲师 `_u STRETCH` 撤销了拉伸**,因此末帧 ≠ 本课成果;
   脚本按"每种拉伸各做一次、不撤销"落地,这是有意的选择。
6. **`STRETCH` 对圆 / 椭圆 / 正多边形"整体移动而非变形"的行为未能演示** ——
   要演示它必须让交叉框**罩住这些对象的一部分**,而视频里讲师是用鼠标框的、
   位置不可知;脚本选择让这四个对象**完全落在框外**(证明"不碰就不动"),
   这是能拿到证据的最强版本,但**不是视频里演示的那一种**。
