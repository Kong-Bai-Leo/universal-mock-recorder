## 四、构造方式

样板课:成品的价值在**标注样式 `机械标注2.5`**,几何是承载标注的样张。
脚本按视频里量过的**每一个数值**各造一件:

| 图元 | 数值来源 |
|---|---|
| `RECTANG 0,0 50,23.1` | 宽 50 = **C**;高 23.1 **无出处**(见缺口 2) |
| `LINE 0,0→21.7,0` + `LINE 21.7,0→57.3,0` | 21.7 / 35.6 = **C**(DIMCONTINUE 链) |
| `CIRCLE 100,0 15.8`、`CIRCLE 100,-50 15.8` | 15.8 = **C**(三次回读) |
| `LINE 150,0→200,0` + `LINE 150,0→185.36,35.36` | 45° = **C**,用 35.36 = 50/√2 精确构造 |

标注:4 条 `DIMLINEAR`、2 条 `DIMRADIUS`、1 条 `DIMANGULAR` —— 命令种类与视频一致。

标注变量组按 **ISO 机械制图 2.5 号字规范**成套设置
(DIMTXT 2.5 / DIMASZ 2.5 / DIMCEN 2.5 / DIMEXE 1.25 / DIMEXO 0.625 /
DIMGAP 0.625 / DIMDLI 3.75 / DIMDEC 1),字体样式引用课时74 建的 `2.黑体-2.5`。

## 七、做不到的部分 / 数值找不到出处

1. **标注样式名 `机械标注2.5` 没有出处。** 讲师用 `D`(DIMSTYLE **对话框**)建样式,
   `-DIMSTYLE` 命令行版一次都没用过,81 条条带里**从未出现样式名**;
   本课也**没有 `dlg\` 对话框裁图**。这个名字是按课程主题起的。
2. **⚠ 矩形高 `23.1` 没有出处。** 视频只标了矩形的**宽**(49.97 / 50),高从未标注。
   23.1 是为了让矩形比例好看而定的。
3. **⚠ 全部标注变量(DIMTXT / DIMASZ / DIMEXE / DIMEXO / DIMGAP / DIMDLI /
   DIMCEN / DIMCLRD / DIMCLRT / DIMTAD / DIMJUST …)都没有出处。**
   本课整整 900 秒的核心内容就是在标注样式对话框里逐项设置这些值,
   但 CV 只抓了命令行条带,**对话框里的每一个数字都没被记录下来**。
   脚本填的是 ISO 2.5 号字的标准配套值(2.5 / 1.25 / 0.625 / 3.75),
   合理但**不是回读**。→ 要补证据,需要对 111–890s 的 DIMSTYLE 对话框停留时段做抽帧。
4. **颜色 `DIMCLRD 2` / `DIMCLRT 2`(黄)无出处**,同上。
5. **图元摆放位置(x = 0 / 100 / 150,y = 0 / −50)全部是布局值。**
6. **视频里画的图元最后全被取消**,终态图纸是空的;脚本重建这些样张是**主动偏离**,
   目的是让标注样式在成品里可见可验。
7. 68.7s 的 `49.97` 与 497.9s 的 `50` 差 0.03 —— 说明讲师中途把矩形重画/调整过。
   脚本取后者(50),因为它是终态且为整数。
