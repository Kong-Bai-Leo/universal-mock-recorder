`MLEADER` 的 **`选项(O)` 全参数链**

## 七、做不到的部分 / 数值找不到出处

1. **⚠ `MLEADERALIGN 指定间距 100` 没有落到脚本。** 576.5s 明确回显
   `指定间距 <0.000000>:100`,这是本课除三个选项参数外唯一的显式数值,
   而脚本里既没有 `MLEADERALIGN` 也没有 100 这个间距。5–7 号三条引线
   (y = −120 / −160 / −200)的**间距是 40**,与证据不符。
   要么补一条 `MLEADERALIGN … _S 100`,要么把三条的间距改成 100。
2. **⚠ 10 条引线的文字内容在命令流里完全找不到出处。**
   `MLEADER` 的文字走**就地 MTEXT 编辑器**,不经过命令行,所以
   `lkjas;lkfjkas` / `asfas` / `asfasf` / `窗户` / `lkasjfdkla` / `萨法` /
   `阿什拉夫卡\P死简历课` / `askIflask` / `2` / `3` 这 10 段文字
   **在 209 条命令行条带里一条都没有**。它们只可能来自画布画面(D 级),
   本文档无法把任何一段追溯到秒。**这是本课最大的证据缺口。**
3. **全部坐标无出处。** 835.2s 动态输入框里的 `17769.1419 / 3582.204` 是光标位置,不是拾取点。
4. `使用基线 [是/否] <是>: N`(857.3s)和 `内容类型 M`(861.6s)这两项演示未落到脚本。
5. `MLEADERCOLLECT`(合并)在视频里**两次都失败**(`已过滤 …,总计 0 个`),
   脚本不复刻,是忠实结果。
6. `_mleaderstyle`(多重引线样式管理器,129.6s)对话框里改了什么**没有任何回显和裁图**,
   脚本没有设任何 MLEADER 样式变量。
