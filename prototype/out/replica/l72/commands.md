# 课时72 其它工具 —— 命令流与证据

**蒙太奇覆盖:12/13 = 92%**(跳过 m09,该段是连续 QSELECT / 窗选取消,无数值)。

本课是**全课程证据密度最高的一课之一**:`MEASUREGEOM` / `DIST` 把每个图元的
距离、面积、周长、半径、直径、角度、体积**全部打在命令行上**,几乎不需要像素测量。

## 一、命令序列

`RECTANG` / `CIRCLE` / `LINE` / `PLINE`(画演示件,多数取消) →
**`DIST`** → **`MEASUREGEOM`**(距离 / 面积 / 周长 / 半径 / 角度 / 体积,全套) →
`DIM`(万能标注,取消) → `QSELECT`(快速选择) → `-LAYER` 改颜色 →
`ID`(点坐标) → **`PTYPE`(点样式)+ `POINT`** → `TYPE` / `TP`(工具选项板) →
`COPYCLIP` / `PASTECLIP` / `PASTEBLOCK`(剪贴板)

### 自校验(SOP 2.5「闭合方程」通道)

矩形只需两个独立量就唯一确定,而 `MEASUREGEOM` 同时给了**面积和周长**:

```
矩形1:  W + H = 886.8824/2 = 443.4412 ,  W·H = 46963.9800
        解得 W = 268.5826(与 137.8s 的 DIST 完全一致),H = 174.8586
矩形2:  W + H = 818.7477/2 = 409.37385 ,  W·H = 31839.8486
        解得 W = 304.9721 ,  H = 104.4017
体积:   31839.8486 × 2.8 = 89151.5760  ← 与 381.2s 回显逐位一致
```

矩形 1 的宽由**两条独立证据**(DIST 268.5826 与面积/周长方程)互证 —— **C 级,零推测**。

## 七、做不到的部分 / 数值找不到出处

1. **⚠ 角度演示的几何算错了。** 视频 333.2s / 335.6s 明确回读 `角度 = 61°`,
   但脚本的两条线是
   ```
   LINE 700,0 → 700,200        (竖直,90°)
   LINE 700,0 → 796.9,173.9    (与 X 轴成 atan(173.9/96.9) = 60.87°)
   ```
   两者夹角 = 90 − 60.87 = **29.1°**,不是 61°。
   看数值 (96.9, 173.9) ≈ 200·(cos61°, sin61°),说明当初是把 61° 当成"与 X 轴的夹角"算的,
   却又把第一条线画成了竖直线。**要复现 61°,应把第一条线改成水平**
   (`LINE 700,0 → 900,0`),或把第二条线改成 `700,0 → 874.9,96.9`。
   现在这份成品用 MEASUREGEOM 量出来会是 29°,与视频证据不符。
   另外 337.1s 的第二个夹角 **67°** 完全没有复刻。
2. **⚠ `PDMODE 34` / `PDSIZE 5` 没有出处,且与命令行回显相反。**
   786.5s / 788.4s 两次 `_point` 都明确打印 `当前点模式: **PDMODE=0 PDSIZE=0.0000**`。
   讲师随后开了 `PTYPE`(点样式对话框,779.3s / 847.0–860.0s,只回显「正在重生成模型。」),
   在对话框里选了哪个样式、多大尺寸**完全没有回显,也没有对话框裁图**。
   脚本的 34 / 5 是编的。要么改回 `PDMODE 0 / PDSIZE 0`(有 C 级证据),要么标为 L。
3. **`LINE 0,300 → 264.8333,300` 被拉直了。** DIST 回读的 `Y 增量 = 0.6250` 说明
   原线并非严格水平(倾角回显 180 是取整结果)。脚本按水平画,丢掉了 0.625 的 Y 差。
4. **全部摆放位置无出处** —— 视频里这些演示件散落在一张旧图上,拾取点从不回显。
5. **`QSELECT`(快速选择,447.5s 选中 2 个)未复刻** —— 选择集不进 DXF,无法验证。
6. **`-LAYER` 改颜色(111 / 2 黄)未复刻** —— 脚本没有建这些图层,本课重点不在图层。
7. **`COPYCLIP` / `PASTECLIP` / `PASTEBLOCK` 不复刻** —— 无头环境没有剪贴板(SOP 已列)。
8. **`TP`(工具选项板)、`TYPE`(列文件)不产生图元**,不复刻。
9. **`ID` 的 `X=2810.0027 Y=1528.0548`** 是**上一课图纸坐标系**里的点,与本复刻件坐标系无关。
