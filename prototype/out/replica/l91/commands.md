**97° 是本轮最有价值的交叉校验**:两臂外缘是 R504 与 R940.8 的公切线,
其与水平的倾角 = arcsin((940.8−504)/3360) = arcsin(0.13) = **7.4696°**,
与左毂**竖直中心线**的夹角 = 90 + 7.4696 = **97.47°** —— DIMANGULAR 按整数显示为 **97**。
也就是说,l90/l91 脚本里用解析公切线算出的切点
T1 = (∓65.52, ±499.72)、T2 = (3237.70, ±932.81) 被这条角度标注**独立证实**。

**823.2 vs 838.95(本轮新发现的一处"讲师自己画错")**:
终帧 `frames/end_00454.png` 是**双窗并排**:左窗是母版 `9.07代练`(标注为青色,竖直尺寸 **838.95**),
右窗是本课现场重画的副本(标注为黄色,同一条竖直尺寸量得 **823.2**)。
3360 与 425.75 在两窗完全一致,只有这一条差 15.75(1.9%)。
判定:**838.95 是设计值,823.2 是本课重画时的落点误差**。脚本取 838.95,并与 l90 保持一致。

**168.39(474.7s)**:讲师量一条应为 168 的边,得 168.39,随即 `ERASE` 删掉重标为 168。
按 R3 剔除,不进入脚本。

## 4. 本轮对脚本的修改

1. R336 缺口圆心 `(2934.25, **-631**)` → `(2934.25, **-838.95**)`
   —— `-631` 是上一轮的像素测量(M 级),`-838.95` 有 l90 的 `OFFSET` 回显 + 母版标注双重 C 级证据。
2. R336 圆弧起止:原来是硬套的 180° 半圆;改为按终帧实测的 **−13° → 142°**
   (起点 `3261.65,-914.55`,终点 `2669.45,-632.05`)。圆心/半径 C 级,张角 M 级。
3. 两条臂内缘 `(387.64, ±288.14)→(2619.64, ±580.50)`(M 级像素)
   → **解析值** `(411.39, ±291.15)→(2619.80, ±580.68)`:
   把外缘公切线沿其法向内移 268.8,再分别与 R504 / R940.8 求交得到。
   新端点到左毂圆心距 = **503.994**(应为 504),旧端点为 483.0(差 4.2%)。
4. 左毂右侧圆弧端点同步改为 `(411.39, ±291.15)`,使其真正落在 R504 圆上。
5. R336 的 DIMRADIUS 拾取点与 ZOOM 窗口按新圆心重算。
6. 新增 `DIMLINEAR` 把 **838.95** 竖直偏移落成可回读标注(原来只有 425.75)。
