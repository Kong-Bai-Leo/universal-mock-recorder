## 三、构造方式

本课主题是**标注样式**,几何只是承载标注的载体:

- `RECTANG 0,0 3429.5692,304` —— 长度取自 562.6s 的 `标注文字 = 3429.6`(见缺口 1);高 304 无回显,为承载高度。
- 5 条竖直分隔线 `x = 643 / 1190 / 1715 / 2620 / 3170`,把矩形分成 6 段。
  - 643 来自 627.4s 回读(C);
  - 1190 = 643 + 547,547 来自 630.7s 回读(C);
  - **1715 / 2620 / 3170 无命令行出处**(见缺口 2)。
- 6 条 `DIMLINEAR` 分段标注 + 1 条带公差的总长标注。
- 标注变量组(DIMTXT 40 / DIMASZ 40 / DIMEXE 20 / DIMEXO 10 / DIMGAP 12 / DIMDLI 200 / DIMTAD 1 / DIMJUST 0 / DIMSCALE 1 …)属于「线」「符号和箭头」「文字」「调整」四个选项卡,本课未展开讲,**这些数值在读过的 5 张对话框裁图里没有出现**,等级只能记 L(为让标注在 3429×304 的图上可读而选的配套值)。

## 六、做不到的部分 / 数值找不到出处

1. **`3429.5692` 的小数位没有出处。** 命令行只给到 `标注文字 = 3429.6`(1 位小数)。脚本用的 4 位小数值虽然四舍五入等于 3429.6,但那 4 位是**构造出来的**,不是读到的。诚实写法应是 3429.6。
2. **第 3 段及之后的分段长度与命令流冲突。** 635.0s 的 DIMCONTINUE 明确回读第 3 段 = **262**;而脚本的第 3 段是 1715−1190 = **525**,第 4/5/6 段 905 / 550 / 259.5692 在 56 条条带里**完全没有出处**。也就是说 5 条竖线里有 3 条(x=1715 / 2620 / 3170)属于无证据数值,且其中第一条与已有的 262 回读相矛盾。
3. 「线」「符号和箭头」「文字」「调整」四个选项卡的具体数值本课未展示,脚本中的 DIMTXT/DIMASZ/DIMEXE/DIMEXO/DIMGAP/DIMDLI 全部无出处。
4. 中文样式名「工业」无法在无头脚本里落地,用 GONGYE 代替。
