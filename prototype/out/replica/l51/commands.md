## ⚠ 数值找不到出处(重点)

1. **`DIMFXLON 1` 与 `DIMFXL 10` 与证据矛盾**。
   两张能看清「线」选项卡的抽帧(**879s** 和 **897s**,后者是全课最后一次修改对话框)
   都显示「固定长度的尺寸界线(O)」**复选框未勾选**、「长度(E)」= **1**(AutoCAD 默认值)。
   脚本把它们写成 `DIMFXLON 1` / `DIMFXL 10`,**在 86 张对话框抽帧和 6 张命令流蒙太奇里都找不到出处**。
   → **建议改回 `DIMFXLON 0` / `DIMFXL 1`**,或删掉这两行(它们本就是默认值)。
   这是本课**唯一一处明确的数值错误**。
2. **`DIMBASELINE 50.85,0 / 61.82,0` 的两个基线点**:命令行从未回显基线标注的值
   (蒙太奇里 `DIMBASELINE`/`DBA` 一次都没出现,只有 `DLI` 和 `DCO`),
   50.85 / 61.82 是**为演示基线标注而定的拾取点**,等级 **L**,不是课程数值。
   另外脚本设了 `DIMDLI 0`(基线间距 0),这会让基线标注**全部重叠**;
   若原意是演示基线标注,应在设 DIMDLI 0 **之前**做,否则视觉效果与视频不符。
3. **第二个矩形 `150,0 → 243.27,31.64`**:x 起点 150 是**布局值**(L),
   与课时50 里由 `DIMCONTINUE 56.62` 推出的 149.89 **不同**;两课并非同一张图,可以接受,但要写明来源不同。
4. **矩形高 31.64**:本课蒙太奇里**没有**出现 `标注文字 = 31.64`,它是**沿用课时50 的 469.0s 回显**。
   在本课范围内属于**继承值**,不是本课证据。
5. **`-LINETYPE _L ACAD_ISO02W100 acadiso.lin`**:对话框显示的线型名是 `ACAD_ISO02`(截断显示),
   完整名 `ACAD_ISO02W100` 是 acadiso.lin 中的标准名,属于合理补全,不算编造,但要写明是**补全**。
6. **顶部 GONGYE-MOBAN 那一段 DIM* 变量**(DIMTXT 2.5 / DIMASZ 2.5 / DIMEXE 1.25 / DIMEXO 0.625 /
   DIMDLI 3.75 / DIMGAP 0.625 / …):是 ISO-25 默认值,用来做"未改动样式"的对照组,
   **不是从本课对话框读出来的**,应标为默认值。

## 验证(verify.json)

```
counts: { LWPOLYLINE: 2, DIMENSION: 6 }
LWPOLYLINE#1 (0,0)(93.27,0)(93.27,31.64)(0,31.64) closed
LWPOLYLINE#2 (150,0)(243.27,0)(243.27,31.64)(150,31.64) closed
DIMENSION ×6: 全部 type 32(线性/基线)
```
- 两个矩形尺寸一致(93.27 × 31.64),符合"同一个图形、两套标注样式"的对照设计。
- **验证盲区**:verify.json **不回读标注的样式名与 DIM* 参数**,
  而本课的全部内容就是那 12 项参数。因此 `DIMFXLON`/`DIMFXL` 的错误
  **不可能被现有 verify 发现** —— 建议在 verify 里加 DXF `DIMSTYLE` 表的回读
  (至少 DIMCLRD 176 / DIMCLRE 177 / DIMEXO 42 / DIMEXE 44 / DIMFXLON 290 / DIMFXL 49)。

## 证据等级分布

- **C(命令行)**:93.27(唯一数值)、`找到 1 个`、`正在重生成 110 个修改过的图元`
- **D(对话框)**:「线」选项卡 13 个字段(11 项与脚本一致,**2 项矛盾**)
- **M**:无
- **L**:第二矩形位置、基线标注拾取点、所有尺寸线位置

## 做不到的部分

- 标注样式参数**永远不进命令行**,只能靠对话框抽帧,天花板是 D 级。
- 线宽下拉列表(297s / 474s)只截到 `1.58 / 2.00 / 2.11 mm` 三行,**讲师最终选了哪一档看不到**;
  脚本按对话框显示的 `ByLayer` / `ByBlock` 落地,不猜具体毫米数。
- 349–371s 的 `<线宽 >` 状态切换是显示开关(LWDISPLAY),不改图元,不复现。
- 基线标注在 `DIMDLI 0` 下会重叠,与视频观感不同(见 ⚠ 第 2 条)。
