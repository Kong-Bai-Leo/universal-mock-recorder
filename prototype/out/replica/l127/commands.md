> ## ⚠ 首要结论:本课的 `l127.scr` **不是**课时127 的复刻件
>
> `diff l126.scr l127.scr` 的结果是:**两者逐行相同,只差最后多了一条
> `_.BOX -60,-120,-200 460,120,0`(一块底板)**。
> 也就是说 `l127.dwg` = 课时126 的模型 + 一块底板。
>
> 而本次读到的 17 张蒙太奇显示,**课时127 的视频画的是另一个零件**,
> 有自己一整套尺寸(见下表),与课时126 的模型没有任何共同数值。
> **本课的复刻应判为"未完成/张冠李戴",这是本批 30 课里最严重的问题。**

## 三、现有 `l127.scr` 的构造方式(即课时126 的模型)

```
CIRCLE 100,0,100 r=100 / CIRCLE 100,0,240 r=30 / LOFT _ALL      圆锥台
CIRCLE 100,0,0   r=100 → EXTRUDE 100                            底盘
SPHERE 100,0,240 30                                             球头
UNION _ALL
BOX 200,-25,50 300,25,70;CYLINDER 350,0,0 50 75;
CYLINDER 350,0,35 30 40;BOX 325,-60,35 375,60,75
UNION ×2 → SUBTRACT
BOX -60,-120,-200 460,120,0          ← 本课唯一新增:一块 520×240×200 的底板
```
底板的 6 个坐标(−60 / 460 / ±120 / −200 / 0)**没有任何出处**;
它大致按"比模型包围盒(400×200×270)略大一圈"取的。

## 六、做不到的部分 / 数值找不到出处

1. **⚠⚠ 本课复刻件张冠李戴。** `l127.scr` 与 `l126.scr` 逐行相同(只多一条 BOX),
   而课时127 的视频画的是**另一个零件**。本课**没有任何一条命令、任何一个数值来自课时127 的命令流**。
   → 建议按上表的 C 级证据重做:
   `CYLINDER … 50 100`(127.6/131.0s)、`EXTRUDE … 200`(304.8s)、
   `FILLETEDGE 半径 15`(684.0s)、`UNION 找到 2 个`、`SUBTRACT`,
   并用标注链 20 / 25 / 40 / 50 / 72 / 77.7 / 100 / 128 / 140 与 R50 / R30 / R10 校核。
2. **新增底板的 6 个坐标无出处**(−60 / 460 / ±120 / −200 / 0)。
3. **本课没有 `MASSPROP` 回显**,无法做体积交叉验证。
4. **视频里 `JOIN` 三次都失败**(`已合并 0 个对象`),`INTERSECT` 两次报 `所选对象太多`,
   这两条命令在真正的复刻里都不应纳入。
5. **`-VPORTS _si`(单一视口)、`-VIEW _swiso/_top/_front`、`VSCURRENT` 都是显示操作**,不入 DXF。
6. **594.7s 动态输入框里的 `4128.041 / -300.9657` 是光标位置**,不是拾取点,不可用。
7. **全部拾取点、布尔运算的对象位置无回显** —— 即使重做,零件各构件的相对位置仍只能按画面推断(L)。
