**解析闭合(本轮的关键发现,一次解掉三个"规格页对不上"的遗留问题)**

已知:上边 y = 390+180 = 570、下边 y = −180(两条边分别切两圆的顶/底),总落差 750;
上边右端 x = 510.72(六边形圆顶切点),左上角 x = 510.72−825 = **−314.28**。
设斜边与水平的夹角 θ(顶角 = 180−θ),R75 倒角的切线长 t = 75/tan(θ/2),则

```
斜边线段长  = 750/sinθ  − t = 833.5
下边线段长  = 314.28 + 750/tanθ − t = 808.98
```

**只用第一式**解得 θ = **48.62131°**(顶角 **131.3787°**,DIMANGULAR 按整数显示成 131),
代回第二式得下边长 = **808.9741**,与规格页 **808.98 相差 0.006 单位(6×10⁻⁶ 相对误差)**。
两个独立的规格值被同一个 θ 同时满足 —— 这是自校验闭合,不是拟合。

结论:上一轮报告的"833.5 / 808.98 与我方值差 0.5%~0.9%"**是把 131° 当成了精确值**造成的;
真值 131.3787° 一给,两者立刻同时对上。**该遗留问题已解决。**

由此得到的精确坐标(已写进 `l90.scr`):

- 斜边 `LINE (-314.28,570) → (-865.2509,-55.4225)`,长度 833.50000
- R75 圆角 `ARC _C (-808.9741,-105)`,切点 (-865.2509,-55.4225) 与 (-808.9741,-180),
  两切点到圆心距离均 = 75.000
- 下边 `LINE (-808.9741,-180) → (0,-180)`,长度 808.9741

**511.6 连线**:上一轮用的是像素点 `(521.0661,210.2976)→(-10.3461,179.7024)`(长 532.3,与标注差 4%)。
本轮认出这条线的两个端点是 **五边形外接圆的最高点 (0,180)** 与 **六边形外接圆的最低点 (510.72,210)**,
长度 = √(510.72² + 30²) = **511.60035** —— 与 `DIMALIGNED = 511.6` 完全一致。
**该遗留问题已解决**,M 级像素坐标全部替换为 C 级解析坐标。

多边形朝向由 DXF 回读确认:五边形首顶点 (0,180)(顶点朝上),六边形首顶点 (690.72,390)(顶点朝右),
与规格页图形一致。
