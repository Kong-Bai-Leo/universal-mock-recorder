### 自校验(六边形闭合)

正六边形**外切于**半径 R = 399.93 的圆 ⇒ 边心距 = 399.93,边长 = 2 × 399.93 × tan30° :
```
2 × 399.93 × 0.5773503 = 461.7962      ← 905.1s 回读 461.8  ✓
外接圆半径 = 399.93 / cos30° = 461.7962 (同值)
```
**边长(461.8)和边心距(399.93)是两次独立回读,而它们由 tan30° 唯一互算 —— 自洽闭合。**

同理:`OFFSET 200` = 399.93 − 199.93,由两个 C 级半径派生,不是猜的。

## 四、构造方式

**左件(六圆花)**:`CIRCLE 0,0 120`(R120)+ `CIRCLE 120,0 60`(R60),
`-ARRAY _P` 环形阵列 6 项 360°,再 `ARC … _R 299.3` + `COPY` 得两段大圆弧。

**右件(六边形 + 双圆 + 修剪)**:
`CIRCLE 1400,0 199.93` → `OFFSET 200` 得 R399.93 →
`POLYGON 6 1400,0 _C 399.93`(外切六边形,边长 461.7962)→
`LINE 1400,0 2400,0`(长 1000)→ `CIRCLE 2400,0 199.97` →
`MOVE` 下移 199.97 → `ERASE` → 三条连接线 → `TRIM _F` 栏选修剪。

**每一个尺寸都来自命令行**,只有摆放位置(0,0 与 1400,0)、`DIMSCALE 12`
和标注引线的落点是布局值。

## 七、做不到的部分 / 数值找不到出处

1. **⚠ 环形阵列的项数与角度没有回显。** 448.5–460.9s 的 `_arraypolar` 只打印了
   `类型 = 极轴 关联 = 否` 和选项菜单,**「项目数」和「填充角度」始终没有键入回显**
   (讲师用的是夹点/功能区面板改的)。脚本的 `6` 项、`360` 度是由
   **六个 R60 圆的 DIMRADIUS 回读次数(六次)+ 花瓣几何**反推的,严格说是 C 派生而非直接 C。
2. **`OFFSET` 的偏移距离没有键入回显**(691.9s 直接取消)。脚本的 `200` 是
   399.93 − 199.93 的差值,由两个 C 级半径派生。
3. **两件的绝对位置(0,0 / 1400,0)和 1000 的方向是布局值** ——
   1000 这个距离本身是 C 级(743.3s),但"沿 X 正向"是排版选择。
4. **`TRIM` 的剪切边和被剪段没有坐标回显**,脚本用栏选点 (2150,−199.97)→(2250,−199.97)
   是按几何推的(L)。同理 `MOVE` 的 199.97 位移、`ERASE` 的拾取点 1750,0 都是 L。
5. **`DIMSCALE 12` 无出处**,为让标注在 ±400 的图上可读而设。
6. **视频里的 147.19 / 464.48 / 直径 200 三个回读值没有对应几何** ——
   它们标的是**旧图上的其它对象**(讲师在别处试标),复刻件里不存在。
7. **命名视图 `"zuqiu"`(163.7s)、`CANNOSCALE 1:5 / 1:8`、图框属性未复刻** ——
   不影响几何。
8. **本课几何全部落在"终态图纸"上,但视频里所有标注最后都 `*取消*` 了** ——
   脚本保留 11 条标注是主动偏离,目的是让这些 C 级数值在成品里可回读复验。
