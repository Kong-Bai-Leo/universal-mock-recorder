## ⚠ 数值出处核对 —— 关键发现

### 发现 1:脚本里几乎所有几何数值**都找不到出处**

`l8.scr` 用到的半径共 18 个不同值:
`15000, 14839.42, 7585.83, 2167.45, 11170.83, 6101.17, 2996.11, 2980.54,
8186.92, 4192.73, 3178.61, 2860.75, 2724.52, 2209.89, 4944.17, 5140.55,
5059.68, 4909.51`。

- **命令行里一个都没有出现过。**
- `out/replica/l8/` 目录下**没有任何测量产物**(无 `geo.json`、无 `end.json`、
  无 `geo_overlay.png`、无 `gen.py` / `build.py`),`out/lesson8_full/` 里也只有
  `trajectory/episodes/actions/input_events`,**没有 measure.py 的输出**。
- 因此按 SOP 铁律 R4(「任何数值必须有证据出处」)衡量,**这些数值目前不可追溯**。

**可以反推出的内部规律**(说明它们不是随手编的,但也**不能代替证据**):
每个分区的图形恰好被压进"网格中心 ± 15000"的方框里 ——
S2 的两个圆右/左边界分别落在 **65000 = 50000+15000** 和 **35000 = 50000−15000**;
S3 的矩形右边界 **115000 = 100000+15000**;S4 的直线起点 **135000 = 150000−15000**;
S5 的矩形跨 **−15000 … 15000**。
这说明作者是**把某一帧画布按比例归一化到 30000 单位宽**再取的坐标,
即**像素测量(M 级)**;但**测量结果没有随交付物保存,无法复现**。

### 发现 2:命令行里真实存在的高等级证据**全部被丢弃**

以下都是 SOP §2.5 明确指认的"高等级证据通道",本课有一大把,脚本却一个都没用:

- 直接输入的半径 / 直径:**1000**(84.5s)、**5000**(340.8s)、**1000**(395.0s)、
  直径 **1000**(220.3s)、直径 **10000**(722.9s);
- `DIST` 硬回显:**距离 = 5000.0000 / X 增量 = 5000.0000**(386.9s);
- `<默认值>` 回显(= 上一次实际用的半径):**5129.8273**(503.5s)、
  **5032.7830**(554.9s)、**2692.2141**(640.3s)、**3142.8129**(658.6s)、
  **17655.2385**(669.6s)、**1547.0054**(884.6s)、**10000.0000**(794.9s);
- `RECTANG` 尺寸:**长 1000 × 宽 1000**(159.4–160.8s);
- `LINE` 长度 **500**(189.6s)。

**建议(本次未改脚本)**:若要把本课提到 C 级,应当用上面这批数值重做几何 ——
特别是 5129.8273 / 5032.7830 / 2692.2141 / 3142.8129 / 17655.2385 / 1547.0054
这 6 个默认值回显,它们是"上一次实际画出的圆"的精确半径,是全课最硬的证据。
