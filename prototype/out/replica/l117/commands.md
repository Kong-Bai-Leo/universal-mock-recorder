# 课时117 实体编辑工具 —— 命令流

蒙太奇覆盖: 14/23 去重条带图 (≈61%)

## 命令序列
BOX / CIRCLE / RECTANG / REGION / SPHERE(半径提示默认 <57.7963>) →
**INTERFERE**(干涉检查: 嵌套选择 N / 设置 S / 检查第一组 K) →
**SLICE**(剖切: 平面对象 O / 曲面 S / z 轴 Z / 视图 V / xy / yz / zx / 三点 3;
保留两个侧面 B;XY 平面上的点 <0,0,0>) →
**THICKEN**(指定厚度 <100.0000>) → **XEDGES**(提取边) →
SOLIDEDIT 边(E) → 复制(C) / 着色(L) → PRESSPULL / EXTRUDE → VSCURRENT X 射线

## 数值证据
| 命令 | 参数 | 等级 | 出处 |
|---|---|---|---|
| THICKEN | 指定厚度 **<100.0000>** | C | 提示默认回显(= 上一次实际厚度) |
| SPHERE | 半径提示默认 **<57.7963>** | C | 提示回显(= 上一次实际半径) |
| SLICE | 选项全表 + 保留两个侧面(B) + XY 平面上的点 <0,0,0> | C | 选项回显 |
| INTERFERE | 嵌套选择(N)/设置(S)/检查第一组(K) | C | 选项回显 |
| SOLIDEDIT | 边(E) → 复制(C)/着色(L) | C | 选项回显 |

## 剔除
- 多次 *取消*
- INTERFERE 会弹出「干涉检查」模态对话框

## 复刻做法
1. BOX → **SLICE _XY**(z=150) **保留两个侧面(B)** → 得 2 个实体
2. BOX → **SLICE _3**(三点定面) 保留一侧
3. BOX → **SLICE _ZX** 保留一侧
4. PLANESURF(平面曲面) → **THICKEN 100** → 实体
5. **SPHERE 半径 57.7963**(用提示默认值这条 C 级证据)
