# 课时105 拉伸工具 —— 命令流

蒙太奇覆盖: 27/33 (82%)

## 命令序列
LINE / PLINE / CIRCLE / ARC / RECTANG / POLYGON(5 边, 外切于圆 C) / ELLIPSE / SPLINE
→ BOUNDARY(BO,已创建 3 个多段线) / JOIN(3 条线段合并为 1 条多段线) / REGION(已创建 1 个面域)
→ EXTRUDE ×N → MIRROR / WIPEOUT / TRIM / ERASE

## 教学要点(错误回显,证据 C)
- 「无法拉伸选定的对象」——直线不能拉伸
- 「不能从打开的曲线创建实体」
- 「不能扫掠或拉伸自交的曲线」
- 「不能扫掠或拉伸非平面对象」
