## 验证(verify.json)

```
l32.dxf  counts = { CIRCLE: 300, LWPOLYLINE: 12 }
CIRCLE = c(0,0) / c(0,484.5247) / c(0,969.0494) / c(484.5247,0) / …  r 161.5083
```

**三条自校验,全部通过:**

**1. 实体计数**
`3 × 4 = 12` 个圆 + `18 × 16 = **288**` 个圆 = **300** ✓ 与 `CIRCLE: 300` 完全一致;
`3 × 4 = 12` 个矩形 ✓ 与 `LWPOLYLINE: 12` 完全一致。
**这直接证明「行 18 / 列 16」(601.5s 的 C 级值)确实生效**。

**2. 圆心坐标 = 间距的整数倍,逐位对上 DIST 回显**
DXF 里前几个圆心是 `(0,0)`、`(0, **484.5247**)`、`(0, **969.0494**)`、`(**484.5247**, 0)` ——
- `484.5247` 与 **219.4s 的 `DIST 距离 = 484.5247`** 逐位一致 ✓
- `969.0494` 与 **199.7s 的 `标注文字 = 969.05`** 一致 ✓

**3. 半径 161.5083 = 323.0165 ÷ 2**
DXF 半径 `161.5083`,与 **508.5s 的 `DIST 距离 = 323.0165`** 恰好差 2 倍 ✓
且 `3 × 484.5247 + 2 × 161.5083 = **1776.591**`,
与 **307.8s 的 `DIST 距离 = 1776.5907`** 吻合到小数点后 3 位 ✓
**—— 四条独立的 DIST/标注回显互相闭合,这是本课最强的证据环。**

**本课的标注实体未落进 DWG**(视频里的 3 个 DIMALIGNED 都被 `*取消*` 了),
故成品无标注回读值,上述 D 级值只作为文档证据使用。

## ⚠ 数值出处核对 —— 关键发现

### 发现 1(好的一面):第 1 组阵列的**每一个数值都能追溯,而且互相闭合**

`161.50825` / `484.5247` / `4` 三个数值分别来自
`DIST 323.0165`、`DIST 484.5247`、`<4>` 默认回显,
并被另外三条独立回显(`标注 484.52`、`标注 969.05`、`标注 1292.07`、
`DIST 1453.5742`、`DIST 1776.5907`)**交叉验证**:

```
323.0165 ÷ 2                       = 161.50825   ← 半径
3 × 484.5247                       = 1453.5741   ← 与 DIST 1453.5742 吻合
3 × 484.5247 + 2 × 161.50825       = 1776.5906   ← 与 DIST 1776.5907 吻合
2 × 484.5247 + 2 × 161.50825       = 1292.0659   ← 与 标注 1292.07 吻合
2 × 484.5247                       =  969.0494   ← 与 标注 969.05  吻合
```

**五条方程全部闭合** —— 这是 SOP §2.5 说的"尺寸链自校验",本课做到了。
