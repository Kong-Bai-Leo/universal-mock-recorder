# 课时46 多行文字(二)—— 命令流与证据

> **本课的性质**:全程在 **MTEDIT 就地文字编辑器**内做格式化(字体/字高/斜体/上标/段落合并/背景遮罩)。
> 编辑器内的操作**不经过命令行**,所以本课的命令流几乎是空的 —— 这是事实,不是漏读。

## 命令流(读了 3/3 张蒙太奇,覆盖率 100%)

| 时间 | 命令行回显 | 说明 |
|---|---|---|
| 25.0s | `命令: _mtedit` / `自动保存到 …sv$` | 进入就地编辑器 |
| 32.6–34.1s | `命令: CO` `COPY 找到 1 个` `当前设置: 复制模式 = 多个` `指定基点或 [位移(D)/模式(O)] <位移>:` → `指定第二个点或 [阵列(A)] <使用第一个点作为位移>:` | COPY 复制文字块 |
| 34.6 / 38.9s | `*取消*` | **COPY 被取消,未产生副本** |
| 50.4s | `*取消*` | — |
| 113.3–138.7s | `MTEDIT _mtedit` 连续 8 次 | 编辑器内格式化,命令行无参数 |
| 261.1–304.8s | `指定对角点或 [栏选(F)/圈围(WP)/圈交(CP)]:` → `*取消*` ×6 | 窗选未确认 |
| 306.2–611.5s | `MTEDIT _mtedit` 连续 9 次(359.0 / 360.0 / 414.2 / 421.4 / 421.9 / 426.2 / 457.4 / 611.5s) | 同上 |
| 901.4s | `命令: _mtedit` | 最后一次编辑 |
| **902.4 / 903.4s** | `命令: _u MTEDIT GROUP` | **撤销** 901.4s 那次编辑 |

**命令行里没有出现过任何数值参数** —— 无字高、无框宽、无坐标、无角度。

## 帧图回读(D 级,来自 `cv/cmdmont` 中夹带的画面条与另抽帧)

| 时间 | 读到 | 用途 |
|---|---|---|
| 130s | 编辑器功能区字高 **1000**(讲师先输错) | 剔除 |
| 430s / 610s | 字体 **黑体**、字高 **10**、斜体(I) 处于按下状态 | → 脚本 `_H 10` 与 `\f…|i1|` |
| 610s | 出现上标 "绿2上" | → 正文里的上标演示 |
| 900s | 左侧副本带**红色背景遮罩**;右键菜单含 `合并段落 / 删除格式 / 背景遮罩(B)…` | 演示项 |

## 剔除

- 34.6s / 38.9s:`COPY` 给完基点后 `*取消*`,**没有生成副本**。
- 50.4s:空 `*取消*`。
- 261.1–304.8s:6 次窗选 `指定对角点` → `*取消*`。
- **902.4s `_u MTEDIT GROUP`**:撤销了 900s 那次段落合并 / 上标编辑,
  因此终态回到 **915s 画面上的四段文字**,脚本按终态构造。

## 构造

| 产物 | 来源 | 等级 |
|---|---|---|
| 4 个 MTEXT 的正文 | 915s 终帧画面转录 | **D** |
| 字高 `_H 10` | 430s / 610s 编辑器功能区字高框读值 | **D** |
| `\fSimHei|b0|i1|c134|p2;` 里的 `i1`(斜体) | 430s / 610s 斜体按钮处于按下态 | **D** |
| `b0`(非粗体)、`c134`(GB2312 字符集)、`p2` | AutoCAD 内联格式码的固定写法,非课程数值 | 记法 |
| 对正 `_TL` | MTEXT 默认对正 | 默认 |
| 框宽 `_W 60 / 45 / 70 / 70` | **无出处**,见下 | **⚠ L** |
| 插入点 `60,130 / -70,100 / 10,100 / 160,100` | **无出处**,见下 | **⚠ L** |

## ⚠ 数值找不到出处

1. **框宽 60 / 45 / 70 / 70**:命令行全程没有 `-MTEXT` 的 `宽度(W)` 分支,画面上的文字框
   由鼠标拖出且无标注。这四个值只能是**照终帧比例定的布局值**,等级 **L**,不是 C 也不是 D。
2. **插入点 60,130 / -70,100 / 10,100 / 160,100**:同上,纯 L 级排布,**不代表原图坐标**;
   它们的作用只是让四块文字互不重叠。
3. **字体 `simhei.ttf` / `\fSimHei`**:与 430s / 610s 读到的「黑体」一致(SimHei 即黑体),
   这一项**有 D 级出处**,与课时43/44/45 的情况不同,可以保留。
4. **`_H 10` 的 10** 只有 D 级(功能区读值),没有命令行回显。130s 时功能区显示过 **1000**,
   是讲师输错后改回的,已剔除。

## 验证(verify.json)

```
counts: { MTEXT: 4 }
```
- 4 个 MTEXT 与 915s 终帧上的四段文字对应(1 段英文 + 3 段中文,其中第 2 段是被强行换行的窄框版本)。
- **验证盲区**:verify.json 未回读 MTEXT 的字高、框宽与内联格式码;
  本课的全部结论(字高 10 / 斜体)都落在这些未回读的字段上,目前**无独立复验**。
  建议补 DXF 组码 40 / 41 与文本内容的回读。

## 证据等级分布

- **C(命令行)**:仅 `COPY 找到 1 个`、`复制模式 = 多个`、`_u MTEDIT GROUP` 这几条**过程**证据,**无任何数值**
- **D(画面/功能区回读)**:字高 10、字体 黑体、斜体开、上标、背景遮罩、正文内容
- **L(布局)**:全部框宽与插入点
- **M**:无

## 做不到的部分

- **就地编辑器内的一切格式化都不进命令行**:字高框、字体框、斜体/上标按钮、段落合并、
  背景遮罩颜色 —— 只能靠抽帧读,永远升不到 C 级。
- **背景遮罩**(900s 左侧副本的红色遮罩)在无头 `-MTEXT` 里无对应参数,**未复现**。
- **上标**("绿2上")被 902.4s 的 `_u` 撤销,终态无上标,故脚本不含上标格式码。
- COPY 出的副本被取消,不存在于终态,不复现。
