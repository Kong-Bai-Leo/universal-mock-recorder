# 课时113 扫掠的设置补充 —— 命令流

蒙太奇覆盖: 17/17 去重条带图 (=330/330 条带, 100%)

## 命令序列
CIRCLE 半径 **4** → CIRCLE 半径 40(*取消*) → CIRCLE 半径 **2** →
SWEEP + **对齐(A) 否(N)** / **基点(B)** / **比例(S)** / **扭曲(T)** →
RECTANG 尺寸(D) **60 × 60** → COPY 阵列 **5** / **10** → JOIN(17 → 1 条多段线) →
VIEW _front/_top → ISOLATEOBJECTS / HIDEOBJECTS / UNISOLATEOBJECTS →
特性面板: 轮廓旋转 0 / 沿路径扭曲 0 / 沿路径缩放 1

## 数值证据
| 命令 | 参数 | 等级 | 出处 |
|---|---|---|---|
| CIRCLE | 半径 **4** | C | t≈79s 键入 |
| CIRCLE | 半径 <4.0000>: **2** | C | t≈118s 键入 |
| RECTANG | 尺寸(D) 长 **60** 宽 **60** | C | t≈200–202s 键入 |
| COPY | 阵列(A) 项目数 **5**, 后又 **10** | C | 回显 |
| JOIN | 17 个对象 → 1 条多段线 | C | 回显 |
| SWEEP | 对齐 [是(Y)/否(N)] <是> → **N** | C | 选项回显 |
| 特性面板 | 轮廓旋转 **0** / 沿路径扭曲 **0** / 沿路径缩放 **1** | D | 抽帧读数 |

## 剔除
- t≈84s CIRCLE 半径 40 *取消*
- SWEEP 报错「路径曲线与轮廓曲线共面或与轮廓曲线的平面相切, 无法扫掠」

## 复刻做法(四个扫掠, 逐一演示一个设置)
1. 圆 r=**4** 沿斜线路径(长 250)扫掠 —— 默认设置
2. 圆 r=**2** + **扭曲(T) 90°**
3. 圆 r=**4** + **比例(S) 2**
4. 矩形 **60×60** + **对齐(A) 否(N)**
