## 二、⭐ 关于「OFFSET 35 未落到几何」这条已知缺口 —— **本次复核认定:该缺口不成立,已闭合**

三条独立证据把 35 钉死在几何上:

1. **94.1s 命令行键入 `OFFSET … 35`**(C);
2. **635.5 / 637.4 / 639.4s 三次 `DIMLINEAR 标注文字 = 35`**(C)—— 说明成品上确实存在一个 35 的尺寸;
3. **解析闭合**:主体矩形宽 **50**(878.4s 回读)、圆角半径 **15**(715.2s 回读),
   `FILLET _R 15` 在右上角产生的切点必然是 (50, 30−15) 和 (50−15, 30) = **(35, 30)**。

`verify.json` 回读的第一条多段线顶点为
`(0,0) (50,0) (50,15) **(35,30)** (0,30)` —— **35 就在顶点表里**。

所以 `OFFSET 35` 落地为 **x = 35 的那条竖直定位线**,最终体现为轮廓顶点 (35,30)。
原先"Y 向用 30+20 所以 35 没落地"的判断,把 35 当成了 Y 向尺寸;
实际上 35 是 **X 向**的(偏移的是竖直构造线,拾取点 (0,20)、侧点 (10,20) 都在水平方向上)。
Y 向的 30(矩形高)与 20(底部凸块深)各有自己的 C 级出处(150.7s / 241.9s / 351.8s)。

## 三、验证(MASSPROP 解析复核 —— 零误差)


## 五、构造方式

```
XLINE _V 0,0 + XLINE _H 0,0
OFFSET 35   → x = 35 定位线           (C)
OFFSET 30   → y = 30 定位线           (C)
OFFSET 50   → x = 50 定位线           (C)
RECTANG 0,0 50,30                     (50、30 均为 C)
FILLET _R 15 + FILLET 50,15 35,30     (15 为 C;切点 (50,15)(35,30) 解析唯一)
PLINE 50,0 80,0 80,30 70,30 70,10 50,10 _CL     右侧 L 形块
PLINE 20,0 20,-20 50,-20 50,0 _CL               底部 30×20 凸块 (C)
ERASE 构造线
EXTRUDE 主体 70 / 右块 50 / 底块 20    (70、50 为 C;20 见缺口 1)
UNION ×2
```

## 七、做不到的部分 / 数值找不到出处

1. **⚠ 右侧 L 形块的绝对宽度 80 / 70 没有直接出处。**
   `50 → 80` 的 30 有 C 级(216.0s 的 `LINE … 30`),`70 → 80` 的 10 有 C 级(226.1s),
   但把它们**接在 x=50 右侧**这一步是几何推断。底块的拉伸高 `20` 同理
   (20 有 C 级回读,但那是截面尺寸,拉伸高度没单独回显)。
   —— 不过体积解析值与 MASSPROP 零误差吻合,反证这套拼装是对的。
2. **⚠ 462.7s 的 `EXTRUDE … 100` 没有落到脚本。** 这是一次 C 级键入,
   但脚本的三次拉伸是 70 / 50 / 20。它很可能属于被取消的试做(464.2s 立刻 `*取消*`)。
3. **⚠ 视频里做的是 `SUBTRACT`(390.7–399.8 / 479.0–485.3s,十余次),脚本做的是 `UNION`。**
   视频的差集全部在选择阶段被 `*取消*`,没有一次走完;而按体积解析
   (三块相加 = 138620.0211,与 MASSPROP 一致)可知**终态是并集**。
   命令层面因此与视频不一致,几何层面正确。
4. **`PRESSPULL` 未复刻** —— 无头版 PRESSPULL 需要面内点击,SOP 已规定改用 `EXTRUDE`。
5. **`MASSPROP` 的原始回显不在本次覆盖的条带里**,体积值由解析式独立复核。
6. **全部拾取点、`MOVE 找到 10 个` 的位移无回显**,不影响最终几何(整体平移不改变体积和相对关系)。
