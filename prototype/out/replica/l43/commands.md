## ⚠ 数值找不到出处(重点)

1. **`_.TEXT 0,5 2.5 45 按时发送` 里的旋转角 45**:9 张蒙太奇全部读完,`指定文字的旋转角度` 这一问在
   130.1s / 132.0s / 137.3s / 148.4s / 152.2s / 160.9s / 163.3s / 169.0s / 170.5s / 187.3s / 232.9s / 234.3s
   共 12 次出现,**每一次都是 `<0>` 并直接回车**,命令流里**没有任何一处输入 45**。
   该值不可追溯,建议改为 0,或降级标注为"画面倾斜文字的目测角度(M 级)"。
2. **字体 `simhei.ttf`**:脚本 `-STYLE Standard simhei.ttf` 与视频证据冲突。视频 817–857s 的 `'_style`
   下拉框里 856.1s 高亮的是 **微软雅黑 Light**(825.4s 讲师红圈同一位置)。`simhei` 在命令流/画面中均未出现。
   注:视频最终并未按"确定"落实字体切换(857.6s 后回到 `*取消*` 序列),因此严格说本课**字体没有被改动**;
   脚本指定 simhei 是为了让中文能落进 DXF 的工程折衷,属于**复现手段**而非课程内容,应在此写明。
3. **插入点坐标**:命令行从不回显 TEXT 起点(唯一一次是 684.7s 的动态输入框,值为 3075.9927/1611.4502)。
   脚本的 `0,40 / 0,30 / 0,20 / 0,5` 是自定的等距布局,**只有 L 级**,不代表原图坐标。

## 验证(verify.json)

```
counts: { TEXT: 4 }
TEXT: "单行文字"@(0,40) / "阿卡丽司法局爱丽丝副科级"@(0,30) / "哈设计课六发哈萨克"@(0,20) / "按时发送"@(0,5)
```
- 实体类型与数量与视频一致(本课只产生单行 TEXT,无其它实体)。
- 视频 921.9s `1 个对象已更改` 对应脚本末尾 `SCALETEXT _L … 10`;DXF 中被缩放的那条高度应为 10,
  其余 3 条为 2.5 —— 该项 verify.json 未回读高度,属**验证盲区**。

## 证据等级分布

- **C(命令行)**:文字高度 2.5、旋转默认 0、对正选项全表、SCALETEXT 新高度 10、`找到 1 个` / `1 个对象已更改`
- **D(对话框/画面读值)**:字体下拉框「微软雅黑 Light」、4 条文字的内容字符串
- **L(布局排列)**:4 条文字的插入点
- **无出处**:旋转角 45

## 做不到的部分

- TEXT 的**文字内容**永远不在命令行回显,只能靠画面转录,无法升到 C 级。
- 视频里的**夹点拉伸**(367–537s,约 20 次)是交互演示且全部被撤销,无稳定终态,不复现。
- `CUTCLIP`(382.7s)在无头环境无剪贴板,不纳入。
- `'_style` 的字体切换未被讲师确认落地,因此 DWG 里的样式字体**不是**课程结论,不作为验证项。
