## 2. 剔除的取消/撤销/重画

- 66–90s、117–138s:DIMRADIUS 起手后 *取消* 多次(讲师在挑对象)
- 143.5s:`DIMLINEAR 标注文字 = 150` 后 *取消*
- 217–229s:`COPY 找到 1 个` **两次 *取消***
- 233–239s:夹点 `** 拉伸 **` **三次 *取消***
- 240.0s:`_u INTELLIZOOM` —— **显式撤销**
- 245–262s:`DIMCONTINUE` 选择连续标注 **两次 *取消***
- 271–300s:`MOVE 找到 1 个` **五次 *取消***,期间反复出现"标注已解除关联"
- 318.2s:`CANNOSCALE 1:25 → 1:20` 后立刻 *取消*
- 332–346s:4 次窗选 *取消*,"标注已解除关联"
- 348–375s:`MATCHPROP` **四次**,全部 *取消*
- 404–411s:`ERASE 找到 1 个` ×3(删掉标错的标注),410.4s 弹出"文字替代" —— **重标**
- 452–457s:TRIM *取消*
- 697–711s:`JOIN` 两次都失败("已合并 0 个对象,操作中放弃了 3 个 / 2 个对象")

**注意**:`ERASE`(404–411s)删掉的是标注实体本身,不影响几何;
`PEDIT`(668.2s)"4 个对象已转换为 1 条多段线"只改实体类型,几何不变,未纳入脚本。

## 4. 本轮对脚本的修改

l93 的脚本是 l92 的超集(多出下方 R1500 外廓弧与两处 R300 圆角),
因此 l92 的两处修改**同样应用到 l93**:

1. `_.CIRCLE 0,0 1200` → `_.ARC _C 0,0 1131.3708,400 1131.3708,-400`
   (R1200 外廓修剪掉右侧伸嘴开口那 38.94°)
2. 伸嘴上下缘加 **R150** 过渡圆角(圆心 `(1272.7922, ±450)`)与 **R300** 过渡圆角
   (圆心 `(1525.7359, 0)`),两条直线的端点相应缩短
3. 新增 2 条 `DIMRADIUS`(R300 / R150 过渡圆角)

推导过程与数值见 `../l92/commands.md` 第 4 节(同一零件,不重复)。

l93 独有的、上一轮已有的部分保持不变并复核通过:
- R1500 外廓弧 `(0,0) r1500 258°→335°`
- 两处 R300 连接圆角 `(-249.4940,-1173.7771)` 与 `(1087.5693,-507.1419)`,
  DXF 回读半径 **300.0018 / 300.0001**,与 `DIMRADIUS = 300` 一致

## 6. 做不到的部分

- **香蕉槽端头与外廓之间的两处 R150 连接圆角**:终帧左下角有 `R150 R150` 两个标注,
  半径是 C 级(21 次 DIMRADIUS = 150),但**拾取点/起止角在 13 张蒙太奇里全无回显**,
  只能像素测(M 级)。按"优先 C 级"原则不做,明确列为缺口。
- **`JOIN` 失败**:视频里讲师两次 JOIN 都返回"已合并 0 个对象",
  说明他自己的图元也没能连成闭合多段线;脚本保持散实体,与视频一致。
- `PEDIT` 的"4 个对象转 1 条多段线"(668.2s)只影响实体类型,未纳入。
- `MATCHPROP`(4 次,全部 *取消*)无头版不存在,未纳入。
- `CANNOSCALE 1:20`(318.2s)标完即 *取消*,脚本用 `DIMSCALE 30` 等价落地。
