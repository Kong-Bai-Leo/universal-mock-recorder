# 课时104 几何体绘制 —— 命令流

蒙太奇覆盖: 18/18 (100%)

## 命令序列
BOX(长度 L) → BOX(立方体 C) → RECTANG(尺寸 D) → EXTRUDE →
CYLINDER ×N → CONE → WEDGE → PYRAMID(4 个侧面, 外切) → SPHERE →
TORUS → POLYSOLID → ISOLINES

## 数值证据 (C)
| 命令 | 参数 | 出处 |
|---|---|---|
| BOX | 长度 800 / 宽度 600 / 高度 1000 | t≈103–142s **键入** |
| RECTANG | 尺寸(D) 长度 600 / 宽度 800 | t≈347–349s **键入** |
| EXTRUDE | 高度 1000 | t≈361s **键入** |
| SPHERE | 半径 10000 | t≈608.6s **键入** |
| CONE | 高度 -1000 | t≈543.8s **键入** |
| CONE | 底面半径提示默认 `<2626.2954>` | t≈533.3s(即上一个圆锥的实际底面半径) |
| CYLINDER | 提示默认 `<824.8525>` 半径 / `<1670.5623>` 高度 | t≈440.6s(即上一个圆柱的实际值) |
| PYRAMID | 4 个侧面,外切 | 选项回显 |
| POLYSOLID | 高度 = 80.0000,宽度 = 5.0000,对正 = 居中 | 命令头部回显 |
| ISOLINES | 4 | 回显 |

## 剔除
CYLINDER 在 t≈445.9s 一次 *取消*;右键菜单误触若干次。

## 复刻
上表中"键入"的四组数值 + 两组提示默认值构成了 5 个实体,全部用 MASSPROP 对解析体积校验。
