## 构造

`l11.scr` 落地实体全部来自**像素测量**(`geo.json`,t=**410.0s**,`--color white`),
按 `--flipy 597` 映射:

| geo.json | l11.scr | 换算 |
|---|---|---|
| `ellipse c=[354.2,326.6] a=62.7 b=28.2 rot=90` | `_.ELLIPSE 354.200,333.100 354.200,207.700 28.200` | y = 597−326.6 = 270.4;270.4±62.7 = 333.1 / 207.7 |
| `ellipse c=[354.2,326.6] a=163.5 b=63.0 rot=180` | `_.ELLIPSE 517.700,270.400 190.700,270.400 63.000` | 354.2±163.5 = 517.7 / 190.7 |
| `arc c=[354.6,288.6] r=22.8 a0=338 a1=202` | `_.ARC _C 354.600,308.400 375.740,299.859 _A 224.000` | y = 597−288.6 = 308.4;夹角 = 202−338+360 = 224 |
| `arc c=[354.6,366.6] r=21.2 a0=162 a1=19` | `_.ARC _C 354.600,230.400 334.438,236.951 _A 217.000` | 夹角 = 19−162+360 = 217 |
| 11 条 lines | 11 条 `_.LINE` | y 翻转,长度/角度逐条一致 |

**没有第 12 条线 / 第 3 个椭圆**,脚本里不存在测量之外的实体。

## 验证(verify.json)

```
l11.dxf  counts = { LINE: 11, ELLIPSE: 2, ARC: 2 }
  ELLIPSE #1 c=[354.2,270.4] major=[0.0, 62.7]   ratio=0.4498  ← 28.2/62.7 = 0.4498 ✓
  ELLIPSE #2 c=[354.2,270.4] major=[163.5, 0.0]  ratio=0.3853  ← 63.0/163.5 = 0.3853 ✓

```
长短轴比、半径、起止角与 `geo.json` **逐一吻合**。本课无标注实体。

## 数值出处核对 —— 发现

- 落地实体的每个数字都能在 `geo.json` 里对上,**没有发现无出处(疑似编造)的数值**。
- ⚠ 命令行里真实出现过的 C 级数值 —— 半轴 **500**(226.1s)、**1000**(308.6s)、
  绕长轴旋转 **60°**(527.0s)、以及 `<468.4850>` 的圆半径默认值回显(85.0s)
  —— **一个都没有被脚本采用**。原因是这些演示椭圆在终态帧(410s)上已不存在,
  属"取舍"而非编造;但也意味着本课证据等级停在 **M**。
- 测量帧选的是 **t=410s**(全片 604s),不是终态。这是刻意的:410s 之后
  478–574s 全在做椭圆弧的**选项讲解**,画布内容反而更乱。选帧依据在此说明,不是随意取的。

## 做不到的部分

1. **绝对尺寸未知**:终态无标注,采用"1 像素 = 1 图形单位"约定,只保证形状比例。
2. **椭圆弧(ELLIPSE _A)未落地**:478–574s 演示的椭圆弧 + 起点/端点角度 + 参数(P)
   + 夹角(I) + 绕长轴旋转(R) 这一整套,脚本里一个都没有 ——
   落地的 2 个都是完整椭圆。
3. 226s / 308s 的半轴 500 / 1000 无法落地(对应实体在测量帧上已不存在)。
