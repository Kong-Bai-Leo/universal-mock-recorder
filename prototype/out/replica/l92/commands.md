## 4. 本轮对脚本的修改(两个已知缺口都补上了)

**缺口 1:外轮廓未按目标图修剪 R1200 圆(保留整圆,视觉上有交叠)**

改为 `_.ARC _C 0,0 1131.3708,400 1131.3708,-400` —— 圆心 (0,0)、R1200、
从 **+19.4712° 逆时针到 340.5288°**(共 321.06°),右侧伸嘴开口处被切掉。

19.4712° 不是量出来的:它是 **R150 过渡圆角与 R1200 圆的切点角**,由下式定死
(见缺口 2),且与终帧角向扫描的"R1200 起于 ≈18°"吻合。

**缺口 2:伸嘴过渡圆角用直线代替**

原来伸嘴上下缘直接从 R1200 圆上的交点 `(1161.8950, ±300)` 起线(相当于硬折角)。
本轮按 `FILLET R150`(C 级)解析求出真正的过渡圆角:

- 圆角圆心到 (0,0) 距离 = 1200+150 = **1350**,到直线 y=300 距离 = 150 ⇒ y_c = 450,
  x_c = √(1350²−450²) = **1272.7922**
- 切点:圆上 (1131.3708, 400)(= 1200∠19.4712°)、线上 (1272.7922, 300)

同理补上伸嘴与斜边之间的 **R300** 过渡圆角(规格页/终帧标注 `R300`):
两线夹角 135°,切线长 = 300/tan67.5° = 124.2641 ⇒ 圆心 **(1525.7359, 0)**,
切点 (1525.7359, 300) 与 (1737.8680, 212.1320)。

于是:
- `LINE 1161.8950,300 → 1650,300` 改为 `LINE 1272.7922,300 → 1525.7359,300`
- `LINE 1650,300 → 1950,0` 改为 `LINE 1737.8680,212.1320 → 1950,0`
- 新增 4 段圆角 ARC(上下各一段 R150 + 一段 R300)
- 下缘同样处理(镜像)
- 新增 2 条 `DIMRADIUS`(R300 与 R150 过渡圆角),拾取点分别取在弧中点
  `(1640.5409, 277.1638)` / `(1186.3200, 327.5600)`,并各自先 `ZOOM _W` 到 ~320 单位窗口
  (按 SOP 坑表:DIMRADIUS 的拾取点必须落在圆周上且在当前 ZOOM 窗口内)

**排错记录**:第一次回放时把 R1200 写成 `_.ARC _C 0,0 1131.3708,-400 1131.3708,400`,
AutoCAD 的 ARC 是**逆时针从起点到终点**,这样只得到 38.94° 的短弧,
后面 `DIMRADIUS` 在 (0,1200) 拾取不到对象,吃掉了后续命令并挂到超时。
调换起止点后正常。已记入本课经验。
