# 课时106 拉伸工具(续) —— 命令流

蒙太奇覆盖: 22/31 (71%)

## 命令序列
RECTANG / LINE / PLINE → EXTRUDE 的各选项:
模式(MO: 实体 SO / 曲面 SU)、方向(D)、路径(P)、倾斜角(T)`<0>`、表达式(E)
→ COPY(阵列 A,项目数 5) → MOVE / ERASE

## 教学要点(错误回显)
「建模操作错误」 Error Code 85006 / 104004

## 数值证据 (C)
- COPY 阵列 项目数 **5**(键入)
- 倾斜角提示默认 `<0>`
- EXTRUDE 高度提示默认值: 53934.4339 / 48079.5132 / -253606.8959 / -175043.0188 / -340697.9595

## 无法取得的证据
轮廓平面尺寸、方向矢量、路径全部鼠标拾取 => 无法构造几何。
