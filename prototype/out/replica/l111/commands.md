# 课时111 旋转工具(REVOLVE) —— 命令流

蒙太奇覆盖: 18/18 去重条带图 (=360/360 条带, 100%)

## 命令序列
RECTANG / PLINE / REGION(创建面域) → **REVOLVE**:
- 模式(MO) → 实体(SO) / 曲面(SU)
- 轴: 对象(O) / X / Y / Z / 轴起点+轴端点(两点)
- 角度: **360**, **150**, **90**;选项 起点角度(ST) <0.0>, 反转(R), 表达式(EX)
→ ROTATE / MOVE / COPY 阵列(A) 项目数 4 → ERASE

## 数值证据
| 命令 | 参数 | 等级 | 出处 |
|---|---|---|---|
| REVOLVE | 旋转角度 **360** | C | t≈150s 键入(默认亦为 360) |
| REVOLVE | 旋转角度 **150** | C | t≈205s 键入 |
| REVOLVE | 旋转角度 **90** | C | t≈262s 键入 |
| REVOLVE | 起点角度(ST) 默认 **<0.0>** | C | 提示回显 |
| REVOLVE | 模式 <实体> _SO / 曲面 _SU | C | 选项回显 |
| COPY | 阵列(A) 项目数 **4** | C | t≈300s |
| 特性面板 | 面积 **1554.3894** | D | t≈353s(某面域/多段线) |

## 剔除
- t≈306–332s 轴选 对象(O) 报错「对象必须位于轴的一侧。无法旋转选定的对象。」
- 轴选 Z 报错「旋转轴与旋转曲线的平面垂直」
- 多次 *取消*

## 复刻做法
三个矩形轮廓, 分别用三种轴定义方式旋转三种角度:
1. RECTANG 100,0→200,300, 轴=对象(O)(直线 x=0), 角度 **360**
2. RECTANG 500,0→560,200, 轴=**Y**, 角度 **150**
3. RECTANG 800,0→850,150, 轴=**Y**, 角度 **90**
矩形尺寸为占位值(L 级); 三个角度是硬证据。
