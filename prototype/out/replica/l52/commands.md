## ⚠ 数值找不到出处(重点)

1. **矩形尺寸 `110 × 70` 与命令行证据冲突**。
   7 张蒙太奇里,与矩形有关的唯一回显是 **`标注文字 = 234.81`**(48.0s、126.2s、132.0s、856.3s
   共 4 次一致)。**`110` 和 `70` 在命令流里一次都没有出现过**,`RECTANG` 也从未走 `尺寸(D)` 分支
   (31.2s 的选项表里有 `尺寸(D)`,但讲师是用鼠标拖的)。
   `dlg_370.png` 终帧显示矩形宽高比 ≈ 1.6,与 110/70 = 1.57 接近,说明 110×70 是**照画面比例定的**,
   等级最多 **M**,且**与 C 级的 234.81 直接矛盾**。
   → 建议:把矩形宽改为 **234.81**,高按同比例定(234.81 / 1.6 ≈ 147)并标为 M 级;
   或至少在文档里承认 110×70 无出处。**这是本课最需要修正的地方。**
2. **`DIMCEN -5` 的 `5`**:圆心标记大小 5 没有命令行或对话框数字出处;
   **符号(负号,即"直线"模式)有画面出处**(`dlg_370.png` 两个圆都是贯穿的中心线),
   但**大小 5 是估的**。ISO-25 的默认是 `2.5`。建议标为 M 级或改回默认 2.5。
3. **弧长 458.03(577.4s)对应的圆弧没有被复现**:脚本里没有 ARC 实体,`DIMARC` 也没有出现在
   verify.json 里(`counts` 无 ARC)。这是**已知缺口**,不是编造,但要写明:
   视频 558–589s 画了一段弧并标了弧长 458.03,成品缺这一项。
4. **`CENTERMARK`(193–231s,6 次)、`DIMBREAK`(428–439s,`1 个对象已修改`)、
   `DIMJOGLINE`(859–868s)三条命令都没有复现**。其中 DIMBREAK 有明确的"已修改"回显,
   即视频里确实生效了。属缺口。
5. **`PICKBOX 10` 与两个 ZOOM 窗口**是无头回放的操作需要,不是课程数值。

## 验证(verify.json)

```
counts: { LWPOLYLINE: 3, DIMENSION: 4, CIRCLE: 2 }
CIRCLE #1 c=(60,-110) r=82.03      ← 与 404.6s / 803.5s 的 82.03 零误差 ✅
CIRCLE #2 c=(260,-110) r=82.03     ← 同上 ✅
LWPOLYLINE ×3: 110×70,起点 (0,0) / (150,0) / (300,0)   ← 尺寸无出处 ⚠
DIMENSION ×4: type 32 ×3(三种箭头的线性标注),type 164 ×1(半径标注)
```
**反算复核**:两个圆的半径 82.03 与命令行**零误差**;
三个矩形的标注值在 DXF 里是 `<measured>`,回放后会算出 **110**,而视频里是 **234.81** —— **不一致**。
现有 verify 不比对标注文字数值,所以**这个不一致不会被自动发现**。

## 证据等级分布

- **C(命令行)**:234.81、82.03、458.03、`找到 1 个`、`1 个对象已修改`、`标注已解除关联`
- **D(对话框/画面)**:三种箭头类型(实心闭合 / 建筑标记 / 无)、圆心标记为"直线"模式
- **M(像素比例)**:矩形 110×70(与 C 级 234.81 冲突)、DIMCEN 的大小 5
- **L(布局)**:三个矩形与两个圆的摆放、所有尺寸线位置

## 做不到的部分

- **矩形与圆都是鼠标拖出来的**,原始输入无数值;圆靠 `DIMRADIUS` 反推成功(C),
  矩形只能靠 `DIMLINEAR` 反推 —— 而脚本没有采用这个反推值(见 ⚠ 第 1 条)。
- **弧 + DIMARC(458.03)、CENTERMARK、DIMBREAK、DIMJOGLINE 四项未复现**。
- 「符号和箭头」选项卡的其余字段(折断大小、弧长符号位置、半径折弯角度、线性折弯高度因子)
  在本次核对的抽帧里看不清,**不猜值**,脚本保持默认。
- 夹点拖动导致的 `标注已解除关联` 是反面演示,不复现。
