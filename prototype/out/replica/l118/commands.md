# 课时118 面的工具(SOLIDEDIT 面) —— 命令流

蒙太奇覆盖: 13/26 去重条带图 (≈50%, **低于 60% 的规程要求, 如实标注**)
覆盖到的时段包含全部键入数值的片段(t≈100–980s 的 SOLIDEDIT 段)。

## 命令序列
RECTANG / PRESSPULL / EXTRUDE / MOVE 建基体 →
**SOLIDEDIT 面(F)**, 面编辑选项 [拉伸(E)/移动(M)/旋转(R)/偏移(O)/倾斜(T)/
删除(D)/复制(C)/颜色(L)/材质(A)/放弃(U)/退出(X)]:
- 拉伸(E): 高度 **1000**, 倾斜角度 <0>: **0**
- 拉伸(E): 倾斜角度 <30>: **-30**;倾斜角度 <89>: **-60**
- 倾斜(T): 倾斜角度 **30**
- 偏移(O): 偏移距离 **-1000**
- 旋转(R): 旋转角度 **30**, 轴 [经过对象的轴(A)/视图(V)/x/y/z] <两点>
- 删除(D)/复制(C)/颜色(L)/材质(A) 演示
→ SOLIDEDIT 边(E) 复制(C)/着色(L) → VSCURRENT X 射线/真实

## 剔除
- 大量 *取消*(讲解时反复进出 SOLIDEDIT 而不确认)
- 删除面(D) 的 103013 报错

## 复刻做法(四个 3000³ 立方体各演示一种面操作)
1. `SOLIDEDIT _F _E` 顶面 拉伸 **1000**, 倾斜角度 **0**
2. `SOLIDEDIT _F _E` 顶面 拉伸 1000, 倾斜角度 **-30**
3. `SOLIDEDIT _F _O` 顶面 偏移 **-1000**
4. `SOLIDEDIT _F _R` 顶面 绕顶面一条棱 旋转 **30**
