## 三、构造方式

**左件**:两个同轴心距 1117.2 的圆(R450 / R225)+ 内接正三角形(R225)+
两段 R3000 的大圆弧(用 `MIRROR` 对称)+ 中心的 30°/60° 花瓣
(由 R450 圆与 r=150 圆角构成,150 来自 532.0s 的 FILLET 半径)。
斜线 `(-542.3743,-542.3743)–(542.3743,542.3743)` 长度 = 1534.2,**无出处**。

**右件**:同心双圆 R399.68 / R799.37 + 水平中心线 + 中心点式椭圆
(短半轴 266.455 = FILLET 266.46)+ 两条斜撑 + 两段 r≈133.23 的小圆弧,
再 `MIRROR` 成对称件。

## 六、做不到的部分 / 数值找不到出处

1. **⚠ 右件的整体轮廓尺寸没有出处。**
   - 椭圆**长半轴 1398.265**(端点 2101.735 / 4898.265);
   - 椭圆中心的 **y = 1482.3273**;
   - 水平中心线 `1900,0 → 5100,0`(长 3200);
   - 左件斜线端点 **±542.3743**。
   这些在 302 条条带里**一次都没有回显**,是按画面比例摆的。
2. **⚠ 两个 C 级长度在复刻件里找不到对应几何。**
   - **1598.74**(806.2s,= 2×799.37):脚本的水平中心线长 **3200**,不是 1598.74。
     这条线很可能应该是 1598.74(即恰好横跨大圆直径),**建议核对**。
   - **532.91**(960.8s):脚本里没有任何长度是 532.91。
3. **`ELLIPSE` 在视频里四次全部取消(927.2 / 976.6s 等),半轴长度从未键入。**
   脚本用 266.455 作短半轴是**借用 FILLET 的 266.46**,属于合理推断而非直接证据。
4. **左件中心花瓣的 30°/60° 分度没有回显** —— 由 `POLYGON 3`(三等分)和
   `MIRROR` 的对称性推出,标 C 派生。
5. **`MIRROR` 的镜像轴坐标从未回显**(433.1 / 580.5 / 900.3s 都只有「指定镜像线的第一点/第二点」),
   脚本取 x 轴 / y 轴是按对称性推定(L)。
6. **视频开头的 1257.9 / 882.9 / 75 三个标注量的是上一课遗留的对象**,复刻件里没有对应几何。
7. **`CANNOSCALE 1:10`(703.4s)未落地**;`DIMSCALE 30` 无出处。
8. **本课是"传动装置绘制1",视频里图形并未画完**(大量 LINE / ARC / ELLIPSE 被取消),
   复刻件是"按已确证尺寸重建的等价件",不是逐笔重放。
