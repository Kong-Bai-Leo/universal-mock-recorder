24 张蒙太奇。**蒙太奇覆盖:15/24 = 63%**
(读 m02、m04、m06、m08、m10、m12、m13、m14、m16、m17、m18、m19、m20、m22、m23)。

⭐ **本课是全课程证据等级最高的一课**:讲师用 **`BOUNDARY`(BO)提取房间边界 →
`LIST`(LI)列出多段线的全部顶点世界坐标**,命令行因此**直接吐出每个房间的精确坐标表**。
脚本里那些带三位小数的坐标(3022.157 / 6346.172 / 19564.569 …)**不是测量值,
是从 LIST 回显逐位抄下来的**。

## 四、构造方式

在课时96/97 的轴网上,把商场西段细分成 **9 个房间/商铺**,每个都用 LIST 抄来的
顶点坐标画成闭合 `PLINE`;东段留出商铺11–13;再加尺寸链、房间名与面积/周长文字、
次入口箭头和一处图案填充。

- 外墙 `RECTANG 0,0 45085,8880`(C,继承 96/97)
- 内墙 `OFFSET **60**`(C,227.5s LIST 换算出内边界在 x=60 / y=60)
  —— 注意与课时96 的 `OFFSET 100` 不同,本课是 60
- 6 组隔墙 `LINE`,x = 13129/13229、17086/17186、25001/25101、29358/29458、
  34036/34136、38136/38236 —— **全部由 LIST 换算得到**
- 9 条闭合 `PLINE`(房间边界)—— 上表
- 底部 11 段尺寸链 + 中段 3 段链 + 总长 45085 + 进深 8880 + 顶部 5 段链
- 26 条 `TEXT`:房间名(杂物间/女卫/男卫/仓库02/商铺11/商铺12/商铺13/入口/次入口)、
  每间的「面积/周长」、标题「商铺划分示意图」
- `-HATCH _P ANSI31 100 0` 一处填充

## 七、做不到的部分 / 数值找不到出处

1. **⚠ 部分面积/周长数值未在本次覆盖的条带里找到出处。**
   已确证的是 `10.21m2` / `13.20m`(328.8s)、`12.61m`(177.1s)、`10.87m`(400.8s)。
   其余 `7.56m2 / 11.01m`、`9.47m2`、`14.00m2 / 15.42m`、`12.03m2 / 14.15m`、
   `7.09m2 / 10.67m`、`7.33m2`、`59.5m2 / 31.1m` **很可能出自我跳过的 9 张蒙太奇
   (m00–m03、m05、m07、m09、m11、m21)里的 LIST 回显**,但本文档无法把它们追溯到秒。
   → 若要 100% 闭环,应补读这 9 张。
2. **⚠ 房间名称文字全部无出处。**「杂物间」「女卫」「男卫」「仓库02」「入口」「次入口」
   「商铺11/12/13」这些中文是用 `MTEXT`/`MTEDIT` 就地编辑器打的,
   `_mtedit` 在命令行只留下命令名(本课出现二十余次,全部 `*取消*`),**内容一个字都没回显**。
   只有标题「商铺划分示意图」有课时97 的特性面板 D 级证据。
3. **⚠ 图案填充的图案名/比例/角度无出处。** 795.8–890.9s 的 `HATCH` 全程走**对话框**,
   命令行只有 `拾取内部点` 和 `未发现有效的图案填充边界。`,而且 862.6s 还
   `_u HATCH` **撤销过一次**。脚本的 `ANSI31 / 比例 100 / 角度 0` 是构造的。
4. **中段尺寸链 `23455 → 35705 → 38185 → 45085` 的两个分点(23455 / 35705)无出处。**
5. **通道箭头 `PLINE 20000,-1400 _W 0 600 20000,600` 的位置无出处**(宽度 0/600 继承课时97 的 C 级)。
6. **`MATCHPROP` 未复刻** —— 无头版既无 `MATCHPROP` 也无 `-MATCHPROP`(SOP 已列)。
7. **`EXTEND`(595.7s)在视频里被 `_u` 撤销**,不复刻。
8. **本课的内墙偏移是 60,课时96 是 100** —— 两者都有 C 级证据(96 是 `OFFSET 100` 键入,
   98 是 LIST 世界坐标换算),说明**讲师在 98 里重画/调整过墙线**。三集的墙厚不一致是
   视频本身的事实,不是复刻错误,但需注意 96 与 98 的成品在这一点上不可互换。
