## 三、构造方式

一个「圆角底板 + 中心锥台 + 通孔」的三维件:

```
RECTANG 0,0 _D 440 320        底板轮廓(440×320 = C)
FILLET _R 50 + _P             四角 R50(50 = C,FILLETEDGE 也确认 4 条边)
EXTRUDE _L 80                 底板厚 80(80 = C)
CIRCLE 220,160,80  r=120      锥台下截面
CIRCLE 220,160,0   r=30       通孔
CIRCLE 220,160,80  r=80  → MOVE 0,0,0 → 0,0,170  ⇒ 落到 z = 250(250 = C,170 = C)
LOFT (r120@z80 → r80@z250)    锥台(2 个横截面 = C)
EXTRUDE (r30) 330             通孔柱,高 330 = 80 + 250
UNION / SUBTRACT              底板 ∪ 锥台,再减去通孔
DIMLINEAR 440 + DIMRADIUS ×4
```

**高度链自校验**:`80`(底板厚,138.2s)+ `170`(夹点拉伸位移,373.9s)= **250**
—— 恰好等于 879.4s 回读的 `标注文字 = 250`。三个数互相闭合。

## 四、验证(MASSPROP)

`MASSPROP` 报出的体积 **15797377.1282**,已与解析值核对为**零误差**
(底板 440×320 带四角 R50 + LOFT 锥台 − Ø60 通孔)。

`verify.json` 回读:
```
3DSOLID     1
LWPOLYLINE  1   8 顶点圆角矩形:(50,0)(390,0)(440,50)(440,270)(390,320)(50,320)(0,270)(0,50)
                → 长 440、宽 320、四角圆角半径 50 ✓
CIRCLE      3   c=(220,160,80) r=120 / c=(220,160,0) r=30 / c=(220,160,250) r=80
DIMENSION   5   线性×1 + 半径×4
```
圆角矩形的顶点直接印证 440 / 320 / R50;第三个圆的 **z = 250** 印证 80+170。

## 六、做不到的部分 / 数值找不到出处

1. **⚠ `MASSPROP` 的原始回显没有在本次覆盖的 13 张里出现**(应在 m07/m09/m11/m13 等未读条带里)。
   体积 15797377.1282 是从既有验收记录承接的,本文档无法追溯到秒。
2. **⚠ 上圆半径 80 存在歧义。** 860.2s 的 `标注文字 = 80` 既可能标的是**底板厚 80**
   也可能是**上截面半径 80**。脚本两处都用了 80。二者同值使证据无法区分,
   但底板厚 80 另有 138.2s 的 `EXTRUDE … 80` 直接确证,所以**上截面半径 80 严格说是 D/L 级**。
3. **`BOX` 在视频里三次全部取消**,不复刻。
4. **`FILLETEDGE`(三维边圆角)未直接复刻** —— 脚本在二维轮廓上先 `FILLET _R 50` 再拉伸,
   几何结果等价,但**命令不同**;视频里 `FILLETEDGE` 也没走完(225.1s `*取消*`)。
5. **全部拾取点、圆心位置 (220,160) 无回显** —— 220 = 440/2、160 = 320/2 是按"居中"推的(C 派生)。
6. **`ISOLATEOBJECTS` / `UNISOLATEOBJECTS`(934.1s)是显示操作**,不入脚本。
7. **`LOFT` 的导向/路径选项未用**(视频取 `<仅横截面>` 默认),脚本一致。
