# 课时68 插入块 / 编辑块 —— 命令流与证据

视频 901s / 235 条命令行条带 / 15 张蒙太奇。
**蒙太奇覆盖:12/15 = 80%**(读 m00–m01、m03–m08、m10、m12–m14;跳过 m02、m09、m11,该三段是连续窗选/取消,无数值)。

## 一、命令序列

`RECTANG`(试画,取消) → `CIRCLE`(试画,取消) → **`BLOCK` 建块**(反复 8+ 次) →
`COPY`(取消) → `LINE`(取消) → **`-INSERT` 插入块** → **`BEDIT` / `-BEDIT` 块编辑器** →
`CIRCLE`(块内加圆) → `BCLOSE` → **`EXPLODE` 分解** → `STRETCH`(取消) →
`BREPLACE`(**无权限,失败**) → `ATTDEF` / `BASE` → `EATTEDIT`(**无属性块,失败**) →
`REFEDIT` / `REFCLOSE _disc` → `RESETBLOCK`

## 四、构造方式

脚本按视频顺序复刻「建块 → 插入 → 改块 → 再插入 → 分解」这条主线:

1. `RECTANG 0,0 180.93,180.93` + `CIRCLE 90.465,90.465 90.465`
   —— 圆内切于正方形。**半径 90.465 是 C 级**(444.6s 的 `<90.4650>` 默认值回显),
   正方形边长 `180.93 = 2 × 90.465` 是由此**推导**的(见缺口 2)。
2. `-BLOCK 方块 …` 建块,对应 `BLOCK 找到 2 个`。
3. `-INSERT 方块 300,0 / 600,0 / 900,0 1 1 0` 三次插入,比例/角度来自 611.7s 的完整回显。
4. 重画一份 + 加一条 `LINE`(对应 475.4s 的 `BLOCK 找到 3 个`),
   用 `-BLOCK 方块 _Y` **覆盖同名块定义** —— 等价于视频里的 `BEDIT` + `保存修改(S)`
   (无头环境没有块编辑器 UI)。
5. 第 4 次 `-INSERT` 插到 1200,0,此时插入的是**改过的块**。
6. `EXPLODE _L` 分解最后一个插入 —— 对应 810.0s 的 `EXPLODE 找到 1 个`。

## 七、做不到的部分 / 数值找不到出处

1. **块名「方块」没有命令行出处。** 视频用的是 `B` → **BLOCK 对话框**,块名是在对话框里键入的,
   命令行只打印 `BLOCK 找到 N 个` 和 `指定插入基点`。235 条条带里**从未出现块名**。
   脚本的「方块」只能来自画面(D 级)或是编的,本文档无法追溯到秒。
2. **正方形边长 180.93 是推导值,不是证据。** 唯一的硬数是圆半径 90.465;
   矩形按"圆内切"的假设算出 180.93。视频里矩形是鼠标拉的,**没有任何尺寸回显**。
3. **4 个插入点(300,0 / 600,0 / 900,0 / 1200,0)完全无出处**,是等距排开的布局值(L)。
4. **块内新加的那条 `LINE`(长 14.5)无出处** —— 视频里 234.8s 的 LINE 被取消,
   真正加进块里的那条线是在块编辑器内画的,拾取点没有回显。
5. **块基点无出处。** 702.0s 出现的 `<4558.3071,880.0287,0.0000>` 是 `BASE` 命令的
   **图形基点默认值**(上一次设的),不是块的插入基点;脚本用圆心作基点是合理推断,非证据。
6. **`BREPLACE`(块替换)在视频里因未登录 Autodesk 帐户而无法执行**,脚本不复刻。
7. **`EATTEDIT` 报「此图形不包含带属性的块」**,属性块是课时69 的内容,本课不涉及。
8. **`REFEDIT` 的修改被 `_disc` 放弃**,不改变终态,脚本不复刻。
9. 视频里 `EXPLODE` 一次选到 9 个/18 个对象并报「N 个不能分解」,
   那些对象是**旧图上的其它内容**,本复刻件里没有对应实体。
