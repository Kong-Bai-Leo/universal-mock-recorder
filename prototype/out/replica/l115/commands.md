# 课时115 按住并拖动(PRESSPULL) —— 命令流

蒙太奇覆盖: 24/24 去重条带图 (=470/470 条带, 100%)

## 命令序列
COPYCLIP(54 个对象) / PASTECLIP(粘进一张平面图) → LAYOFF(逐层关闭) →
**PRESSPULL**(回显「已提取 1 个环 / 已创建 1 个面域 / 已创建 1 个拉伸」)
指定拉伸高度 **2800**(反复)、**400**、**900**、**700** →
EXTRUDE(高度提示默认 <184.5313>) → BOX(高度提示默认 <712.0863>)

| 命令 | 参数 | 等级 | 出处 |
|---|---|---|---|
| PRESSPULL | 指定拉伸高度 **2800** | C | t≈672s 起, 多次键入 |
| PRESSPULL | 高度 **400** / **900** / **700** | C | 键入 |
| EXTRUDE | 高度提示默认 **<184.5313>** | C | 提示回显 |
| BOX | 高度提示默认 **<712.0863>** | C | 提示回显 |

## 剔除
- 多次 *取消* 与 U 撤销
- COPYCLIP/PASTECLIP 属剪贴板命令

## 复刻做法与降级说明
**坑表第 8 条: PRESSPULL 在无头 accoreconsole 里无效(需要在面内点击做边界检测),
本课已按规程改用 EXTRUDE 等价实现, 高度值全部沿用视频里 PRESSPULL 的键入值。**

1. 外墙 RECTANG 6000×4000 + 内墙 RECTANG 5600×3600 → 各 EXTRUDE **2800** → SUBTRACT
   (等价于视频里「在墙线闭合区域上 PRESSPULL 2800」)
2. RECTANG 1000×1000 → EXTRUDE **900**
3. RECTANG 1000×1000 → EXTRUDE **700**
4. RECTANG 1000×500 → EXTRUDE **400**

## 做不到的部分

- 视频里的平面图是粘贴进来的外部图纸, 无源文件 → 用矩形墙圈占位(L 级)。
- COPYCLIP/CUTCLIP/PASTECLIP 在无头环境无剪贴板, 未纳入(坑表第 23 条)。
