# Computer Use Agent 复现任务

## 目标

在 AutoCAD 中绘制奥运五环样式图形: 顶排三个圆用“两点(2P)”方式各以直径 20000 相切排列,底排两个圆用“相切,相切,半径(TTR)”方式与相邻顶圆相切、半径 10000。

## 输入

- 完整结构化流程：`semantic-trace.json`
- 可执行 TypeScript 描述：`mock-script.ts`
- 原录制参考截图：`../screenshots/`
- 目标 Mock 软件入口：由执行者提供并确保可重置到初始状态

## 执行规则

1. 使用 Computer Use 操作目标 Mock，不调用被录制软件的专用接口。
2. 按语义功能、无障碍信息、文字、视觉、相对位置的顺序定位控件。
3. 每步后截图，并与 canvasChange 和参考截图核对；不满足预期时先 Escape，必要时 Undo，再重试候选目标。
4. drag 必须使用 gesture 的起点、终点和路径；位置均相对目标窗口归一化。
5. measurements 是几何验收值；业务单位不可见时只比较 px 或 window_ratio。
6. 不执行 omitted 中被撤销、取消或无状态贡献的动作。
7. 最后保存结果截图，并报告成功步骤、失败步骤、几何误差和最终画布差异。
