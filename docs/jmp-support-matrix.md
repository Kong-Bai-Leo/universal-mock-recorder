# JMP 第一批支持边界

环境：VM3，JMP Trial 19.1.5 英文版。不是 JMP Pro。

| 范围 | 实现 | 验证要求 |
| --- | --- | --- |
| VM 内键鼠、前后截图、UIA 开关 | 已在 VM 采集合成操作；空闲延迟后图已实测捕获最终报告 | 26 事件新样本包含提交后单元格与 Distribution 报告；不保证任意延迟都被覆盖；UIA 关闭分支尚未实测 |
| UI Map | File/Analyze、数据表、列信息、Distribution 启动对话框第一批；父层级分文件 | 标记 observed 与 documented_not_scanned；不是全量扫描 |
| 显式建表、行、列、单元格、重命名 | AI 返回语义操作 + 明确原生接口调用 | 校验接口/参数/对象，再比较行列、列类型与每个单元格 |
| Distribution | 无缺失的连续数值列 | 统计值/绑定列另行比对 |
| Bivariate / Fit Line | 连续数值 X、Y，无缺失，至少3行，X不恒定 | X/Y角色、拟合参数另行比对 |
| 主要交付 | 默认单文件 `jmp-replay.jsl`，数据与受支持分析内嵌，直接在 JMP 运行 | 本轮默认输出/离线重编译测试通过；不要求运行时 JSON、Node、密钥或执行 AI，不等于本轮已实机执行 |
| 内部接口计划与原生验证 | `_internal/replay-plan.json` 审计；最终状态 JSL 与本地有界逐接口验证适配器分别验收 | 历史样本通过保存重开及独立源真值对照；默认编译器不是逐调用执行器，不代表其他组合均已实测 |
| 分段/预算/失败 | 合法表列身份、检查点、每轮2次/每次12图、失败需显式重试 | 离线测试；真正 VLM 请求单独授权 |
| 未知/低清数据 | 不猜数，不默认填0，不输出假完整结果 | 反例测试 |
| 导入/公式/删行列/筛选/权重/分组/分析后改表 | 未支持 | 拒绝或标记 unresolved |
| DOE/Graph Builder/其他统计/Pro | 未支持 | 不宣称涵盖 |

精确值来自录制证据，不来自已保存源表。原生接口仅用于回放、导出与验证。
