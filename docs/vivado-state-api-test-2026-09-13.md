## 本轮补修的通用问题

1. 知识引用可以是已登记的控件、Tcl 接口或官方文档来源，不能只拿控件 ID 列表检查。未知 ID 仍被拒绝，知识 ID 不会当作对象句柄执行。
2. 触发操作和确认图片所属的后续输入分开：后续导航可以携带确认前态图，不等于前面的顶层切换被取消。仍拒绝真正的取消矛盾、缺少触发贡献或伪造截图。
3. 仅打开包含 Set as Top 的菜单不等于已激活它；文字防漏检查不应将这种准备行为强制当成顶层事务。它不是像素级真实性证明，仍需独立视觉核查。
4. 对同一工程、同一类型/名称、同一逻辑 ID 再做 get_filesets/get_runs，是重新读取已有绑定。保留对象属性、输入修订号及 completed/stale 状态，不重新登记成 not_started。改 ID 创建别名、跨类型覆盖及借重查复活旧综合仍被拒绝。
5. 局部恢复核验完整请求/响应/用量与祖先链；变更 schema、提示、证据或预算拒绝复用，缺失响应/用量也拒绝续跑。另加只读最终审计，不调用 API、不发布 Tcl。
