# 截图视觉面追踪

这是分析侧功能：在原有 VLM 请求中定位可见面的轮廓，本地追踪器分配
`vf-000001` 等视觉 ID。它不读取 3ds Max 场景数据库，不把物体拆成节点，
也不会把视觉 ID 当成 MAXScript 的 polygon index。

## 使用

正常录制并 Generate，或者重新分析已有录制即可。此功能默认开启，分析器
直接使用新的代码；本次修改不需要重新编译录制器。旧分析缓存因版本变化
会失效，重新生成会产生正常的 API 费用；本次开发测试没有发出付费请求。

结果保存在原有 `generated/semantic-trace.json` 中，不新增常规输出文件：

- `visualFaceTracking.tracks`：最终目录。包含视觉 ID、所属物体、首次/末次
  观察、来源面、视觉邻接、置信度和状态。`runtimeFaceId` 始终为 `null`。
- `visualFaceTracking.frames`：逐张已分析截图的观察记录。轮廓 `polygon`
  使用上传图片的 0–1 坐标；`sourcePolygon`、`sourcePixelPolygon` 在映射已知
  时指回原始全图。`screenshot` 和 `frameId` 说明它属于哪张截图。
- `visualFaceTracking.issues`：未覆盖帧、被拒绝的轮廓、歧义匹配、缺乏完成
  证据的新面声明等。它们不会单独触发付费语义修复，也不会删掉正确场景操作。
- `visualFaceFrames`：原始模型提议，供审计；不能把这里的声明视为本地已接受。

## 身份规则

| 情况 | 处理 |
|---|---|
| 视口稳定，唯一轮廓高度重叠 | 复用旧 ID；不是只比较外接矩形 |
| 视口缩放、平移、旋转 | 禁止仅凭旧像素位置匹配 |
| 首次看见之前隐藏的面 | `newly_visible`，不宣称编辑创建 |
| 暂时没观察到 | `not_observed`，不是删除 |
| 遮挡后再次出现 | 需实际附带对照图和明确特征/邻接支持，否则为候选 |
| 已完成 Bevel 等编辑，具有前后证据及来源面 | `created_by_edit`，分配新 ID 并记录 `parentIds` |
| 被编辑替换且具有后继面的旧面 | 明确证据下才 `retired` |
| 两个面竞争同一个旧 ID，或多个候选接近 | 保留候选 ID，置信度不高于 0.49，不按列表顺序硬选 |

轮廓提取依赖 VLM，不是新增了一个训练完成的分割模型。轮廓相交/面积、
坐标边界、事件/图片来源、物体身份、一对一匹配及相机导航屏障由本地代码
检查。这里的邻接关系仍是视觉判断，不等于读取了真实 mesh 拓扑。

视觉追踪和精确回放是两层：Bevel 仍须已有的局部轴极值选择或带几何校验
的准确面编号；本功能不自动把一个视觉面绑定为可执行的内部面。

## 分段与成本边界

目录通过检查点和下一段上下文续接；记录增量，避免每段复制整份历史。
默认在已有截图额度内优先保留前后全图，最多分析 6 个新帧、每帧 12 个
重点面，下一段最多携带 32 个近期面摘要及额度内的历史对照图。
这是采样的可见面目录，不是“所有帧/所有隐藏面”的完整目录。

同一请求返回面观察，不新增专门的模型调用，但新增文字输出会增加 token
和部分耗时。预算排除的帧、重点面覆盖会明确标注，数字参数截图仍共用原有
总上传预算。需要调整时，在配置的 `analysis.threeDsMax` 下添加：

```json
{
  "visualFaceTracking": {
    "enabled": true,
    "maxFrames": 6,
    "maxFacesPerFrame": 12,
    "maxContextTracks": 32
  }
}
```

分别最高为 16、64、128；调高不会自动上传原本没选中的截图。设
`enabled=false` 可关闭追踪并恢复原截图优先级。

## 验证范围

`node --test tests/threedsmax-visual-faces.test.mjs` 使用明确标为合成数据的
VLM 返回样本，验证目录、匹配、遮挡、新面来源、跨段恢复、坐标映射和
一次请求接入。它不证明真实模型在复杂遮挡/对称物体上的分割准确率。
需要用实际录制进行另一次付费分析，才能评估该部分效果。

模型字段沿用 [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)
的严格结构化输出规则；格式合规不等于视觉判断正确，所以本地仍单独校验。
