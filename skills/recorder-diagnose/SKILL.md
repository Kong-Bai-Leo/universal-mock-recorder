# 录制器证据链排查

目标是解释最早从哪里开始出错，而不是让生成的 SCR/MS 暂时看起来正确。区分“识别不到”“识别到了但表达不了”“编译/执行错误”。

## 定位与范围

- 先确认用户指定的仓库、应用和录制。没有指定录制时，按对应应用目录的录制时间定位最新项，并说明选择；不要把最新修改的旧 generated 当新录制。
- 以下路径相对项目根目录，不是技能安装目录。先查看 Git 状态，保留其他任务的未提交改动。
- AutoCAD：`bin/recorder/recordings`、`src/analyzer/cli.mjs`。
- 3ds Max：`bin/3dsmax-recorder/recordings`、`src/analyzer/3dsmax-cli.mjs`。
- 先用已有本地结果排查。诊断请求本身不授权付费重分析、上传新数据或控制用户当前场景；有明确授权再执行相应步骤。

## 按最早错误点追踪

1. 阅读该次录制的 manifest、错误详情、分析输入/上传清单、semantic trace 与 CAD/Max program 中有关操作。字段及文件随版本变化，先核实实际文件；分段摘要不等于完整原始请求。
2. 取一项失败操作及必要的前后依赖，核对：原始事件 → 候选动作/命令阶段 → 已选截图 → 真正成功加载上传的图片 → VLM 输出 → 本地校验/实体目录 → 编译脚本 → 实际回放。停在第一个有证据的偏差，标记后续连锁后果。
3. 查看实际图片，不仅看文件名。检查捕获时间、所属窗口、截图尺寸、裁剪范围及原图映射。`before/after/settledAfter` 是角色标签，不保证时序；晚到的截图可能包含下一动作。原图存在才可能补裁，没保存的像素无法恢复。
4. 核查一组操作所需证据是否作为整体保留：前图、选中/预览、参数、确认后持久状态，以及必要全局视图。小 TRIM 不能仅因变化像素少被去掉；大变化也可能只是缩放、悬停或选择高亮。
5. 对照当前界面提示审查 UIA、知识库候选和 harness 状态；它们是辅助假设，可能滞后。发生冲突时记录冲突及采用证据，不强行服从旧标签。

## 两类应用的高频陷阱

**AutoCAD**

- 先确定命令阶段再解释输入：活动 ARRAY 的 I 可能是 Items，ROTATE 的 C 可能是 Copy，OFFSET 的数值可能是侧点而非偏移距离。命令目录用于候选，当前提示和提交后的状态用于确认；不能仅按单字符缩写匹配。
- 区分游标坐标、最终吸附点、绝对/相对坐标与距离/角度。已知圆线几何和明确约束可解析推导；屏幕上看起来竖直不自动证明 CAD 角度精确。
- 顺着创建、修改、替换、删除、撤销和阵列成员查实体链。一个早期漏掉的 OFFSET/FILLET 可导致后续 TRIM/COPY/MOVE 全部无法引用；不要逐项编造新 ID 去消除报错。
- Escape 可能只退出连续命令，已完成的多次修改仍存在；跨段 active/deferred 也不等于整段无效。

**3ds Max**

- 拖拽先区分创建、对象变换、复制、子对象编辑、选择、视口导航及无变化。对象级与 Polygon/Edge/Vertex 级不互相替代。
- XYZ 要同时确认工具、选择层级、字段含义、单位和绝对/偏移模式；它可能是游标位置、对象位置、旋转角、缩放百分比或子对象选择中心。
- 基本体创建的早期高度可能是预览；Shift 拖拽与 Clone Options 属于同一事务；Bevel 可能包含拖高度、松开后移动调整 Outline、再点击确认。第一次松开不是所有工具的完成点。
- `vf-...` 视觉面 ID 不是运行时面编号；画面新出现的面可能只是刚从遮挡中露出。局部屏幕上方不等于物体局部 +Z。

## 耗时和费用排查

分别统计预处理、初次分析、分段续接、语义修复、最终审计、网络重试和编译耗时。使用实际请求数及 input/cached/output usage；不要把事件数、图片数、请求体 MB 当 token 或费用。未保存完整请求/usage 时明确估算边界；报价另查当时对应模型的官方价格，不在技能里固定价格。

检查是否重复发送全部历史、整段图片及 previousResult，检查 checkpoint 是否因输入/版本改变而失效。网络中断和语义不合格是两类错误：不能通过增加模型自信或无限重试解决。先解释哪类请求重复，提出有预算和停止条件的下一步。

## 修复与交付

用户要求修复时，在最早错误层做通用修复并补回归测试；生成脚本只作检查，不手改某次成品来冒充修复。不能硬编码齿轮、音符、某个 Cylinder 或某段录制的坐标。

报告：结论 → 关键事件/截图或代码证据 → 连锁影响 → 已改与未改 → 验证范围。明确哪些只是推测。原录制、截图、密钥及含用户数据的请求体不写入技能、测试夹具或提交；复现夹具优先合成、必要时脱敏。
