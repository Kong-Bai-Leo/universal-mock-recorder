# 录制器适配开发

把 AutoCAD 与 3ds Max 的实现经验迁移为应用适配，不把特定作品流程写入通用录制引擎。

## 确认能力边界

先明确应用版本/语言、输入模式、目标输出、支持的操作级别与允许的精度。用户已明确的信息不重复询问。目标 Mock 尚不存在时，先定义语义契约和适配接口，不声称已验证 Mock 回放。

区分四层：系统输入/截图采集 → 应用知识与状态推断 → 结构化操作及本地校验 → 回放后端。SCR、MAXScript、Computer Use、Mock 是不同验证/执行后端，不等于识别器本身。

本项目默认不依赖目标软件内部接口进行采集。UI Automation 可关闭；AutoCAD Action Recorder 等专用接入是可选增强。回放时使用目标软件脚本接口，不代表采集时已读到真实场景对象。用户要视频输入时，不能依赖录制专有的事件 ID、Automation ID 或键盘提交证据存在。

## UI Map 与命令知识

- 核实目标版本和工作区；UI 层级保留 tab/section、panel、control、split button 主按钮/箭头、菜单项的父子关系及所属控件。图标按钮也要有身份和功能说明，不能只记录能 OCR 的文本。
- 静态 `ui-map.json` 表达可复用层级与语义；`live-observation.json` 表达某次布局/窗口状态。bounds 属于具体观察，不是跨分辨率固定点击坐标。
- 按页面/panel 分文件并建立引用。记录 canonical 名称、别名、功能、可见标签、可用阶段、来源与核实状态。手册提到不等于在当前安装中观察过；未扫描项明确标注，不声称全覆盖。
- 查目标版本官方手册确认命令与选项；功能测试使用安全空白文件并在用户许可范围内。没有 Computer Use 权限时，可以先做文档目录，但不能将其称为实机扫描。
- 分段只检索相关条目。未命中时给有限候选、来源和不确定性；按视觉/上下文可提出近似匹配，不将“最相近”自动升级为确定按钮或命令。

## 证据与状态契约

每个操作至少能关联来源事件、时间区间、目标窗口、命令阶段、选择对象、参数证据和最终状态。每个数值应有角色、单位、绝对/相对模式、依据来源与精度类型；有数值但未知角色仍是未知。

截图策略按事务而非平均抽样：保留前态、必要预览/选择、带标签数值、确认后的持久后态。局部裁剪要保留原图范围/缩放映射，全图要能定位目标。预算不足时记录被排除的证据，不能静默保留半对图片并宣称已完整上传。

CV 适合辅助去重、配准和定位变化，但小改动不可直接忽略；窗口/视口导航应与几何变化分开。屏幕归一化只改变坐标表示，不自动得到 CAD 单位或三维深度。

维护 active command、stage、pending input、selection、deferred transaction。强提示优先于旧启发式。按完成事务安排分段；跨段传递有界状态、稳定实体目录和必要对照证据，而非反复传整个 session。事务超出预算时保留可续接状态，不强行截断成伪完整操作。

## 结构化操作与支持矩阵

新增操作同时检查：输入证据 → schema → 本地语义校验 → 对象/拓扑生命周期 → 编译器 → 运行时保护 → 测试。只加提示词或枚举值不代表支持已完成。

- 对象 ID 稳定且带合法创建时序；TRIM/FILLET 等替换结果有前后继关系；阵列需可追踪到成员；复制和实例不能混淆。
- 三维视觉面身份、运行时 mesh 面身份和场景 node 身份分开；拓扑变更后索引可能失效，不能把每个面随意 detach 成对象。
- 精确值、明确允许的估计值和未知值分开。估计需参照、视图条件、算法/模型来源、限制及标记；不存在标尺时不宣称恢复绝对尺寸。估算参数不能替代可靠选择。
- 不能表达的已完成修改保留为 unresolved/omitted 及原因，不当作无意义输入抹掉。撤销/取消通过最终状态和依赖判断。
- 生成器由本地受控代码编译 IR；模型不自由拼接可执行脚本。选择歧义、过期 ID、数量不符时应阻止错误修改，不默默选第一个对象。

## 项目定位与验证

在用户指定项目根目录查找：`src/Recorder.Native/Recorder.cs`、`src/analyzer/lib/analysis-harness.mjs`、`src/analyzer/lib/threedsmax-transform-harness.mjs`、`ui-maps/`。路径为导航提示，以当前代码为准。

默认沿用已有模型配置，先优化证据和状态表达，不擅自切模型。对成本控制设请求/图片/token 预算和修复上限；检查点要覆盖输入、schema、prompt、知识库等影响结果的版本。局部修复也必须保留依赖和全局一致性。

以合成 fixtures 验证新增路径及拒绝路径，并回归其他适配器；有授权再做真实模型分析或隔离目标应用测试。报告支持矩阵中的“已编码、离线验证、实机验证、真实录制验证”，不要合并成一个“完成”。
